Q Reference

Overview

q_lib is the core of Q: the DSP library itself. It is header-only, and it depends on nothing but the C++ standard library and the header-only Cycfi infra, so the same code runs on a desktop, inside a plugin, or on a small microcontroller with no operating system. q_io and QPlug build on it; it builds on neither.

Everything lives in namespace cycfi::q, which the reference writes as q::, and every header is included by its path under q/:

#include <q/fx/biquad.hpp>

namespace q = cycfi::q;
using namespace q::literals;

Start with Fundamentals. It covers what every page here assumes: the units and literals, the data types, and how processors compose as function objects.

Contents

Section What it covers

Units

Frequency, duration, period, phase, decibels, intervals and pitch as types, with the literals that make them readable in code.

Biquad

The classic second-order filters: low, high and band pass, all pass, notch, peaking and shelving.

Resonant Filters

State-variable, ladder (Moog and OTA) and Chamberlin filters with resonance, for synthesis.

Envelope

Envelope followers, from fast peak detectors to true RMS.

Dynamic

Compressors, the expander and automatic gain control.

Miscellaneous

The general-purpose blocks: delays, moving sums, averages and maxima, one-pole filters and DC blocking, gates, triggers and edge detectors, peak picking, clippers, phase shifters and signal conditioning.

Synthesizers

Oscillators, virtual analog with hard sync, and grains; generators for ramps, windows, envelopes, noise and LFOs; FM synthesis and a DX7 patch compiler.

FFT

The fast Fourier transform.

Support

The foundations the rest is built on: base types, fast math, concepts, multichannel buffers and the audio stream interface.

MIDI

MIDI 1.0 and MIDI 2.0: messages, readers, processors, translation between the two, MPE, per-note expression, endpoints and MIDI-CI.

Utility

Ring buffers, interpolation, lag search, antialiasing, sample format conversion and bit sets.

Pitch Detection

Real-time pitch and period detection with bitstream autocorrelation (BACF).
