Smoothing

Overview

smoothed provides a gradual slide to value for parameters that can change fast and thus cause artefacts. It allows for usage of different filters for different behaviour, such as the one-pole lowpass (q::one_pole_lowpass), Cytomic’s (Andrew Simper) dynamic smoother (q::dynamic_smoother) or any other filter that complies to the same standard.

An exponential smoother like q::one_pole_lowpass only approaches the target asymptotically, and in floating point it can stall just short of it. snap solves this: once the smoothed value is within a small delta of the target, or stops changing, it returns the target itself and reports settled(). The caller can then skip work that is only needed while the value moves, such as recomputing filter coefficients.

Snap

Include

#include <q/fx/smoothing.hpp>

Declaration

struct snap
{
   explicit          snap(float delta);

   float             operator()(float s, float target);
   bool              settled() const;

   float             _delta;
   float             _prev = NaN;
   bool              _settled = false;
};

Expressions

Notation

Object of type snap.

delta

Floating point value, the distance from the target within which the value snaps to the target.

s

Floating point value for the smoothed input sample.

target

Floating point value for the target.

Constructors

Expression Semantics

snap(delta)

Construct a snap with the specified delta. The snap starts out unsettled.

Function Call

Expression Semantics Return Type

sn(s, target)

Process the smoothed sample s. If abs(s - target) ⇐ delta, or s is identical to the previous sample, the snap is settled and target is returned. Otherwise it is unsettled and s is returned unchanged.

float

sn.settled()

Return true if the latest call settled on the target.

bool
The identical-sample test catches a smoother that has stalled short of the target due to floating point precision, even when delta is very small or zero. The first sample is never considered stalled.

Access

Expression Semantics Return Type

sn._delta

Direct access to delta.

float

Smoothed

smoothed<Smoother> owns a Smoother and a snap. Call it once per sample with the target; it returns the smoothed value, and the exact target once it has settled.

The smoother is constructed with a cutoff of 1 / (2π time). For a one pole smoother this makes time the time constant: after time has passed since a step, the output has covered about 63% of the distance to the new target.

Include

#include <q/fx/smoothing.hpp>

Declaration

template <typename Smoother>
struct smoothed
{
                     smoothed(duration time, float sps, float delta);

   float             operator()(float target);
   float             operator()() const;
   smoothed&         operator=(float v);

   bool              settled() const;

   Smoother          _smoother;
   snap              _snap;
};

Requirements on Smoother

Smoother must be a filter such as q::one_pole_lowpass, q::dynamic_smoother or any other filter that functions the same way. The requirements for the implementation of such a filter are the following:

s(x)

Per-sample processing function that returns the current state.

Return the current state of the filter.

Reset the filter state to a given value.

Jump the smoother straight to v, with no glide.

Choosing delta

delta is an absolute distance, so pick it relative to the range of the value. A smaller delta follows the exponential tail for longer before snapping. A larger one ends the glide sooner, but leaves a small audible step if it is too large. For a gain in the range 0 to 1, 1e-4 (-80 dB) is a good start. For a cutoff frequency in Hz, a value of 0.1 is more appropriate.

Example

Smooth a gain control applied to the input samples in, at sps samples per second, with a 10 ms time constant:

#include <q/fx/smoothing.hpp>
#include <q/fx/lowpass.hpp>
...
namespace q = cycfi::q;
using namespace q::literals;

float gain;                                               // set by the user
...
q::smoothed<q::one_pole_lowpass> smooth{10_ms, sps, 1e-4f};    (1)

for (auto& s : in)
   s *= smooth(gain);                                          (2)

if (smooth.settled())                                          (3)
{
   // Do something, eg. reporting back to the UI.
}
1 Construct a smoothed value with a 10 ms time constant. The output snaps to the target within 1e-4.
2 Smooth the gain and apply it to the sample. Once the gain reaches its target, smooth returns it exactly.
3 Check whether the glide is over, for example at the end of each block.
