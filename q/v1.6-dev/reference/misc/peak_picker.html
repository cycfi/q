Peak Picker

Overview

Peak picking finds the maxima of a signal and selects the meaningful ones. It recurs throughout DSP: the spacing between successive peaks is a period, and so a pitch; a peak in an onset or novelty signal marks a note attack; a crest is the amplitude of the signal; pitch marks placed at peaks anchor the overlap-add of time stretching and pitch shifting; and the peaks of a spectrum are the partials of a tone. A signal has many maxima. The picker selects among them causally, with no lookahead, as the samples arrive.

peak_picker marks the local maxima of a signal. It locates each maximum from a first_difference sign change: when the slope turns from rising to falling, the previous sample was the peak. The latency is one sample, the least for a causal picker, and the picker reports the exact apex amplitude. The maximum is strict, the slope going from positive to negative. A flat sample (a zero slope) keeps the previous direction, so a plateau top gives one peak, at its last sample, and a flat spot on a descent gives none.

Figure 1. On an exponentially decaying sine, the bare picker marks one local maximum per cycle, each at the exact crest amplitude.

Each call returns a pick: a hit flag, true on the sample a maximum is confirmed, and a const reference to the state of the picker, peak_info, which holds the exact apex amplitude amp and the current sample s.

The picker reports every local maximum. Qualifiers composed around it select among them. A qualifier runs on every sample and returns the pick, with hit cleared to reject the peak. A qualifier that compares a peak with a running measure (a level, a slope) takes the measure as a further argument, from a follower the caller runs. The picker and a qualifier nest:

#include <q/fx/peak_picker.hpp>
#include <q/fx/envelope.hpp>
...
namespace q = cycfi::q;

q::peak_picker pk;                        // the picker
q::peak_gate gate{2.0f};                  // a qualifier
q::true_rms_envelope_follower rms{512};   // the follower the caller runs
float s;                                  // the input sample
...
gate(pk(s), rms(s));

The library has three qualifiers: Peak Gate, Peak Minimum Slope and Peak Z-Score. Other qualifiers can be added without changing the picker.

You will usually write your own qualifiers, specialized to your use case. A qualifier is a function object that takes a pick, plus any running measure it compares against, and returns a pick. See Qualifier.

The picker is single-sided: it finds the maxima of its input. Run one on +s and another on -s to mark both lobes of a waveform. It does not gate on silence, and it holds no sample position. The caller keeps the time line: a span between marks is a difference, so the one-sample offset cancels.

#include <q/fx/peak_picker.hpp>

struct peak_info
{
   float             s = 0.0f;      // current sample
   float             amp = 0.0f;    // apex amplitude of the latest maximum

struct pick
{
   bool              hit;           // a maximum was confirmed on this sample

class peak_picker
{

   pick              operator()(float s);

   void              reset();
};

Example

Get the apex amplitude of each local maximum of the input samples in:

namespace q = cycfi::q;

auto pk = q::peak_picker{};                               (1)
float apex = 0;

{
   if (auto r = pk(s); r.hit)                             (2)
      apex = r.info.amp;                                  (3)
}

Qualifier

qualifier is the concept a peak picker qualifier satisfies: a function object whose first argument is a pick, followed by any running measures, and that returns a pick. It passes the pick on unchanged, or with hit cleared to reject the peak. It does not change the state of the picker.

Include

#include <q/fx/peak_picker.hpp>

Declaration

template <typename Q, typename... T>
concept qualifier =
   requires (Q q, pick p, T... t)
   {
      { q(p, t...) } -> std::same_as<pick>;
   };

Peak Gate

peak_gate keeps a peak only if its apex is above ratio times a reference level given at the call. The level sets the behavior:

  • 0 keeps only the peaks above zero, and drops the shallow maxima a single-sided picker finds in the negative excursions of a bipolar signal.

  • A slow peak envelope gives a bar that tracks a note as it decays.

  • The RMS over a fundamental period gives one landmark per cycle on a sustained tone.

  • A moving average of |s| does the same with less computation.

ratio is the minimum crest factor (apex over level). A higher ratio is more selective. The test is strict (apex > bar), so a level of 0 keeps the peaks above zero.

Figure 2. A window of a real guitar staccato through a conditioner with the clip and compressor bypassed. peak_gate at level 0 keeps the dominant positive crest of each cycle (filled) and drops the shallow maxima in the negative excursions (hollow), leaving one clean landmark per cycle as the note decays.

Figure 2 shows peak_gate at level 0 on the output of a Signal Conditioner with the clip and compressor bypassed (basic_signal_conditioner<sc_bypass::clip | sc_bypass::compressor>): denoised, with crest shapes and timing intact. The gate keeps the positive crest of each cycle and drops the shallow maxima in the negative excursions.

For a sustained periodic signal, the RMS is the steadiest level reference: the peak envelope wobbles with the crest phase. With the RMS over a fundamental period, the bar rides the note level, below the crests, and the gate marks one crest per cycle, without the creep of a z-score bar. In Figure 3, the RMS runs over a window of a low E note through a conditioner with the clip and compressor bypassed. The gate on the RMS over one period:

#include <q/fx/peak_picker.hpp>
#include <q/fx/envelope.hpp>
...
namespace q = cycfi::q;

float f0;                      // the fundamental frequency, in Hz
float sps;                     // samples per second
float s;                       // the input sample
...
q::peak_picker                 pk;
q::peak_gate                   gate{2.0f};
q::true_rms_envelope_follower  rms{q::frequency{f0}.period(), sps};

// Per sample:
auto r = gate(pk(s), rms(s));
Figure 3. A window of a low E note through a conditioner with the clip and compressor bypassed. The bar (amber) is twice the RMS over one period; it rides the note level and stays below the crests, so peak_gate on the RMS keeps the fundamental crest of each cycle (filled) and drops the harmonic humps (hollow).

A moving average of |s| costs less than the RMS: an abs and a moving average update per sample, with no square and no square root. The mean of |s| runs a little under the RMS (for a sine, 2/pi against 1/sqrt(2) of the amplitude), so use a slightly higher ratio for the same one-per-cycle result.

Example

Get the crests above zero of the input samples in, and mark each crest amplitude:

#include <q/fx/peak_picker.hpp>
...
namespace q = cycfi::q;

void mark(float amp);               // takes each crest amplitude
...
auto pk = q::peak_picker{};
auto pos = q::peak_gate{1.0f};                            (1)

for (auto s : in)
{
   auto r = pos(pk(s), 0.0f);                             (2)
   if (r.hit)
      mark(r.info.amp);
}
1 Construct a peak_gate with a ratio of 1. At a level of 0, the ratio has no effect.
2 Pick the local maxima of the sample, and keep the ones above 0.

Peak Minimum Slope

peak_min_slope keeps a peak only where the signal climbs steeply into it, comparing a slope given at the call with a threshold. A slowly varying wave does not rise fast enough to pass, and a fast one does. In Figure 4, a low, slow wave crossfades into a high, fast one: the slow crests are passed over and the fast crests kept.

Figure 4. A quick crossfade from a low, slow wave to a high, fast one. peak_min_slope keeps a peak only where the signal climbs steeply enough, so the slow crests (hollow) are passed over and the fast ones (filled) kept.

Peak Z-Score

peak_z_score keeps a peak only when its apex stands more than threshold standard deviations above a moving mean of the signal, over a trailing window lag. The mean and the spread follow the signal, so the bar follows a noisy or wandering baseline. Use it for peaks that stand out from a background. The crests of a sustained oscillation sit about 1.4 deviations above their own mean, and fall under the bar as the window fills.

influence (0 to 1) sets how much a sample above the bar feeds the baseline. Near zero, peaks leave the mean and spread unchanged, so a burst of events does not raise the bar and hide the ones that follow.

peak_z_score keeps its own moving mean and mean of squares over lag. The other two qualifiers hold no state.

Figure 5. A band-limited noise floor with louder events on top. peak_z_score keeps the apexes that stand several deviations above the running mean (filled) and rejects the noise-floor maxima (hollow).

After the real-time z-score peak detector by Jean-Paul van Brakel.
