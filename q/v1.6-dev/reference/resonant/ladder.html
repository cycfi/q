Ladder Filter

Overview

The ladder filter is N topology-preserving one-pole lowpasses in series, wrapped in a global resonance feedback loop. It is implemented by a class template named basic_ladder, the base of Moog Ladder Filter and OTA Ladder Filter, which differ only in the cell.

basic_ladder has two template parameters:

  • The cell, what a real filter of this shape does to the signal. A transistor ladder saturates symmetrically and adds odd harmonics; a variable gain (OTA) cell of the kind Curtis built runs off center and adds second harmonic. See OTA Ladder Filter for the data sheet figures.

  • The pole count, N, 4 by default. Four poles give the classic 24 dB per octave voice. Two poles give the brighter setting that the OB-Xa offers on the same filter chip.

When the cell is linear, the instantaneous (zero-delay) feedback is resolved analytically, so the filter is exact and stays stable and free of zipper noise under per-sample cutoff modulation, as does the State Variable Filter. See Vadim Zavalishin’s The Art of VA Filter Design and Will Pirkle’s Designing Software Synthesizer Plug-Ins in C++.

Resonance and the Pole Count

Resonance is a normalized r in [0, 1], where 1 is self-oscillation. The feedback gain k at self-oscillation depends on the pole count, and the filter computes it: the loop’s phase reaches 180 degrees where N atan(w/wc) = pi, so at w/wc = tan(pi/N), and the chain’s gain there is cos(pi/N)^N. Below three poles there is no self-oscillation point to normalize to: those take the four-pole scale, k = 4r, and r sets the feedback amount.

Figure 1. The same filter at two, four and six poles, cutoff 1 kHz, no resonance. The dashed lines are the analog prototypes, (1 + (w/wc)²)^(-N/2) at the prewarped ratio; the measured response tracks them and steepens near Nyquist as the bilinear warping bends the curve.

Cells

The Cell type provides two member functions:

bool     linear() const;
float    input(float x, float k, float y) const;

When linear() is true, the filter resolves the zero-delay feedback exactly. Otherwise, input gives what the N stages are fed, from the input sample x, the feedback gain k and the previous output y. A nonlinear cell thus works from the previous output: a one-sample delay in the nonlinearity alone, while the stages stay TPT. This is the standard inexpensive nonlinear ladder.

The one-sample delay adds phase to the loop, so a nonlinear cell reaches self-oscillation before r = 1 once the cutoff is a large fraction of the sample rate: above a cutoff of about fs/3.5 at r = 0.4, fs/8 at r = 0.6, and fs/30 at r = 0.8. Below r = 0.3 it does not happen. The output stays bounded either way. The linear path is exact and has no such limit.

Q provides two cells: moog_cell, a tanh in the feedback path that can be switched off, used by Moog Ladder Filter; and ota_cell, an asymmetric curve on the sum of the input and the feedback, used by OTA Ladder Filter. Either cell takes any pole count: basic_ladder<moog_cell, 2> is a two-pole Moog ladder.

Include

#include <q/fx/ladder.hpp>

Declaration

template <typename Cell, std::size_t N = 4>
struct basic_ladder
{
   using cell_type = Cell;
   static constexpr std::size_t poles = N;

                  basic_ladder(frequency f, float sps, float reso = 0.0f);

   static float   k_limit();

   float          operator()(float x);

   void           cutoff(frequency f, float sps);
   void           resonance(float r);
   void           config(frequency f, float sps, float r);

   Cell&          cell();
   Cell const&    cell() const;

   basic_ladder&  operator=(float y);
};

Example

Filter the input samples in, at sps samples per second, through a two-pole and a four-pole version of the same filter with the OTA cell, the switch the OB-Xa has on its front panel:

#include <q/support/literals.hpp>  // For the literals

namespace q = cycfi::q;
using namespace q::literals;

auto bright = q::basic_ladder<q::ota_cell, 2>{1_kHz, sps, 0.4f};         (1)
auto fat = q::basic_ladder<q::ota_cell, 4>{1_kHz, sps, 0.4f};

bright.cell().drive(1.5f);                                                 (2)
fat.cell().drive(1.5f);

for (auto s : in)
{
   auto y2 = bright(s);                                                    (3)
   auto y4 = fat(s);
   // Use y2 or y4
}
1 Construct a two-pole and a four-pole ladder with the OTA cell, a cutoff of 1 kHz and a resonance of 0.4.
2 Set the drive of each cell.
3 Process the sample through each filter.

Moog Cell

The cell of a transistor ladder: a tanh saturation in the feedback path, symmetric, so it adds odd harmonics. It is linear until switched on.

OTA Cell

The variable gain (OTA) cell of the Curtis CEM3320 and its kin. It runs off center, so it adds mostly second harmonic, and it shapes the sum of the input and the feedback. See OTA Ladder Filter for the harmonic figures.
