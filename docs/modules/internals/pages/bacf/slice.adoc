= bacf_slice

The signal since the last drop, for the xref:bacf/lag_tracker.adoc[BACF lag
tracker]: when it began, its hint, its strongest pulse, and the window a
score may run over.

== Include

```c++
#include <q/pitch/detail/bacf_slice.hpp>
```

== Declaration

```c++
namespace cycfi::q::detail
{
   class bacf_slice
   {
   public:

                           bacf_slice(
                              std::uint32_t window
                            , std::uint32_t min_window
                           );

      void                 drop(std::uint32_t now, float hint);
      void                 reset();
      void                 observe(bacf_pulse const& p);

      bool                 after(std::uint32_t t) const;
      float                hint() const;
      float                peak() const;
      std::uint32_t        one_lag(std::uint32_t lag) const;
      std::uint32_t        window(std::uint32_t lag, std::uint32_t now) const;
      bool                 ready(std::uint32_t lag, std::uint32_t now) const;
   };
}
```

== The slice

`drop(now, hint)` begins a slice at `now` on the sample clock, stores
`hint`, the last good lag before it in samples (0 for none), and sets the
peak to 0. `observe(p)` takes each completed pulse: if `after(p.lead)`, the
peak becomes the larger of the two. `after(t)` is
`std::int32_t(t - drop) >= 0` once there is a drop: the difference on the
wrapping clock, true for a time up to 2^31^ samples after the drop.

Before any drop, and after `reset()`, there is no slice: `after()` is false
for every time, `window()` is the full window and `ready()` is true, at any
clock value. A flag says whether a drop has been made; `drop()` sets it and
`reset()` clears it, with the hint and peak.

== The window

A score at `lag` compares the latest bits of a window with those `lag`
earlier (see xref:bacf/bitstream.adoc[`bacf_bitstream`]), so it reaches
back the window, the lag and up to a word. Until all of that is after the
drop, a full window would mix the slice with what came before it. With
`since = now - drop`:

* `one_lag(lag)`: `max(lag, min_window)`, rounded up to whole words. The
  tracker's `min_window` is 2 ms.
* `window(lag, now)`: with no drop, the full window. Otherwise, if
  `since < lag + word_size`, `one_lag(lag)`.
  Else, with `clear = floor((since - lag - word_size) / word_size) *
  word_size`, the full window if `clear >= window`, else `one_lag(lag)`.
  So the full window from `since = window + lag + word_size` on.
* `ready(lag, now)`: with no drop, true. Otherwise `since >= one_lag(lag) +
  lag + word_size`: one lag of the slice can be scored.
