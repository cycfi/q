= bacf_bitstream

The front end of the xref:bacf/follower.adoc[BACF follower]: the
bitstream, its edges and pulses, and the score.

== Include

```c++
#include <q/pitch/detail/bacf_bitstream.hpp>
```

== Declaration

```c++
namespace cycfi::q::detail
{
   struct bacf_pulse
   {
      std::uint32_t        lead;
      float                peak;
      float                width;
   };

   bool                    similar(bacf_pulse const& a, bacf_pulse const& b);

   class bacf_bitstream
   {
   public:

      enum edge_kind { leading, trailing };
      using edge_list = bacf_list<std::uint32_t>;
      using pulse_list = bacf_list<bacf_pulse>;

      static constexpr std::size_t  word_size = bitset<>::value_size;
      static constexpr float        width_level = 0.3f;

                           bacf_bitstream(
                              float hysteresis
                            , std::size_t history
                            , std::size_t capacity
                           );

                           template <typename F>
      void                 operator()(float s, F&& on_edge);

      std::uint32_t        now() const;
      std::size_t          history() const;
      bool                 has(std::uint32_t lag, std::uint32_t w) const;
      std::uint32_t        mismatch(std::uint32_t lag, std::uint32_t w) const;
      edge_list            edges(edge_kind k) const;
      pulse_list           pulses() const;
      void                 reset();
   };
}
```

== The bitstream

The comparator starts low. At each sample `s`, it goes high when it is low
and `s > hysteresis`, and low when it is high and `s < -hysteresis`; between
the two it keeps its state. The follower sets `hysteresis` to -45 dB (0.0056).

`history` is rounded up to whole words, `keep`. The bits go into a `bitset`
of `2 * keep + word_size` bits, one a sample, at the next free position.
When `2 * keep` bits are stored, at the start of the next sample, the
latest `keep` (the second half) are moved to the start and the rest is
cleared, so the next bit goes at `keep`. A move of whole words keeps every
bit's position within its word: a bit's position in its word is its sample
index modulo `word_size`, always. `word_size` is the platform's natural
word, 64 bits on a 64-bit host, 32 on an ARM Cortex-M.

`history()` counts the bits stored since construction or `reset()`,
saturating at `keep`. `has(lag, w)` is `history() >= w + lag + word_size`.

== Edges and pulses

A leading edge is the sample where the comparator goes high, a trailing edge
the sample where it goes low. Their times on the sample clock go into two
rings, one per kind, and each completed pulse into a third; each ring holds
`capacity` entries, and its count saturates there. `edges(k)` and
`pulses()` list them newest first.

A pulse is measured over the samples where the comparator is high:

* `lead`: the leading edge's time.
* `peak`: the largest sample, starting from the leading edge's own.
* `width`: set once, at the first sample, from the leading edge on, that is
  under `width_level` (30%) of the peak so far: `width = t - lead`. If no
  sample is, it is set at the trailing edge, to that edge's `t - lead`. It
  says how soon the pulse falls from its peak, not how long the signal stays
  above zero.

`similar(a, b)` holds when `|a.peak - b.peak| <= 0.4 * max(a.peak, b.peak)`
and `|a.width - b.width| <= 0.15 * max(a.width, b.width)` (`rel_within`;
the width tolerance is `1 - zero_crossing_collector::pulse_width_diff`).
The lock and the provisional use it; the provisional's page gives the
reasons for both tolerances and a worked example.

== One sample

`bits(s, on_edge)`, in order:

. If `2 * keep` bits are stored, the move above.
. A crossing: at a leading edge, the pulse in progress starts (`lead` and
  `peak` this sample, `width` 0), `on_edge(leading)` runs, then the edge's
  time goes into its ring. At a trailing edge, the pulse's width is set if
  it is not yet, the pulse goes into the pulse ring, `on_edge(trailing)`
  runs, then the edge's time goes into its ring.
. While high, the pulse's peak and width are updated with this sample.
. The sample's bit is stored, `now()` advances by one, `history()` by one
  up to `keep`.

So in `on_edge`, `now()` is the edge's sample, `pulses()` already holds the
pulse a trailing edge ends, `edges(k)` does not yet hold this edge, and the
history ends at the sample before. The callback is a template parameter,
inlined. `now()` is a `std::uint32_t` from construction; `reset()` does not
restart it, and it wraps.

== The score

`mismatch(lag, w)`, with `w` a whole number of words and `p` the position
of the next bit: `start = floor((p - w - lag) / word_size) * word_size`,
and the result is the number of `i` in `[0, w)` where bit `start + i`
differs from bit `start + lag + i`. The bits must reach back `w + lag`
(`w + lag <= p`, asserted in debug builds); the owner sizes the history
for the furthest score it makes. The later window ends between
`word_size - 1` bits before the latest bit and the latest bit itself, and
the earlier one `lag` before it. `bitstream_acf` counts it a word at a time
with XOR and popcount.

== Reset

`reset()` clears the bits, the three rings' counts, the bit position and
`history()`, and sets the comparator low. The pulse in progress is not
cleared; with the comparator low, the next leading edge overwrites it. The
clock runs on.

== Tests

`test/pitch/detail/bacf_bitstream.cpp`:

* edges at the hysteresis crossings, reported at their sample, with the
  history and clock at the callback, and the edge ring's order;
* pulse lead, peak and width, with and without a fall under 30%;
* `mismatch()` against a count one bit at a time, at five lags and three
  windows, through many slides of the history;
* `history()`, `has()` and `reset()`;
* `similar()` at the edges of its tolerances.
