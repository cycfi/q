= Q Internals

These pages are for developers working on Q itself. They describe how the
implementation is put together: the classes in `detail` namespaces that the
public classes are built from, their state, the invariants they keep, and how
they are tested. None of it is public API, and it changes with the
implementation.

The public documentation does not link here; this page is the entry point.
