= QPlug Tutorials

include::../common.adoc[]

== Overview

These tutorials walk through the examples that come with QPlug, from the
simplest to the most involved. Each one is a complete plugin in its own
directory under `example/q_plug/`, built in every format its platform has,
and each page quotes the example's own code.

Every example has the same shape: the three parts described in
{architecture}, each a header and a source file, the file that makes them,
and the build.

----
example/q_plug/<name>/
   CMakeLists.txt         the implementation library and the formats
   <name>_processor.hpp   the DSP
   <name>_processor.cpp
   <name>_controller.hpp  the parameters
   <name>_controller.cpp
   <name>_presenter.hpp   the editor
   <name>_presenter.cpp
   <name>.cpp             make_controller, make_processor, make_presenter
                          and info
   resources/             the images the editor draws, when it has any
----

The examples are built with everything else (see {setup}), and every one
lands in `cmake-build-debug/products/`:

[,sh]
----
cmake -B cmake-build-debug -G Ninja -DCMAKE_BUILD_TYPE=Debug -DQ_BUILD_PLUG=ON
cmake --build cmake-build-debug
----

== The Path

Start with {tutorial-gain}. It has one parameter, and every piece a plugin
is made of appears in it once. The Anna tutorials then build one
polyphonic synthesizer in five stages, each a complete plugin and each
built on the one before, so read them in order: a later page explains
only what its stage adds. Dexter closes the series: a DX7 style FM synth
that uses everything the Anna stages cover, with Q's FM engine inside.

[cols="1,2,2", options="header"]
|===
| Tutorial | What it demonstrates | Key parts

| {tutorial-gain}
| A mono gain with one automatable volume and a console fader for it
| `processor`, `controller`, `presenter`, `parameter`, `plugin_info`

| {tutorial-anna-1}
| A sawtooth through an envelope, sixteen voices, played from a keyboard
| `midi_processor`, times on a log taper, `bind` with a parameter's taper

| {tutorial-anna-2}
| A resonant low-pass with its own contour, and key tracking
| Q's `svf`, a frequency parameter, a second envelope

| {tutorial-anna-3}
| A chorus over the whole instrument
| Q's fractional `delay` and `sin_cos_gen`, an effect of the plugin's own

| {tutorial-anna-4}
| Envelopes drawn and dragged instead of set with sliders
| Elements' `curve_editor`, `x_of` and `y_of`

| {tutorial-anna-5}
| Factory presets, and the standard header to choose them
| `factory_presets.json`, `make_header`

| {tutorial-dexter}
| A six operator FM synth that plays DX7 patches and cartridges
| 145 parameters as a `dx_patch`, decks, drawn curves, `drop_box`
|===
