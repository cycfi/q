== Overview

These tutorials walk through the examples that come with QPlug, from the
simplest to the most involved. Each one is a complete plugin in its own
directory under `example/q_plug/`, built in every format its platform has,
and each page quotes the example's own code.

Every example has the same shape: the three parts described in
{architecture}, each a header and a source file, the file that makes them,
and the build.

----
example/q_plug/<name>/
   CMakeLists.txt         the implementation library and the formats
   <name>_processor.hpp   the DSP
   <name>_processor.cpp
   <name>_controller.hpp  the parameters
   <name>_controller.cpp
   <name>_presenter.hpp   the editor
   <name>_presenter.cpp
   <name>.cpp             make_controller, make_processor, make_presenter
                          and info
   resources/             the images the editor draws, when it has any
----

The examples are built with everything else (see {setup}), and every one
lands in `cmake-build-debug/products/`:

[,sh]
----
cmake -B cmake-build-debug -G Ninja -DCMAKE_BUILD_TYPE=Debug -DQ_BUILD_PLUG=ON
cmake --build cmake-build-debug
----
