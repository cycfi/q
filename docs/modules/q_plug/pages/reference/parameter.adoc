= Parameters

include::../common.adoc[]

== Overview

A `parameter` declares one of a plugin's parameters as presented to the host:
its id, its name, its kind, its range, its initial value, and how the host
is to treat it. A {controller} declares all of its parameters in one static
array and returns it from `parameters()`. This is the whole list of the
`delay` example:

[source,c++]
----
#include <q_plug/controller.hpp>
...
namespace q_plug = cycfi::q_plug;
using namespace cycfi::q::literals;

class delay_controller : public q_plug::controller
{
public:

   static constexpr cycfi::q::duration max_delay = cycfi::q::duration{1.0};
   parameter_list       parameters() const override;
   ...
};

using parameter_list = delay_controller::parameter_list;
...
parameter_list delay_controller::parameters() const
{
   static parameter params[] =
   {
      parameter{ 1, "Delay", 350_ms }.range(0.0, max_delay.rep),
      parameter{ 2, "Feedback", 50.0 }.range(0.0, 100.0).unit("%")
   };

   return { params };
}
----

The constructor takes the id, the name and the initial value, and the type
of the initial value picks the kind: `350_ms` makes a duration, `50.0` a
plain number. The modifiers that follow, `range` and `unit` here, each
return a changed copy, so a declaration reads as one expression.

The id is the parameter's identity for the life of the plugin. The host
automates the parameter by it, and a saved state is matched to the
parameter by it, or failing that by its name. Never reuse an id and never
change one, even for a parameter that has been retired. The plugin's own
code addresses a parameter by its index in the list instead, and QPlug
translates between the two.

A value is a plain `double` in the parameter's own units: a decibel
parameter holds decibels, a duration holds seconds. The host is given those
values and that range. The kind defines what the number means: how it reads
as text, whether the host treats it as stepped, and which {cpp} type the
controller returns it as.

A control works in its own travel, from 0 to 1, and the parameter maps
between the two, linearly, or logarithmically with `log`.

== parameter

=== Include

```c++
#include <q_plug/parameter.hpp>
```

=== Declaration

```c++
struct parameter
{
   enum type
   {
      bool_, int_, double_, note, frequency, decibel, duration, enum_
   };
   using id_type = std::uint32_t;

                        template <std::floating_point T>
   constexpr            parameter(id_type id, char const* name, T init);

                        template <std::integral T>
   constexpr            parameter(id_type id, char const* name, T init);

   constexpr            parameter(id_type id, char const* name
                         , q::midi_1_0::note init);
   constexpr            parameter(id_type id, char const* name
                         , q::frequency init);
   constexpr            parameter(id_type id, char const* name
                         , q::duration init);
   constexpr            parameter(id_type id, char const* name
                         , q::decibel init);

   // An enumeration: names is null terminated, the value is the index.
   constexpr            parameter(id_type id, char const* name, int init
                         , char const* const* names);

   // Each returns a copy with one thing changed, so they chain.
                        template <typename T>
   constexpr parameter  range(T min, T max) const;
   constexpr parameter  log() const;
   constexpr parameter  unit(char const* unit_) const;
   constexpr parameter  module(char const* module_) const;
   constexpr parameter  dont_automate() const;
   constexpr parameter  dont_save() const;
   constexpr parameter  live() const;
   constexpr parameter  hidden() const;
   constexpr parameter  bypass() const;
   constexpr parameter  periodic() const;

   constexpr id_type             id() const;
   constexpr char const*         name() const;
   constexpr type                kind() const;
   constexpr double              init() const;
   constexpr double              min() const;
   constexpr double              max() const;
   constexpr char const*         unit() const;
   constexpr char const*         module() const;
   constexpr char const* const*  names() const;
   constexpr bool                is_automatable() const;
   constexpr bool                is_saved() const;
   constexpr bool                is_live() const;
   constexpr bool                is_hidden() const;
   constexpr bool                is_bypass() const;
   constexpr bool                is_periodic() const;
   constexpr bool                stepped() const;
   constexpr bool                logarithmic() const;

   // The GUI control's travel, 0 to 1, from a value and back.
   double               position(double value) const;
   double               value(double position_) const;

   // Text for a value, and a value from text, in the parameter's units.
   // Returns false if the buffer is too small or the text unreadable.
   bool                 to_text(double val, char* text
                         , std::size_t size) const;
   bool                 from_text(char const* text, double& val) const;
};
```

=== Expressions

==== Notation

`p`, `a`, `b`        :: Objects of type `parameter`.
`id`                 :: Object of type `parameter::id_type`, the id.
`name`, `str`        :: Null terminated strings.
`f`                  :: A floating point value.
`n`                  :: An integral value other than `bool`.
`sw`                 :: A `bool`.
`k`                  :: Object of type `q::midi_1_0::note`.
`hz`                 :: Object of type `q::frequency`.
`d`                  :: Object of type `q::duration`.
`db`                 :: Object of type `q::decibel`.
`i`                  :: An `int`, an index into `names`.
`names`              :: A null terminated array of null terminated strings.
`x`, `y`             :: Values of one numeric type, in the parameter's units.
`v`                  :: A `double`, a value in the parameter's units.
`pos`                :: A `double`, a position along a control's travel.
`buf`, `size`        :: A `char` buffer and its size.

==== Type Definitions

[cols="1,1,1"]
|===
| Expression               | Semantics                          | Type

| `parameter::type`        | Get the kind type.                 | `enum type`
| `parameter::id_type`     | Get the id type.                   | `std::uint32_t`
|===

==== Constructors and Assignment

The type of the initial value picks the kind, and with it a range to start
from. `range` replaces that with the plugin's own.

[cols="1,1"]
|===
| Expression                       | Semantics

| `parameter(id, name, f)`         | Construct a plain number, kind
                                     `double_`. The range is 0 to 1,
                                     widened to take in `f`.
| `parameter(id, name, sw)`        | Construct a switch, kind `bool_`: 0
                                     is off and 1 is on.
| `parameter(id, name, n)`         | Construct a whole number, kind
                                     `int_`. The range is 0 to 1, widened
                                     to take in `n`.
| `parameter(id, name, k)`         | Construct a
                                     xref:ROOT:reference/midi/notes.adoc[MIDI note],
                                     kind `note`, from A0 (21) to G9 (127).
| `parameter(id, name, hz)`        | Construct a frequency in hertz, kind
                                     `frequency`, from 15 Hz to 20 kHz.
| `parameter(id, name, d)`         | Construct a duration in seconds, kind
                                     `duration`, from 0 to 1 s.
| `parameter(id, name, db)`        | Construct a level in decibels, kind
                                     `decibel`, from -60 to +12 dB.
| `parameter(id, name, i, names)`  | Construct a choice, kind `enum_`. The
                                     value is an index into `names`, from 0
                                     to one less than the number of names.
| `parameter(p)`                   | Copy construct from `parameter p`.
| `a = b`                          | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used.

NOTE: A parameter keeps the pointers it is given, not copies of the
strings, so `name`, `names`, and the strings given to `unit` and `module`
must outlive it. String literals and static arrays do.

==== Modifiers

[cols="1,1,1"]
|===
| Expression               | Semantics                          | Return Type

| `p.range(x, y)`          | Set the range to `x` through `y`,
                             and clamp the initial value into
                             it.                                | `parameter`
| `p.log()`                | Set a logarithmic taper for the
                             control. See <<_taper>>.           | `parameter`
| `p.unit(str)`            | Set the unit. An `int_` or a
                             `double_` value is written with it,
                             such as `50 %`; the other kinds
                             write their own.                   | `parameter`
| `p.module(str)`          | Set the group the host may show the
                             parameter under. A `/` in `str`
                             separates the levels of a tree.    | `parameter`
| `p.dont_automate()`      | Mark the parameter as not
                             automatable: the host neither
                             records nor plays back automation
                             for it.                            | `parameter`
| `p.dont_save()`          | Leave the parameter out of a
                             preset. The host's session keeps
                             it.                                | `parameter`
| `p.live()`               | Mark the parameter as read by the
                             processor as it is used: a change to
                             it does not call the processor's
                             `parameters_changed`.              | `parameter`
| `p.hidden()`             | Mark the parameter as hidden from
                             the host, as for one not in use.   | `parameter`
| `p.bypass()`             | Mark the parameter as the plugin's
                             bypass, so the host can merge it
                             with its own bypass button.        | `parameter`
| `p.periodic()`           | Mark the parameter as periodic: its
                             value wraps around, as a phase
                             does.                              | `parameter`
|===

Each modifier returns a copy of `p` with one thing changed, so they chain.
The Anna examples declare their envelope times this way:

[source,c++]
----
#include <q_plug/parameter.hpp>
...
using cycfi::q_plug::parameter;
using namespace cycfi::q::literals;

static parameter params[] =
{
   parameter{1, "Attack", 20_ms}
      .range((1_ms).rep, (10_s).rep).log().unit("s")
 , parameter{2, "Decay", 300_ms}
      .range((1_ms).rep, (10_s).rep).log().unit("s")
 , parameter{3, "Sustain", 50.0}.range(0.0, 100.0).unit("%")
 , parameter{5, "Release", 500_ms}
      .range((1_ms).rep, (10_s).rep).log().unit("s")
   ...
};
----

Attack reads left to right: a duration starting at 20 ms, its range set to
1 ms through 10 s, on a logarithmic taper, with `s` as its unit. Each call
works on the copy the one before it returned, and the last copy is what
goes into the array.

`range` takes plain numbers in the parameter's units, so a Q unit is given
as its `.rep`, as in `range((1_ms).rep, (10_s).rep)`.

A host treats a bypass as a switch from 0, off, to 1, on. Declare it with a
`bool` initial value, which is exactly that:
`parameter{id, "Bypass", false}.bypass()`.

NOTE: A parameter marked `dont_save` belongs to the session. The host's
saved session carries it, as CLAP expects of every parameter; a preset
does not, so loading a preset sets it to its default. An operator's mute
in an FM synth is one: a session remembers which operators were off, and
any preset turns them all back on.

==== Accessors

[cols="1,1,1"]
|===
| Expression               | Semantics                          | Return Type

| `p.id()`                 | Get the id.                        | `parameter::id_type`
| `p.name()`               | Get the name the host shows.       | `char const*`
| `p.kind()`               | Get the kind.                      | `parameter::type`
| `p.init()`               | Get the initial value, which the
                             host also takes as the default.    | `double`
| `p.min()`                | Get the bottom of the range.       | `double`
| `p.max()`                | Get the top of the range.          | `double`
| `p.unit()`               | Get the unit, empty unless the
                             kind or `unit` gave one.           | `char const*`
| `p.module()`             | Get the module, empty unless
                             `module` gave one.                 | `char const*`
| `p.names()`              | Get an `enum_` parameter's names,
                             null for the other kinds.          | `char const* const*`
| `p.is_automatable()`     | Check whether the host may automate
                             the parameter: true unless
                             `dont_automate`.                   | `bool`
| `p.is_saved()`           | Check whether a preset saves the
                             parameter: true unless
                             `dont_save`.                       | `bool`
| `p.is_live()`            | Check whether the parameter is
                             marked `live`.                     | `bool`
| `p.is_hidden()`          | Check whether the parameter is
                             marked `hidden`.                   | `bool`
| `p.is_bypass()`          | Check whether the parameter is
                             marked `bypass`.                   | `bool`
| `p.is_periodic()`        | Check whether the parameter is
                             marked `periodic`.                 | `bool`
| `p.stepped()`            | Check whether the host treats the
                             parameter as stepped: true for the
                             kinds `bool_`, `int_`, `note` and
                             `enum_`.                           | `bool`
| `p.logarithmic()`        | Check whether the logarithmic taper
                             applies: `log` was applied, and the
                             range starts above zero.           | `bool`
|===

A {presenter} reads what it needs from the parameter itself, such as the
range for a scale. The `gain` example builds its fader's scale this way:

[source,c++]
----
#include <q_plug/presenter.hpp>
#include <elements.hpp>
...
namespace q_plug = cycfi::q_plug;
using namespace cycfi::elements;

struct gain_controller : q_plug::controller
{
   parameter const&     volume_param() const;
   ...
};
...
class gain_presenter : public q_plug::presenter
{
   ...
   void on_attach(cycfi::elements::view& view_) override
   {
      auto const& param = _ctl.volume_param();
      db_scale scale{param.min(), param.max()};
      ...
   }

   gain_controller&     _ctl;
};
----

An `enum_` is declared to the host as an enumeration, so the host can show
the names.

==== Taper

[cols="1,1,1"]
|===
| Expression           | Semantics                              | Return Type

| `p.position(v)`      | Get the position along a control's
                         travel, 0 to 1, for the value `v`,
                         clamped into the range first.          | `double`
| `p.value(pos)`       | Get the value at the position `pos`,
                         clamped into 0 to 1 first.             | `double`
|===

The two are inverses. A {presenter}'s `bind` takes a mapping with
`position` and `value`, and a parameter is one, as in the `delay` example:

[source,c++]
----
#include <q_plug/presenter.hpp>
#include <elements.hpp>
...
namespace q_plug = cycfi::q_plug;
using namespace cycfi::elements;

struct delay_controller : q_plug::controller
{
   enum { delay_id, feedback_id };
   ...
};
...
class delay_presenter : public q_plug::presenter
{
   ...
   void on_attach(cycfi::elements::view& view_) override
   {
      auto const& params = ctrl().parameters();
      auto const& delay_param = params[delay_controller::delay_id];
      auto const& feedback_param = params[delay_controller::feedback_id];
      auto delay_dial = share(dial(basic_knob<60>()));
      auto feedback_dial = share(dial(basic_knob<60>()));
      ...
      // Each control's travel is 0 to 1; the parameter maps it to its own
      // range, so a dial needs nothing but the parameter it belongs to.
      bind(delay_controller::delay_id, delay_dial, delay_param);
      bind(delay_controller::feedback_id, feedback_dial, feedback_param);
      ...
   }
};
----

Two tapers are available, with `min` and `max` the ends of the range:

linear:: The default. `v = min + pos * (max - min)`.

logarithmic:: `v = min * pow(max / min, pos)`. Equal ratios for equal
travel, which is how the ear hears time and pitch: half way along a 1 ms
to 1 s control is 31.6 ms, not half a second.

A ratio needs both ends of the range above zero. Where they are not, `log`
does not apply, and the taper is linear. A level in decibels is already a
ratio, so it stays linear. The Anna examples put the filter on these
tapers:

[source,c++]
----
#include <q_plug/parameter.hpp>
...
using cycfi::q_plug::parameter;
using namespace cycfi::q::literals;

static parameter params[] =
{
   // The filter. Cutoff is heard in ratios, so it runs on a log taper
   // like the times; its range is the audible band rather than four
   // whole decades, so its labels are the frequencies themselves and
   // no travel is spent below hearing. Resonance is a ratio too, four
   // octaves of it. Depth is in octaves, which is what the ear counts,
   // so it is the one control here that is plainly linear.
   parameter{6, "Cutoff", 300_Hz}
      .range((20_Hz).rep, (20_kHz).rep).log()
 , parameter{7, "Resonance", 2.0}.range(0.5, 8.0).log()
 , parameter{8, "Env Depth", 4.0}.range(0.0, 8.0).unit("oct")
   ...
};
----

The taper belongs to the plugin's own editor. The host receives the plain
range, without the taper, so its own controls and automation run linearly
over the range. A presenter is free to bind with another mapping instead
of the parameter, such as the `db_scale` above.

==== Text

[cols="1,1,1"]
|===
| Expression               | Semantics                          | Return Type

| `p.to_text(v, buf, size)`| Write `v` into `buf` as text, in
                             the parameter's units. False if
                             `buf` is too small.                | `bool`
| `p.from_text(str, v)`    | Read a value from `str` into `v`.
                             False if the text cannot be read.  | `bool`
|===

The host calls these to show a value and to take one typed in. Each kind
has its own form:

[cols="1,2,2"]
|===
| Kind          | Written as                    | Read from

| `bool_`       | `On` above 0.5, else `Off`.   | `On` or `on`, or a number
                                                  above 0.5, is on. Anything
                                                  else is off.
| `int_`        | The nearest whole number,
                  then the unit: `50 %`.        | A number, clamped into the
                                                  range.
| `double_`     | Three decimal places, less
                  trailing zeros, then the
                  unit: `0.95`, `50 %`.         | A number, clamped into the
                                                  range.
| `enum_`       | The name at the nearest
                  index.                        | One of the names, exactly.
| `note`        | The note name: `C4` for 60.   | A note name in the range,
                                                  exactly: `C#4`.
| `frequency`   | `440.0 Hz` below 1 kHz,
                  `1.50 kHz` from there.        | A number in hertz, or in
                                                  kilohertz when a `k`
                                                  follows it, clamped.
| `decibel`     | One decimal place: `-6.0 dB`. | A number in decibels,
                                                  clamped.
| `duration`    | `20.0 ms` below 1 s,
                  `1.500 s` from there.         | A number in seconds, or in
                                                  milliseconds when an `m`
                                                  follows it, clamped.
|===

==== Example

Declare the parameters of a small synth, as a {controller}'s `parameters()`
returns them, and write one value as text:

```c++
namespace q_plug = cycfi::q_plug;
using namespace cycfi::q::literals;
using q_plug::parameter;

static char const* const waves[] = {"Sine", "Saw", "Square", nullptr};

static parameter const params[] =
{
   parameter{1, "Volume", 0_dB}.range(-60.0, 6.0),                         <1>
   parameter{2, "Cutoff", 1_kHz}.range((20_Hz).rep, (20_kHz).rep).log(),  <2>
   parameter{3, "Wave", 0, waves},                                        <3>
   parameter{4, "Bypass", false}.bypass()                                  <4>
};

char text[32];
params[1].to_text(params[1].value(0.5), text, sizeof(text));             <5>
```

<1> A level in decibels, its range set to -60 dB through +6 dB.
<2> A frequency from 20 Hz to 20 kHz, on a logarithmic taper.
<3> A choice of three waveforms, starting at `Sine`.
<4> A switch, marked as the plugin's bypass.
<5> Write the cutoff at the middle of the control's travel as text:
    `632.5 Hz`.

== parameter_traits

`parameter_traits<T>` converts between the `double` a parameter holds and
the type the plugin works with. The {controller}'s `get_parameter<T>`,
`set_parameter<T>` and `edit_parameter<T>` go through it, so a {processor}
can read a `q::decibel`, for example. A Debug build asserts that `T`
matches the parameter's kind.

=== Include

```c++
#include <q_plug/parameter.hpp>
```

=== Declaration

```c++
template <typename T>
struct parameter_traits
{
   static constexpr bool   matches(parameter::type t);
   static T                get(double val);
   static constexpr double set(T val);
};
```

`parameter_traits` is specialized for `bool`, `int`, `double`,
`q::decibel`, `q::duration`, `q::frequency` and `q::midi_1_0::note`. The
primary template is declared only.

=== Expressions

==== Notation

`T`                  :: A type `parameter_traits` is specialized for.
`traits`             :: The type `parameter_traits<T>`.
`t`                  :: Object of type `parameter::type`.
`v`                  :: A `double`, a value in the parameter's units.
`val`                :: A value of type `T`.

==== Conversions

[cols="1,1,1"]
|===
| Expression               | Semantics                          | Return Type

| `traits::matches(t)`     | Check whether a parameter of kind
                             `t` converts to `T`.               | `bool`
| `traits::get(v)`         | Convert `v` to `T`.                | `T`
| `traits::set(val)`       | Convert `val` to `double`.         | `double`
|===

[cols="1,1,2"]
|===
| `T`                   | Kinds          | Conversion

| `bool`                | `bool_`        | Above 0.5 is `true`; `true` is 1.
| `int`                 | `int_`,
                          `enum_`        | Rounded to the nearest, halves
                                           away from zero.
| `double`              | `double_`      | Unchanged.
| `q::decibel`          | `decibel`      | Decibels.
| `q::duration`         | `duration`     | Seconds.
| `q::frequency`        | `frequency`    | Hertz.
| `q::midi_1_0::note`   | `note`         | Rounded to the nearest key.
|===
