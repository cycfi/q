= Base

include::../../common.adoc[]

== Overview

`<q/support/base.hpp>` holds the few definitions that belong to no component in particular: a pair of bounds, a view of bytes, the `pi` constant, a `constexpr` absolute value, and two closeness tests for comparing measured values. The header also declares the fast approximations of the transcendental functions, documented in {fast_math}.

== min_max_range

A pair of bounds, `min` and `max`, of one type, such as a frequency range or a pitch range.

=== Include

```c++
#include <q/support/base.hpp>
```

=== Declaration

```c++
namespace cycfi::q
{
   template <typename T>
   struct min_max_range
   {
      T  min, max;
   };
}
```

=== Expressions

==== Notation

`T`         :: The type of the bounds.
`lo`, `hi`  :: Objects of type `T`: the lower and upper bounds.
`r`, `a`, `b` :: Objects of type `min_max_range<T>`.

==== Constructors and Assignment

[cols="1,1"]
|===
| Expression                    | Semantics

| `+min_max_range<T>{lo, hi}+`  | Construct a `min_max_range<T>` from `lo` (lower bound) and `hi` (upper bound).
| `min_max_range<T>(r)`         | Copy construct from `min_max_range<T> r`.
| `a = b`                       | Assign `b` to `a`.
|===

==== Access

[cols="1,1,1"]
|===
| Expression    | Semantics                           | Return Type

| `r.min`       | Direct access to the lower bound.   | `T`
| `r.max`       | Direct access to the upper bound.   | `T`
|===

==== Example

Clamp a frequency to the range 80 Hz to 1.2 kHz:

```c++
#include <q/support/base.hpp>
#include <algorithm>
...
namespace q = cycfi::q;

float f;                            // the frequency, in Hz
...
auto range = q::min_max_range<float>{80.0f, 1200.0f};    <1>
f = std::clamp(f, range.min, range.max);                 <2>
```

<1> Construct the range from its lower and upper bounds.
<2> Clamp `f` to the bounds of the range.

== byte_span

`byte_span` is a read-only view of contiguous bytes: a pointer and a length, with no ownership and no copy of the data. Q uses it for anything that moves a whole message or record as bytes. A MIDI 1.0 message, system exclusive included, is a `byte_span` to the readers of {midi_readers} and to a MIDI 1.0 {midi_sink}, and the MIDI-CI responders of {midi_ci} send their replies as one. It is a `std::span`, passed by value.

=== Include

```c++
#include <q/support/base.hpp>
```

=== Declaration

```c++
namespace cycfi::q
{
   using byte_span = std::span<std::uint8_t const>;
}
```

=== Expressions

==== Notation

`arr`       :: An array of `std::uint8_t`, or a `std::vector<std::uint8_t>`.
`p`         :: Pointer to `std::uint8_t const`.
`n`         :: Object of type `std::size_t`: a number of bytes.

==== Constructors

[cols="1,1"]
|===
| Expression                | Semantics

| `+byte_span{arr}+`        | Construct a view of the whole of `arr`.
| `+byte_span{p, n}+`       | Construct a view of `n` bytes starting at `p`.
|===

All the other expressions of `std::span` apply.

==== Example

View a MIDI note-on message, and its status byte alone:

```c++
namespace q = cycfi::q;

std::uint8_t const note_on[] = {0x90, 60, 100};
q::byte_span msg{note_on};                          <1>
q::byte_span status{note_on, 1};                    <2>
```

<1> Construct a view of the whole message.
<2> Construct a view of its first byte, the status byte.

== Constants and Functions

=== Include

```c++
#include <q/support/base.hpp>
```

=== Declaration

```c++
namespace cycfi::q
{
   constexpr double  pi = 3.1415926535897932384626433832795;

   template <typename T>
   constexpr T       abs(T x);

   bool              abs_within(float a, float b, float eps);
   bool              abs_within(int i, int j, int n);
   bool              rel_within(float a, float b, float eps);
}
```

=== Expressions

==== Notation

`T`               :: An arithmetic type, or any type with `<`, unary `-`, and construction from `0`.
`x`               :: Object of type `T`.
`a`, `b`, `eps`   :: Floating point values.
`i`, `j`, `n`     :: Integer values.

==== Constants

[cols="1,1,1"]
|===
| Expression    | Semantics                 | Return Type

| `pi`          | Get the constant pi.      | `double`
|===

==== Functions

[cols="1,1,1"]
|===
| Expression                | Semantics                                   | Return Type

| `abs(x)`                  | Compute the absolute value of `x`, in a
                              `constexpr` context too.                    | `T`
| `abs_within(a, b, eps)`   | Test that `a` and `b` differ by at most
                              `eps`.                                      | `bool`
| `abs_within(i, j, n)`     | Test that `i` and `j` differ by at most
                              `n`.                                        | `bool`
| `rel_within(a, b, eps)`   | Test that `a` and `b` differ by at most
                              `eps` times the larger of their
                              magnitudes.                                 | `bool`
|===

==== Example

Test a measured frequency against the expected one. The tolerance of `rel_within` is a fraction, so the same test serves 55 Hz and 5 kHz:

```c++
#include <q/support/base.hpp>
...
namespace q = cycfi::q;

float measured;                     // in Hz
float expected;                     // in Hz
...
bool pass = q::rel_within(measured, expected, 0.001f);   <1>
```

<1> Test that `measured` is within 0.1% of `expected`.
