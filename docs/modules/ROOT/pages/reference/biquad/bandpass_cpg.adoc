= Band Pass Filter; Constant Peak Gain

include::../../common.adoc[]

== Overview

Band pass second-order IIR (Infinite Impulse Response) filter with constant 0 dB peak gain. This filter is embodied by the `bandpass_cpg` class.

== Include

```c++
#include <q/fx/biquad.hpp>
```

== Declaration

```c++
struct bw <1>
{
   double val; // in octaves
};

struct bandpass_cpg : biquad
{
         bandpass_cpg(frequency f, float sps, bw _bw);
         bandpass_cpg(frequency f, float sps, double q = 0.707);

   void  config(frequency f, float sps, bw _bw);
   void  config(frequency f, float sps, double q = 0.707);
};
```

<1> Utility type to distinguish bandwidth from `q`, which is just a `double`.

:biquad: xref:reference/biquad.adoc[biquad]

== Expressions

In addition to valid expressions for {biquad}, `bandpass_cpg` allows these expressions.

=== Notation

`bf`              :: Object of type `bandpass_cpg`.
`f`               :: Object of type `frequency`.
`sps`             :: Floating point value representing samples per second.
`b`               :: Floating point value for bandwidth (in octaves).
`q`               :: Floating point value for Q or quality factor.
`a [, b, c, d]`   :: Required `a`, optional `b, c, d`.

=== Constructors

[cols="1,1"]
|===
| Expression                     | Semantics

| `bandpass_cpg(f, sps [, q])`   |  Construct a `bandpass_cpg` filter from `f`, `sps` and optional `q` (defaults to `0.707`).
| `bandpass_cpg(f, sps, bw\{b})` |  Construct a `bandpass_cpg` filter from `f`, `sps` and `b` (bandwidth).
|===

NOTE: C++ brace initialization may also be used.

=== Mutators

[cols="1,1,1"]
|===
| Expression                    | Semantics                                   | Return Type

| `bf.config(f, sps [, q])`     | Configure a `bandpass_cpg` filter from
                                  `f`, `sps` and optional `q` (defaults to
                                  `0.707`).                                   | `void`
| `bf.config(f, sps, bw\{b})`   | Configure a `bandpass_cpg` filter from
                                  `f`, `sps` and `b` (bandwidth).             | `void`
|===

=== Example

Extract the band around 1 kHz from the input samples `in`, at `sps` samples
per second:

```c++
namespace q = cycfi::q;
using namespace q::literals;

auto bf = q::bandpass_cpg{1_kHz, sps, q::bw{1.0}};       <1>

for (auto& s : in)
   s = bf(s);                                            <2>
```

<1> Construct a constant 0 dB peak gain band pass filter centered at 1 kHz,
    one octave wide.
<2> Filter the sample in place.
