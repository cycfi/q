= All Pass Filter

include::../../common.adoc[]

== Overview

All pass second-order IIR (Infinite Impulse Response) filter. This filter is embodied by the `allpass` class.

== Include

```c++
#include <q/fx/biquad.hpp>
```

== Declaration

```c++
struct allpass : biquad
{
         allpass(frequency f, float sps, double q = 0.707);
   void  config(frequency f, float sps, double q = 0.707);
};
```

:biquad: xref:reference/biquad.adoc[biquad]

== Expressions

In addition to valid expressions for {biquad}, `allpass` allows these expressions.

=== Notation

`ap`              :: Object of type `allpass`.
`f`               :: Object of type `frequency`.
`sps`             :: Floating point value representing samples per second.
`q`               :: Floating point value for Q or quality factor.
`a [, b, c, d]`   :: Required `a`, optional `b, c, d`.

=== Constructor

[cols="1,1"]
|===
| Expression               | Semantics

| `allpass(f, sps [, q])`  |  Construct an `allpass` filter from `f`, `sps` and optional `q` (defaults to `0.707`).
|===

NOTE: C++ brace initialization may also be used.

=== Mutators

[cols="1,1,1"]
|===
| Expression                  | Semantics                                   | Return Type

| `ap.config(f, sps [, q])`   | Configure an `allpass` from `f`, `sps` and
                                optional `q` (defaults to `0.707`).         | `void`
|===

=== Example

Mix the input samples `in`, at `sps` samples per second, with their all pass
filtered copy, cancelling the frequencies around 1 kHz as in one stage of a
phaser:

```c++
namespace q = cycfi::q;
using namespace q::literals;

auto ap = q::allpass{1_kHz, sps};                        <1>

for (auto& s : in)
   s = 0.5f * (s + ap(s));                               <2>
```

<1> Construct an all pass filter centered at 1 kHz, where its phase shift is
    180 degrees.
<2> Add the phase shifted sample to the dry sample. The two cancel at 1 kHz.
