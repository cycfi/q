= Hann Window Generator

include::../../../common.adoc[]

== Overview

image:hann.svg[alt="Hann Window", width=300, role=right]

The Hann window, also known as the Cosine Bell, is named after the Austrian meteorologist Julius von Hann. The Hann window is a taper formed with a cosine raised above zero. It is used as one of many windowing functions for smoothing values. The Hann window taper belongs to both the cosine-sum and sine-power families. Unlike the Hamming window, the Hann window's end points touch zero.

The formula for the Hann window is:
```
w(n) = 0.5*(1 - cos(2pin/(N-1)))
```

Aside from its common use as a window function, the Q DSP library also utilizes the Hann window generator for modulating the audio signal and generating complex envelopes.

== Hann Window Generator

=== Include

```c++
#include <q/synth/gen/hann_gen.hpp>
```

=== Declaration

```c++
struct hann_gen
{
            hann_gen(duration width, float sps);

   float    operator()();
   void     config(duration width, float sps, bool reset_ = false);
   void     reset();
   void     midpoint();
};
```

=== Expressions

`hann_gen` is a model of `{generator}`. In addition to valid expressions for `{generator}`, `hann_gen` allows these expressions.

==== Notation

`g`               :: Object of type `hann_gen`.
`w`               :: Object of type `duration`.
`sps`             :: Floating point value representing samples per second.
`r`               :: Boolean value: `true` to reset the phase (default: `false`).

==== Constructor

[cols="1,1"]
|===
| Expression               | Semantics

| `hann_gen(w, sps)`       | Construct a `hann_gen` given window width, `w`,
                             and samples per second, `sps`.
|===

NOTE: C++ brace initialization may also be used.

==== Operation

[cols="1,1,1"]
|===
| Expression               | Semantics                                         | Return Type

| `g.reset()`              | Set the current phase to the start of the window.   | `void`
| `g.midpoint()`           | Set the current phase to the middle of the window.  | `void`
|===

==== Mutators

[cols="1,1,1"]
|===
| Expression               | Semantics                                         | Return Type

| `g.config(w, sps [, r])` | Set the window width, `w`, with samples per
                             second, `sps`. If `r` is `true`, also set the
                             current phase to the start of the window.         | `void`
|===

NOTE: `config` keeps the current phase unless `r` is `true`, so a running
generator changes its width without a discontinuity.

==== Example

Apply a 10 ms Hann window to a grain of 10 ms of samples, at `sps`
samples per second:

```c++
#include <q/synth/gen/hann_gen.hpp>
#include <span>
...
namespace q = cycfi::q;
using namespace q::literals;

std::span<float> grain;             // 10 ms of samples
...
auto win = q::hann_gen{10_ms, sps};       <1>
for (auto& s : grain)
   s *= win();                             <2>
```

<1> Construct a Hann window generator, 10 ms wide.
<2> Generate the next value of the window and apply it to the sample.

== Ramp Generators

Two subclasses of `hann_gen` are specialized for ramp generation:

1. The Hann upward ramp generator generates a rising curve with the
shape of the first half of a Hann window taper.

2. The Hann downward ramp generator generates a falling curve with the
shape of the second half of a Hann window taper.

=== Include

```c++
#include <q/synth/gen/hann_gen.hpp>
```

=== Declaration

```c++
struct hann_upward_ramp_gen : hann_gen
{
            hann_upward_ramp_gen(duration width, float sps);

   void     config(duration width, float sps, bool reset_ = false);
};

struct hann_downward_ramp_gen : hann_gen
{
            hann_downward_ramp_gen(duration width, float sps);

   void     reset();
   void     config(duration width, float sps, bool reset_ = false);
};
```

=== Expressions

`hann_upward_ramp_gen` and `hann_downward_ramp_gen` are models of
`{ramp}` and implement all valid expressions of `{ramp}`. In addition to
valid expressions for `{ramp}`, `hann_upward_ramp_gen` and
`hann_downward_ramp_gen` allow these expressions.

==== Notation

`g`               :: Object of type `hann_upward_ramp_gen` or `hann_downward_ramp_gen`.
`w`               :: Object of type `duration`.
`sps`             :: Floating point value representing samples per second.
`r`               :: Boolean value: `true` to reset the ramp.

==== Mutators

[cols="1,1,1"]
|===
| Expression               | Semantics                                         | Return Type

| `g.config(w, sps, r)`    | Set the ramp width, `w`, with samples per
                             second, `sps`. If `r` is `true`, also reset
                             the ramp to its start.                            | `void`
|===

NOTE: `hann_downward_ramp_gen` starts at the middle of the window: its
`reset()` sets the current phase to the midpoint.

NOTE: The ramp generators run freely. After one ramp width, the phase
continues into the other half of the window, and the next ramp runs the
other way. Run a ramp for one width's worth of samples, then call `reset()`,
or pass `true` as `r` to `config`, to start the next ramp.

==== Example

Fade in the buffer `out`, holding 50 ms of samples at `sps` samples per
second:

```c++
namespace q = cycfi::q;
using namespace q::literals;

auto ramp = q::hann_upward_ramp_gen{50_ms, sps};   <1>
for (auto& s : out)
   s *= ramp();                                     <2>
```

<1> Construct a Hann upward ramp generator, 50 ms wide.
<2> Generate the next value of the ramp, rising from 0.0 to 1.0 over
    50 ms, and apply it to the sample.
