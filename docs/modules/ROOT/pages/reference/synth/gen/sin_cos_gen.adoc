= Sine Cosine Generator

include::../../../common.adoc[]

== Overview

image:sin_cos.svg[alt="Sine and Cosine Waves", width=300, role=right]

`sin_cos_gen` is an oscillator that simultaneously generates sine and cosine waveforms. `sin_cos_gen` is implemented utilizing Hal Chamberlin's state variable IIR filter, a digital derivation of the analog state variable filter optimized for infinite Q oscillation. `sin_cos_gen` is suitable as a low frequency sine wave oscillator. The upper frequency limit for stability is roughly 1/6 sps. At low frequencies, the waveform symmetry is very pure, but it becomes skewed as you approach the upper limit. For low frequencies, we can reduce the calculation of the coefficient to 2*Pi*freq/sps. When utilized with fixed point or IEEE floating point, the oscillator should run forever without instability.

Although `sin_cos_gen` is technically an oscillator that produces periodic waveforms, it is represented as a model of a `{generator}` because it does not adhere to the `{oscillator}` concept, which requires complete control over the `{phase}` for synchronicity. As a free-running oscillator, `sin_cos_gen` can exhibit phase drift over time due to accumulating floating-point errors.

The generator is a class template, `basic_sin_cos_gen<T>`, where `T` is the type of its coefficient and state. `sin_cos_gen` is its `double` instantiation.

Source: https://www.earlevel.com/main/2003/03/02/the-digital-state-variable-filter/[The digital state variable filter]

== Precision

The recurrence holds its amplitude in either precision: run free, the peak stays within about 1e-8 of its start in `double`, and within about 1e-6 in `float`, however long it runs. Rounding moves the frequency slightly in `float` at very low rates: at 0.1 Hz and 48 kHz it is off by about 7e-7 of itself, and exact in `double`.

`sin_cos_gen` is `double`, the choice for a free-running oscillator such as an LFO. `basic_sin_cos_gen<float>` suits a single-precision FPU, such as a Cortex-M4F, where `double` is computed in software, and a short run from a reset, such as a crossfade ramp, where its rounding is far below hearing.

== Include

```c++
#include <q/synth/gen/sin_cos_gen.hpp>
```

== Declaration

```c++
template <typename T>
struct basic_sin_cos_gen
{
                              basic_sin_cos_gen(frequency f, float sps);

   std::pair<T, T>            operator()();
   void                       config(frequency f, float sps);
   void                       reset(T sin = 0, T cos = 1);
   void                       midpoint();
};

using sin_cos_gen = basic_sin_cos_gen<double>;
```

`T` models `std::floating_point`.

== Template Instantiations

`sin_cos_gen` is the template instantiation of `basic_sin_cos_gen` that most code uses:

`sin_cos_gen`:: A sine and cosine generator in `double`.

```c++
using sin_cos_gen = basic_sin_cos_gen<double>;
```

== Expressions

`basic_sin_cos_gen<T>` is a model of `{generator}`. In addition to valid expressions for `{generator}`, `basic_sin_cos_gen<T>` allows these expressions.

=== Notation

`G`               :: A `basic_sin_cos_gen<T>` type.
`g`               :: Object of type `G`.
`f`               :: Object of type `frequency`.
`sps`             :: Floating point value representing samples per second.
`sval`, `cval`    :: Values of type `T`.

=== Constructor

[cols="1,1"]
|===
| Expression               | Semantics

| `G(f, sps)`              | Construct a `G` given frequency, `f`,
                             and samples per second, `sps`.
|===

NOTE: C++ brace initialization may also be used.

=== Function Call

[cols="1,1,1"]
|===
| Expression      | Semantics                                        | Return Type

| `g()`           | Generate a sin/cos signal and get
                    both `sin` and `cos` result. The return type
                    is a `std::pair<T, T>` which stores
                    the `sin` and `cos` results.                     | `std::pair<T, T>`
| `g().first`     | Generate a sin/cos signal and get
                    only the `sin` result.                           | `T`
| `g().second`    | Generate a sin/cos signal and get only the `cos`
                    result.                                          | `T`
|===

=== Operation

[cols="1,1,1"]
|===
| Expression            | Semantics                                         | Return Type

| `g.reset()`           | Reset the current `sin` and `cos` to 0 and
                          1, respectively.                                  | `void`
| `g.reset(sval, cval)` | Reset the current `sin` and `cos` values,
                          respectively.                                     | `void`
| `g.midpoint()`        | Equivalent to `g.reset(0, -1)`.                   | `void`
|===

=== Mutators

[cols="1,1,1"]
|===
| Expression            | Semantics                                         | Return Type

| `g.config(f, sps)`    | Set the frequency, `f`, with samples per
                          second, `sps`.                                    | `void`
|===

`config` keeps the current `sin` and `cos` values, so a running generator
changes its frequency without a discontinuity.

=== Example

Apply a 5 Hz tremolo to the two channels of a stereo signal, a quarter
cycle apart, at `sps` samples per second:

```c++
#include <q/synth/gen/sin_cos_gen.hpp>
#include <span>
...
namespace q = cycfi::q;
using namespace q::literals;

std::span<float> left;              // the left channel
std::span<float> right;             // the right channel
...
auto lfo = q::sin_cos_gen{5_Hz, sps};               <1>
for (std::size_t i = 0; i != left.size(); ++i)
{
   auto [sin_val, cos_val] = lfo();                 <2>
   left[i] *= 0.75f + 0.25f * sin_val;
   right[i] *= 0.75f + 0.25f * cos_val;
}
```

<1> Construct a 5 Hz sine and cosine generator.
<2> Generate the next sine and cosine values.
