= LFO Generator

include::../../../common.adoc[]

== Overview

`lfo_gen` is a low frequency oscillator for modulation, with six waveforms,
a rate in Hz, and a delayed fade-in from key-on. `lfo()` advances the
oscillator one sample and returns its value, and `lfo.value()` returns the
same value again, so one LFO per voice can drive several destinations from
the same sample, vibrato and tremolo for example.

After `key_on`, the LFO waits `delay` seconds, then fades in linearly over
`fade` seconds, so the modulation of a held note builds up gradually, as a
player's vibrato does, and a short note stays steady. With both at zero, the
LFO runs at full depth from the first sample.

The waveforms come from Q's oscillators without band limiting:
`{basic_triangle_osc}`, `{basic_saw_osc}`, `{basic_square_osc}`, {sin_osc},
and {sample_hold_osc} fed by the {white_noise_gen}. An LFO runs far below the
frequencies where aliasing occurs.

== Include

```c++
#include <q/synth/gen/lfo_gen.hpp>
```

== Declaration

```c++
struct lfo_gen
{
   enum waveform : std::uint8_t
   {
      triangle, saw_down, saw_up, square, sine, sample_hold
   };

   struct config
   {
      float          rate        = 5.0f;     // Hz
      float          delay       = 0.0f;     // seconds, before the fade
      float          fade        = 0.0f;     // seconds, to full
      bool           key_sync    = true;     // restart on key-on
      std::uint8_t   wave        = triangle;
   };

                  lfo_gen();
                  lfo_gen(config const& cfg, float sps);

   void           set(config const& cfg, float sps);
   void           key_on();
   float          operator()();
   float          value() const;
};
```

== Expressions

`lfo_gen` is a model of `{Generator}`. In addition to valid expressions for `{Generator}`, `lfo_gen` allows these expressions.

=== Notation

`lfo`          :: Object of type `lfo_gen`.
`cfg`          :: Object of type `lfo_gen::config`.
`sps`          :: Floating point value representing samples per second.

=== Constructors

[cols="1,1"]
|===
| Expression              | Semantics

| `lfo_gen()`             | Default construct an `lfo_gen`: a 5 Hz triangle
                            at 44.1 kHz, with no delay or fade.
| `lfo_gen(cfg, sps)`     | Construct an `lfo_gen` given `cfg`
                            (configuration) and `sps` (samples per second).
|===

NOTE: C++ brace initialization may also be used.

=== Function Call

[cols="1,1,1"]
|===
| Expression              | Semantics                                     | Return Type

| `lfo()`                 | Generate the next sample: the waveform, from
                            -1.0 to 1.0, scaled by the fade-in.           | `float`
|===

=== Operation

[cols="1,1,1"]
|===
| Expression              | Semantics                                     | Return Type

| `lfo.key_on()`          | Start the delay and the fade-in, and restart
                            the phase if `cfg.key_sync` is `true`.        | `void`
|===

=== Mutators

[cols="1,1,1"]
|===
| Expression              | Semantics                                     | Return Type

| `lfo.set(cfg, sps)`     | Set the rate, delay, fade, waveform and key
                            sync given `cfg` and `sps` (samples per
                            second).                                      | `void`
|===

=== Accessors

[cols="1,1,1"]
|===
| Expression              | Semantics                                     | Return Type

| `lfo.value()`           | Get the latest sample generated by `lfo()`.   | `float`
|===

=== Access

[cols="1,1,1"]
|===
| Expression              | Semantics                                     | Return Type

| `cfg.rate`              | Direct access to the rate, in Hz
                            (default: 5.0).                               | `float`
| `cfg.delay`             | Direct access to the delay from key-on to
                            the start of the fade-in, in seconds
                            (default: 0.0).                               | `float`
| `cfg.fade`              | Direct access to the duration of the
                            fade-in, in seconds (default: 0.0).           | `float`
| `cfg.key_sync`          | Direct access to the key sync: if `true`,
                            `key_on` restarts the phase, so every note
                            starts at the same point in the waveform
                            (default: `true`).                            | `bool`
| `cfg.wave`              | Direct access to the waveform: one of
                            `lfo_gen::triangle`, `saw_down`, `saw_up`,
                            `square`, `sine` and `sample_hold`
                            (default: `triangle`).                        | `std::uint8_t`
|===

=== Example

Apply vibrato and tremolo from one LFO to an oscillator, writing to the
output samples `out`, at `sps` samples per second:

```c++
#include <q/synth/gen/lfo_gen.hpp>
#include <q/synth/sin_osc.hpp>  // For sin
...
namespace q = cycfi::q;

auto osc = q::sin;                  // the oscillator
q::phase_iterator pi;               // its phase, at the note's frequency
...
q::lfo_gen lfo{
{
   .rate  = 5.5f,    // Hz
   .delay = 0.4f,    // seconds before the fade-in
   .fade  = 0.3f     // seconds to full depth
},
   sps
};                                                     <1>

lfo.key_on();                                          <2>
auto const step = pi._step.rep;                        // the unmodulated step

for (auto& s : out)
{
   auto mod = lfo();                                   <3>

   // Vibrato: 25 cents either way
   auto bend = std::exp2(mod * 0.25f / 12);
   pi._step = q::phase{std::uint32_t(step * bend), q::direct_unit};

   // Tremolo: 6 dB down at the trough of the LFO
   auto trough = (1.0f - lfo.value()) * 0.5f;          <4>
   s = osc(pi++) * q::lin_float(q::dB(-6 * trough));
}
```

<1> Construct a 5.5 Hz LFO that waits 0.4 seconds after key-on, then fades
    in over 0.3 seconds.
<2> Start the delay and the fade-in when the note starts.
<3> Generate the next sample of the LFO and use it for the vibrato.
<4> Get the same sample again for the tremolo.
