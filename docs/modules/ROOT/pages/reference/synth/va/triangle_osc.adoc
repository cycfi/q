= Triangle Wave Oscillator

include::../../../common.adoc[]

== Overview

image:triangle.svg[alt="Triangle Wave", width=300, role=right]

The triangle wave oscillator programmatically generates a triangle waveform that ramps between -1.0 and 1.0. The `basic_triangle_osc` is not bandwidth limited, while `triangle_osc` is, using a technique called "PolyBLAMP" to reduce aliasing artifacts that can occur when generating the triangle waveform with sharp corners.

The symmetry is the fraction of the cycle the wave spends rising, 0.5 being the plain triangle. It is clamped to [0.01, 0.99]. Skewing it moves the wave toward a sawtooth (or a reverse sawtooth) and changes the harmonic mix: the even harmonics come up as the symmetry leaves the middle. Analog oscillator chips specify theirs: a Curtis CEM3340 at 50 percent, with a 45 to 55 percent range.

Phase 0 falls at a different point of the two oscillators. `basic_triangle_osc` is at its trough at phase 0. `triangle_osc` is shifted by half the rise, so at phase 0 it crosses zero going up, in step with a sine. Each keeps its landmark at phase 0 whatever the symmetry.

image::triangle_symmetry.svg[alt="The triangle at three symmetries, and its harmonics", width=700px, align=center, title="Top: the triangle at symmetry 0.5, 0.25 and 0.1, moving toward a sawtooth. Bottom: the harmonics. The symmetric triangle has odd harmonics only; skewing it brings the even ones up.", link={imagesdir}/triangle_symmetry.svg]

PolyBLAMP (polynomial band-limited ramp) corrects the corners of the waveform, the discontinuities in its first derivative. For each sample within one phase step of a corner, it computes a cubic approximation of the difference between a band-limited ramp and the ideal ramp, scaled by the change in slope, and applies it to the waveform. This reduces the aliasing from harmonics above the Nyquist frequency, half the sample rate.

```c++
#include <q/synth/va/triangle_osc.hpp>
```

== Declaration

```c++
struct basic_triangle_osc
{
    constexpr            basic_triangle_osc(float symmetry = 0.5f);

    constexpr float      operator()(phase p) const;
    constexpr float      operator()(phase_iterator i) const;

    constexpr void       symmetry(float sym);
    constexpr float      symmetry() const;
};

struct triangle_osc : basic_triangle_osc
{
    constexpr            triangle_osc(float symmetry = 0.5f);

    constexpr float      operator()(phase p, phase dt) const;
    constexpr float      operator()(phase_iterator i) const;
};

constexpr auto basic_triangle = basic_triangle_osc{};
constexpr auto triangle = triangle_osc{};
```

== Expressions

`basic_triangle_osc` is a model of {basic_osc}. `triangle_osc` is a model of {bandlimited_osc}. In addition to valid expressions for {basic_osc} and {bandlimited_osc}, `basic_triangle_osc` and `triangle_osc` allow these expressions.

The global instances `basic_triangle` and `triangle` are plain triangles, with a symmetry of 0.5. They can be used anywhere without needing to be placed in a class or struct. They are `const`: a different symmetry needs an object of its own.

=== Notation

`osc`        :: Object of type `basic_triangle_osc` or `triangle_osc`.
`sym`        :: A floating point value from 0.0 to 1.0 representing symmetry.
`pi`         :: Object of type `{phase_iterator}`.
`ph`, `dt`   :: Objects of type `{phase}`: the phase, and the phase step between two samples.

=== Constructors

[cols="1,1"]
|===
| Expression                  | Semantics

| `basic_triangle_osc()`      | Construct a `basic_triangle_osc` with a symmetry of 0.5.
| `basic_triangle_osc(sym)`   | Construct a `basic_triangle_osc` given a symmetry, `sym`.
| `triangle_osc()`            | Construct a `triangle_osc` with a symmetry of 0.5.
| `triangle_osc(sym)`         | Construct a `triangle_osc` given a symmetry, `sym`.
|===

NOTE: C++ brace initialization may also be used.

=== Function Call

[cols="1,1,1"]
|===
| Expression            | Semantics                                   | Return Type

| `triangle(pi)`        | Generate the band limited triangle at the
                          phase of `pi`.                              | `float`
| `triangle(ph, dt)`    | Generate the band limited triangle given
                          `ph` (phase) and `dt` (phase step).         | `float`
| `basic_triangle(pi)`  | Generate the triangle, not band limited,
                          at the phase of `pi`.                       | `float`
| `basic_triangle(ph)`  | Generate the triangle, not band limited,
                          at `ph`.                                    | `float`
|===

=== Mutators

[cols="1,1,1"]
|===
| Expression            | Semantics                                   | Return Type

| `osc.symmetry(sym)`   | Set the symmetry to `sym`, clamped to
                          [0.01, 0.99].                               | `void`
|===

=== Accessors

[cols="1,1,1"]
|===
| Expression            | Semantics                                   | Return Type

| `osc.symmetry()`      | Get the symmetry.                           | `float`
|===

=== Example

Generate a 220 Hz band limited triangle that rises over a quarter of the
cycle into the output samples `out`, at `sps` samples per second:

```c++
namespace q = cycfi::q;
using namespace q::literals;

auto osc = q::triangle_osc{0.25f};              <1>
auto pi = q::phase_iterator{220_Hz, sps};

for (auto& s : out)
   s = osc(pi++);                               <2>
```

<1> Construct a band limited triangle oscillator with a symmetry of 0.25.
<2> Generate the triangle at the current phase, then advance the phase
    iterator to the next sample.
