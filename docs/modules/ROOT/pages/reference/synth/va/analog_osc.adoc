= Analog Oscillator

include::../../../common.adoc[]

== Overview

`analog_osc` is one oscillator core with its waveforms available at once, the
way a voltage controlled oscillator chip gives them. A Curtis CEM3340, the
part in a Prophet-5 Rev 3 and an OB-Xa, runs a single ramp and derives the
sawtooth, the triangle and the pulse from it, and a patch mixes the ones it
uses. A voice built that way needs them all from one phase, which an
oscillator with a single output cannot give.

image::analog_osc.svg[alt="Saw, pulse and triangle from one core", width=700px, align=center, title="One core at 200 Hz: the sawtooth, a pulse at width 0.3 and the triangle, all from the same phase and all available on the same sample. The pulse and the sawtooth are PolyBLEP corrected, the triangle PolyBLAMP.", link={imagesdir}/analog_osc.svg]

It is Q's three virtual analog oscillators in one object, sharing the
caller's phase: `saw`, `pulse` and `triangle` name what `operator()` would
otherwise have to choose between, and the controls come with them, `width`
from `{pulse_osc}` and `symmetry` from `{triangle_osc}`.

The phase is the caller's, as it is for every oscillator in Q, so the same
`{phase_iterator}` drives the three outputs and they stay in step.

NOTE: The parts this takes after are analog, and their imperfections are part
of the sound. `symmetry` is one of them: a CEM3340 specifies its triangle at
50 percent with a 45 to 55 percent range, and a skewed triangle is a
different harmonic mix. What is not modelled here is the finite reset time
that rounds a real ramp's corner as the frequency rises.

== Include

```c++
#include <q/synth/va/analog_osc.hpp>
```

== Declaration

```c++
   struct analog_osc : saw_osc, pulse_osc, triangle_osc
   {
      constexpr            analog_osc(
                              float width = 0.5f, float symmetry = 0.5f
                           );

      constexpr float      saw(phase p, phase dt) const;
      constexpr float      pulse(phase p, phase dt) const;
      constexpr float      triangle(phase p, phase dt) const;

      constexpr float      saw(phase_iterator i) const;
      constexpr float      pulse(phase_iterator i) const;
      constexpr float      triangle(phase_iterator i) const;

      using pulse_osc::width;
      using triangle_osc::symmetry;
   };
```

== Expressions

=== Notation

`osc`          :: Object of type `analog_osc`.
`i`            :: A `{phase_iterator}`.
`p`, `dt`      :: A `{phase}` and the phase step.
`w`, `s`       :: A `float` in (0, 1).

=== Constructors

[cols="1,1"]
|===
| Expression                 | Semantics

| `analog_osc()`             | A square pulse and a symmetric triangle.
| `analog_osc(w)`            | Pulse width `w`.
| `analog_osc(w, s)`         | Pulse width `w`, triangle symmetry `s`.
|===

=== Function Call

[cols="1,1"]
|===
| Expression                 | Semantics

| `osc.saw(i)`               | The sawtooth at that phase, band limited.
| `osc.pulse(i)`             | The pulse, band limited.
| `osc.triangle(i)`          | The triangle, band limited.
| `osc.saw(p, dt)`           | The same from a phase and its step.
|===

=== Controls

[cols="1,1"]
|===
| Expression                 | Semantics

| `osc.width(w)`             | The pulse width, 0 to 1. Inherited from
                               `{pulse_osc}`.
| `osc.symmetry(s)`          | Where the triangle turns, 0 to 1. Inherited
                               from `{triangle_osc}`.
|===

== Example

One oscillator feeding a patch that mixes a sawtooth and a pulse together,
which is how the polysynths of the era voiced most of their sounds:

```c++
q::analog_osc osc{0.35f};               // a narrow pulse
q::phase_iterator pi{220_Hz, sps};
q::lfo_gen lfo{{.rate = 0.6f}, sps};

for (auto& s : buffer)
{
   osc.width(0.5f + 0.4f * lfo());      // the width moving, for thickness
   s = 0.6f * osc.saw(pi) + 0.4f * osc.pulse(pi);
   ++pi;
}
```

Both outputs come from the same phase, so they stay locked to each other;
the beating between two oscillators comes from running a
second `analog_osc` on its own iterator, a few cents away.
