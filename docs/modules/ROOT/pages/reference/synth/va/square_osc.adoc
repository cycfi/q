= Square Wave Oscillator

include::../../../common.adoc[]

== Overview

image:square.svg[alt="Square Wave", width=300, role=right]

The square wave oscillator programmatically generates a pulse waveform with a 50% pulse width. The `basic_square_osc` is not bandwidth limited, while `square_osc` is, using a technique called "PolyBLEP" to reduce aliasing artifacts that can occur when generating the waveform with a sharp discontinuity as the signal transitions between -1.0 and 1.0.

PolyBLEP (polynomial band-limited step) corrects the samples nearest each discontinuity. For each sample within one phase step of a jump, it computes a quadratic approximation of the difference between a band-limited step and the ideal step, and applies it to the waveform. The correction spreads the jump over two samples and reduces the aliasing from harmonics above the Nyquist frequency, half the sample rate.

== Include

```c++
#include <q/synth/va/square_osc.hpp>
```

== Declaration

```c++
struct basic_square_osc
{
    constexpr float operator()(phase p) const;
    constexpr float operator()(phase_iterator i) const;
};

constexpr auto basic_square = basic_square_osc{};

struct square_osc
{
    constexpr float operator()(phase p, phase dt) const;
    constexpr float operator()(phase_iterator i) const;
};

constexpr auto square = square_osc{};
```

== Expressions

`basic_square_osc` is a model of {basic_osc}. `square_osc` is a model of {bandlimited_osc}. In addition to valid expressions for {basic_osc} and {bandlimited_osc}, `basic_square_osc` and `square_osc` allow these expressions.

`basic_square_osc` and `square_osc` are stateless. The global instances `basic_square` and `square` can be used anywhere without needing to be placed in a class or struct. They are semantically equivalent to global functions.

=== Notation

`pi`         :: Object of type `{phase_iterator}`.
`ph`, `dt`   :: Objects of type `{phase}`: the phase, and the phase step between two samples.

=== Function Call

[cols="1,1,1"]
|===
| Expression          | Semantics                                   | Return Type

| `square(pi)`        | Generate the band limited square wave at the
                        phase of `pi`.                              | `float`
| `square(ph, dt)`    | Generate the band limited square wave given
                        `ph` (phase) and `dt` (phase step).         | `float`
| `basic_square(pi)`  | Generate the square wave, not band limited,
                        at the phase of `pi`.                       | `float`
| `basic_square(ph)`  | Generate the square wave, not band limited,
                        at `ph`.                                    | `float`
|===

=== Example

Generate a 220 Hz band limited square wave into the output samples `out`,
at `sps` samples per second:

```c++
namespace q = cycfi::q;
using namespace q::literals;

auto pi = q::phase_iterator{220_Hz, sps};

for (auto& s : out)
   s = q::square(pi++);                         <1>
```

<1> Generate the band limited square wave at the current phase, then advance
    the phase iterator to the next sample.
