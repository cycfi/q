= Hard Sync

include::../../../common.adoc[]

== Overview

Hard sync restarts the phase of one oscillator, the slave, each time another
oscillator, the master, completes a cycle, as the sync input of a voltage
controlled oscillator does. The slave runs at its own frequency until the
master wraps, then starts again. The pitch heard is the master's, and the
slave's frequency becomes a timbre control: sweeping it gives the sound of the
Prophet-5's OSC A SYNC switch.

image::hard_sync.svg[alt="A slave oscillator restarted by its master", width=700px, align=center, title="A 560 Hz sawtooth restarted by a 200 Hz master. The slave runs at its own frequency until the master's cycle ends, marked by the dotted lines, and the wave is cut wherever it happens to be. The pitch heard is the master's; moving the slave moves the timbre.", link={imagesdir}/hard_sync.svg]

Hard sync is implemented by a class named `hard_sync`. Both phases belong to
the caller, as everywhere in Q. Advance both phase iterators as usual, then
call `hard_sync` with the pair: it detects the master's wrap and moves the
slave's phase.

NOTE: The discontinuity at the restart is not band limited. The slave's
waveform corrections cover only the jump at the end of its own cycle.

== Restart Between Samples

A cycle rarely ends on a sample boundary. When the master wraps, it is
already some fraction of a step past zero, and the slave starts the same
fraction into its own step. A restart quantized to the sample grid would make
the pitch waver, audibly on a sweep.

`fraction()` returns that position, from 0 to 1, for the sample on which the
restart happened.

== Include

```c++
#include <q/synth/va/sync.hpp>
```

== Declaration

```c++
struct hard_sync
{
   bool           operator()(phase_iterator& slave, phase_iterator const& master);

   float          fraction() const;
};
```

== Expressions

=== Notation

`sync`, `a`, `b`     :: Objects of type `hard_sync`.
`slave`, `master`    :: Objects of type `{phase_iterator}`: the phase being restarted, and the phase that restarts it.

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression              | Semantics

| `hard_sync()`           | Default construct a `hard_sync`.
| `hard_sync(sync)`       | Copy construct from `hard_sync sync`.
| `a = b`                 | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used.

=== Function Call

[cols="1,1,1"]
|===
| Expression              | Semantics                                   | Return Type

| `sync(slave, master)`   | Process the pair, after advancing both.
                            On the sample `master` wraps, move the
                            phase of `slave` to the restart point and
                            return `true`.                              | `bool`
|===

=== Accessors

[cols="1,1,1"]
|===
| Expression              | Semantics                                   | Return Type

| `sync.fraction()`       | Get the position of the latest restart
                            within its sample, from 0 to 1.             | `float`
|===

=== Example

Sweep a slave sawtooth from 110 Hz to 770 Hz against a 110 Hz master, into
the output samples `out`, at `sps` samples per second:

```c++
#include <q/synth/va/analog_osc.hpp>  // For analog_osc

namespace q = cycfi::q;
using namespace q::literals;

auto osc = q::analog_osc{};
auto master = q::phase_iterator{110_Hz, sps};
auto slave = q::phase_iterator{110_Hz, sps};
auto sync = q::hard_sync{};                                     <1>

for (std::size_t i = 0; i != out.size(); ++i)
{
   auto t = float(i) / out.size();
   slave.set(q::frequency{110.0 * (1.0 + 6.0 * t)}, sps);
   ++master;
   ++slave;
   sync(slave, master);                                         <2>
   out[i] = osc.saw(slave);                                     <3>
}
```

<1> Construct the `hard_sync`.
<2> Restart the slave's phase when the master wraps.
<3> Generate the sawtooth from the slave's phase. The master is not heard: it
    sets the pitch by restarting the slave.
