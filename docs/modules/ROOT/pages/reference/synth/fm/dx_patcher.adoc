= DX Patcher

include::../../../common.adoc[]

== Overview

A DX7 patch holds its 156 parameters as counts, mostly 0 to 99, each with a
law of its own: an output level maps to decibels in steps of 0.75 dB, and an
envelope rate to a slope set by the chip's 49,096 Hz clock. `dx_patcher`
compiles a patch, once, into what an {fm_voice} takes: ratios, decibels,
seconds and radians.

The compilation also makes a note-on cheap. Keyboard scaling, velocity and
rate scaling all depend on the key, so the patcher precomputes them for
every key and every velocity, and a note-on is a set of table reads.

The laws that map a DX7 patch's counts are in `dx_patcher`. The DX7's
envelope shape and attack curve are in {dx_envelope_gen}, and its 32
algorithms in {dx7_routing}.

=== The Patch

`dx_patch` is the patch as a cartridge stores it, so a preset maps one to
one: six `dx_op_config` operators, the pitch envelope, the algorithm and
feedback, the LFO, the modulation depths and sensitivities, the transpose and
the name. `dx_patcher::config` is an alias for it. {dx_sysex} reads patches
from the DX7's `.syx` dumps.

=== A Patcher

`dx_patcher` models a `{Patcher}`: it holds the voice's configuration, its
sample rate, and fills a `note` for a key and a velocity. A voice takes one
directly:

```c++
#include <q/synth/fm/dx_patcher.hpp>
#include <q/synth/fm/fm_voice.hpp>
...
namespace q = cycfi::q;

q::dx_patch cfg;                    // a DX7 patch
float sps;                          // samples per second
...
q::dx_patcher patch{cfg, sps};      // compiled once
q::fm_voice voice{patch};           // settings and sample rate
voice.attack(patch, 69, 0.8f);      // A4, velocity 0.8
```

Any other type that conforms to `{Patcher}`, a JSON preset reader for
example, plays a voice the same way.

=== What the Patcher Maps

The header's notes give each law in detail.

[cols="1,2"]
|===
| Patch parameter | What the voice gets

| Output level, keyboard level
  scaling, velocity        | A level in decibels, summed into the envelope's
                             levels. Scaling works in groups of three notes
                             from the break point, with linear or
                             exponential curves either side.
| Envelope rates           | A time per segment, from the DX7's rate law on
                             its own 49,096 Hz clock, with keyboard rate
                             scaling folded in.
| Coarse, fine, detune     | A frequency ratio to the key, or a fixed
                             frequency in Hz. Detune is a few cents, more at
                             low frequencies than high.
| Algorithm, feedback      | A {fm_routing} from `{dx7_routing}`, an index
                             of 4π, and a feedback in radians: π/2 at level
                             7 for a carrier, four times that for a
                             modulator.
| LFO speed and delay      | A rate in Hz, and a wait then a fade in seconds.
| Pitch envelope           | Levels in semitones and rates in semitones a
                             second.
| Pitch and amplitude
  modulation depths        | Semitones at the LFO's peak, and a decibel cut
                             per operator at its trough, by the patch's
                             sensitivities. The mod wheel's depths are the
                             same laws at depth 99, the DX7's full wheel
                             range.
| Transpose                | Moves the key the scalings see as well as the
                             pitch.
|===

=== Sources

The laws are the DX7s measurements published by the Music Synthesizer for
Android project (Raph Levien), with Ken Shirriff's reverse engineering of
the OPS and EGS chips for the hardware behind them. What those leave out was
measured on Dexed (Pascal Gauthier), run as a black box. No emulator's source
code was read or used.

The voice differs from Dexed in three ways:

* The envelopes run on the DX7's 49,096 Hz envelope clock. Dexed runs the
  same law at the audio sample rate, so at 44.1 kHz its envelopes are 11
  percent slower.
* The arithmetic is floating point, with the envelope in double precision.
  Dexed's fixed point arithmetic adds quantization noise, audible as a
  broadband burst at each note's onset.
* At feedback 6 or 7, with a modulator near full level, Dexed's feedback
  loop turns chaotic, and this voice stays periodic.

The full account of the sources, the shape of the laws, the emulations
before this one and how the voice was checked is in the {dx7_design}.

== Declaration

```c++
enum dx_curve : std::uint8_t
{
   dx_neg_lin, dx_neg_exp, dx_pos_exp, dx_pos_lin
};

struct dx_eg_config
{
   std::uint8_t   rate[4]  = {99, 99, 99, 99};   // R1..R4
   std::uint8_t   level[4] = {99, 99, 99, 0};    // L1..L4
};

struct dx_op_config
{
   std::uint8_t   output_level  = 99;    // 0..99
   bool           fixed         = false; // fixed frequency
   std::uint8_t   coarse        = 1;     // frequency coarse 0..31
   std::uint8_t   fine          = 0;     // frequency fine 0..99
   std::uint8_t   detune        = 7;     // 0..14, 7 is none
   dx_eg_config   env;
   std::uint8_t   break_point   = 39;    // 0..99, 39 is C3
   std::uint8_t   left_depth    = 0;     // 0..99
   std::uint8_t   right_depth   = 0;
   std::uint8_t   left_curve    = dx_neg_lin;
   std::uint8_t   right_curve   = dx_neg_lin;
   std::uint8_t   rate_scaling  = 0;     // 0..7
   std::uint8_t   amp_mod_sens  = 0;     // 0..3
   std::uint8_t   velocity_sens = 0;     // 0..7
};

struct dx_algorithm_config
{
   std::uint8_t   algorithm = 1;         // 1..32
   std::uint8_t   feedback  = 0;         // 0..7
};

struct dx_lfo_config
{
   std::uint8_t   speed     = 35;        // 0..99
   std::uint8_t   delay     = 0;         // 0..99
   bool           key_sync  = true;
   std::uint8_t   wave      = lfo_gen::triangle;
};

struct dx_patch
{
   using eg_config = dx_eg_config;

   dx_op_config   op[6];                 // OP1..OP6
   eg_config      pitch_env = {{99, 99, 99, 99}, {50, 50, 50, 50}};
   dx_algorithm_config algorithm;
   dx_lfo_config  lfo;
   std::uint8_t   pitch_mod_depth = 0;   // LFO PMD 0..99
   std::uint8_t   amp_mod_depth = 0;     // LFO AMD 0..99
   std::uint8_t   pitch_mod_sens = 3;    // 0..7
   bool           osc_key_sync = true;
   std::uint8_t   transpose = 24;        // 0..48, 24 is C3
   char           name[11] = "INIT VOICE";
};

struct dx_op_patch
{
   double         ratio[128];            // to the key's
   phase          fixed_step;            // fixed mode
   std::uint8_t   qrate[4];              // envelope rates
   std::uint8_t   qrate_offset[128];     // rate scaling per key
   float          output_db[128];        // output level per key
   float          velocity_db[128];      // dB per velocity
   float          eg_db[4];              // envelope levels
};

struct dx_patcher
{
   using curve = dx_curve;
   using config = dx_patch;
   using op_config = dx_op_config;
   using op_patch = dx_op_patch;

   static constexpr auto neg_lin = dx_neg_lin;
   static constexpr auto neg_exp = dx_neg_exp;
   static constexpr auto pos_exp = dx_pos_exp;
   static constexpr auto pos_lin = dx_pos_lin;

                  dx_patcher(config const& cfg, float sps);

   void           note(
                     std::uint8_t key, float velocity, fm_note& out
                  ) const;

   config         cfg;
   float          sps;
   fm_voice_config voice;
   op_patch       op[6];
   double         rate_time[64];         // seconds, per qrate
};
```

`dx_op_patch` is one compiled operator: the tables `note` reads for a key
and a velocity.

== Expressions

=== Notation

`patch`, `a`, `b`  :: Objects of type `dx_patcher`.
`cfg`              :: Object of type `dx_patch`.
`op`               :: Object of type `dx_op_config`.
`eg`               :: Object of type `dx_eg_config`.
`sps`              :: Floating point value for samples per second.
`key`              :: `std::uint8_t` value for a MIDI key number, 0 to 127.
`velocity`         :: Floating point value from 0.0 to 1.0.
`n`                :: Object of type `fm_note`.
`i`                :: `std::size_t` operator index, from 0 (OP1) to 5 (OP6).
`j`                :: `std::size_t` envelope segment index, from 0 (R1, L1)
                      to 3 (R4, L4).
`k`                :: `std::size_t` internal rate, from 0 to 63.

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression                 | Semantics

| `dx_patcher(cfg, sps)`     | Construct a `dx_patcher` by compiling `cfg`
                               (patch) for `sps` (samples per second).
| `dx_patcher(patch)`        | Copy construct from `dx_patcher patch`.
| `a = b`                    | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used.

=== Operation

[cols="1,1,1"]
|===
| Expression                      | Semantics                       | Return Type

| `patch.note(key, velocity, n)`  | Fill `n` with the note for
                                    `key` at `velocity`: each
                                    operator's ratio or fixed step,
                                    and its envelope in decibels and
                                    seconds.                        | `void`
|===

=== Example

Play the factory patch E.PIANO 1 at `sps` samples per second:

```c++
namespace q = cycfi::q;

// E.PIANO 1, as a cartridge stores it
q::dx_patcher::config cfg = {
   .op = {
      {                        // OP1, the tine's carrier
         .output_level = 99,
         .coarse = 1,          // at the note
         .detune = 10,         // three steps sharp
         .env = {{96, 25, 25, 67}, {99, 75, 0, 0}}
      },
      {                        // OP2, the ping that strikes it
         .output_level = 58,
         .coarse = 14,         // fourteen times the note
         .env = {{95, 50, 35, 78}, {99, 75, 0, 0}},
         .velocity_sens = 7    // harder playing, brighter ping
      }
      // ... four more operators
   },
   .algorithm = {5, 6},        // algorithm 5, feedback 6
   .lfo = {.speed = 34, .delay = 33},
   .name = "E.PIANO 1"
};

q::dx_patcher patch{cfg, sps};                                 <1>
q::fm_voice voice{patch};                                      <2>
voice.attack(patch, 60, 0.7f);                                 <3>
```

<1> Compile the patch for the sample rate, once.
<2> Construct a voice of six sine operators from the patcher's voice
    configuration and sample rate.
<3> Start middle C at velocity 0.7, with the note the patcher compiles for
    that key and velocity.
