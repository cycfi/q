= FM Voice

include::../../../common.adoc[]

== Overview

`basic_fm_voice` is one sounding note: a set of {fm_operator} through an
{fm_algorithm}, with an {lfo_gen} for vibrato and tremolo and a pitch
envelope. `fm_voice` is the DX7's shape, six sine operators with the DX7
envelope, and a voice of any other size or make is a matter of listing the
operator types:

```c++
#include <q/synth/fm/fm_voice.hpp>
#include <q/synth/va/saw_osc.hpp>
...
namespace q = cycfi::q;
...
using fm_voice = q::basic_fm_voice<
   q::fm_operator, q::fm_operator, q::fm_operator
 , q::fm_operator, q::fm_operator, q::fm_operator>;

// Two operators, a saw modulating a sine
q::basic_fm_voice<
   q::fm_operator,
   q::basic_fm_operator<q::basic_saw_osc, q::dx_envelope_gen>
> voice;
```

The pitch is the caller's. Each sample the voice takes a `{phase_iterator}`,
bends it by the LFO and the pitch envelope, and passes it to the operators,
which follow it by their ratios. A keyboard, a pitch detector, a glide or a
bend can drive a voice alike.

=== A Note Is Data

`attack` takes a `note`: per operator, a frequency ratio (or a fixed step)
and an envelope configuration. Everything that varies with the key and the
velocity is in the note, so a patch compiler can precompute it.

A `Patcher` is such a compiler: a type that holds a voice configuration,
`voice`, and its sample rate, `sps`, and fills a note for a key and a
velocity (0 to 1) with `note(key, velocity, n)`. {dx_patcher} is one. The
concept, `concepts::Patcher`, is in the Declaration below. A voice takes a
patcher directly:

```c++
#include <q/synth/fm/fm_voice.hpp>
#include <q/synth/fm/dx_patcher.hpp>
...
namespace q = cycfi::q;

float sps;                                 // samples per second
q::dx_patcher patch{q::dx_patch{}, sps};   // a Patcher
q::fm_voice voice{patch};
std::uint8_t key = 69;                     // A4
float velocity = 0.8f;
...
voice.attack(patch, key, velocity);      // the patcher fills the note
```

=== What the Voice Owns

The LFO runs once per sample and feeds two things: the pitch, by
`pitch_mod` semitones at its peak, and each operator's gain, cut by
`amp_mod[i]` decibels at its trough. Tremolo is applied to each operator's
gain, so an operator with tremolo that modulates another changes the timbre
of what it modulates.

The pitch envelope ramps in semitones between its four levels, at its four
rates. It starts at the fourth level, runs through the first three, and
holds at the third until the release, which ramps it back to the fourth.

image::fm_voice_owns.svg[alt="What the voice owns: the operators, the algorithm, the LFO and the pitch envelope, with the pitch and the note coming from outside", width=750px, align=center, title="What the voice owns, inside the dashed line: the operators, the algorithm that runs them, the LFO and the pitch envelope. The pitch and the note come from the caller. The LFO reaches both the pitch and each operator's gain.", link={imagesdir}/fm_voice_owns.svg]

* `master` is the caller's `{phase_iterator}`.
* `attack(note)` gives every operator its ratio and its envelope.
* The pitch envelope bends the pitch in semitones, and the LFO adds vibrato to it.
* The LFO also applies tremolo to each operator's gain.
* The algorithm holds the routing, the index and the feedback, and each operator has its own phase and envelope.

=== While the Note Sounds

Three controls reach a note that is already sounding.

* The mod wheel, 0 to 1, deepens the vibrato and the tremolo toward the
  configuration's wheel depths, `pitch_mod_wheel` and `amp_mod_wheel[i]`.
  Each depth is the larger of the LFO's own depth and the wheel's share of
  the wheel depth, as on the DX7.
* `enable` takes a mask with a bit per operator. An operator whose bit is
  clear neither sounds nor modulates, so an editor can play one operator
  alone, or the voice without it.
* `update` gives the note a new patch. Each part takes its new settings and
  continues from where it is, as a DX7's sounding notes follow a voice
  change or an edit: the envelopes keep their place and move toward the new
  levels at the new rates, and the pitch envelope, the LFO and the phases
  carry on. A released note held at an audible release level fades when the
  new level is lower.

`set` gives the voice its settings for the next note, and `attack` starts a
note from the beginning.

== Include

```c++
#include <q/synth/fm/fm_voice.hpp>
```

The example below also uses `<q/synth/fm/dx_patcher.hpp>` for the patcher and

== Declaration

```c++
struct fm_voice_config
{
   fm_algorithm::config  algorithm;
   lfo_gen::config       lfo;
   float                 pitch_mod = 0.0f;  // semitones at the LFO's peak

   // a cut in decibels at the LFO's trough, one per operator
   float                 amp_mod[fm_max_operators] = {};

   // The depths the mod wheel reaches at full: it takes each from
   // the one above toward these, whichever is the deeper.
   float                 pitch_mod_wheel = 0.0f;   // semitones
   float                 amp_mod_wheel[fm_max_operators] = {};  // dB

   std::array<float, 4>  pitch_env_level = {};  // semitones
   std::array<float, 4>  pitch_env_rate = {};   // semitones per second
   bool                  key_sync = true;   // phases restart at note-on
};

template <typename Env>
struct basic_fm_note
{
   struct op_params
   {
      double         ratio = 1.0;
      phase          fixed_step = {};
      typename Env::config env;
   };

   op_params      op[fm_max_operators];
};

using fm_note = basic_fm_note<dx_envelope_gen>;

namespace concepts
{
   template <typename T, typename Note>
   concept Patcher =
      requires(T const& p, std::uint8_t key, float velocity, Note& n)
      {
         { p.voice } -> std::convertible_to<fm_voice_config>;
         { p.sps } -> std::convertible_to<float>;
         p.note(key, velocity, n);
      };
}

template <typename Op, typename... RestOps>
struct basic_fm_voice
{
   static constexpr std::size_t size = 1 + sizeof...(RestOps);

   using envelope_type = typename Op::envelope_type;
   using config = fm_voice_config;
   using note = basic_fm_note<envelope_type>;

                  basic_fm_voice();
                  basic_fm_voice(config const& cfg, float sps);
                  template <concepts::Patcher<note> P>
                  basic_fm_voice(P const& patch);

   void           set(config const& cfg, float sps);
   void           update(config const& cfg, note const& n);
                  template <concepts::Patcher<note> P>
   void           update(P const& patch, std::uint8_t key, float velocity);

   void           attack(note const& n);
                  template <concepts::Patcher<note> P>
   void           attack(P const& patch, std::uint8_t key, float velocity);
   void           release();
   bool           active() const;

   void           mod_wheel(float w);
   float          mod_wheel() const;
   void           enable(fm_routing::mask m);
   fm_routing::mask
                  enabled() const;

   float          operator()(phase_iterator master);
};

using fm_voice = basic_fm_voice<
   fm_operator, fm_operator, fm_operator
 , fm_operator, fm_operator, fm_operator>;
```

`Op` and `RestOps` are `basic_fm_operator` types (see {fm_operator}), one to
`{fm_max_operators}` in all, with the same `envelope_type`.

== Expressions

=== Notation

`Op`, `RestOps`  :: `basic_fm_operator` types with the same `envelope_type`.
`Env`            :: A type that conforms to `{EnvelopeGenerator}`.
`v_type`         :: A `basic_fm_voice<Op, RestOps...>` type.
`v`, `a`, `b`    :: Objects of type `v_type`.
`cfg`            :: Object of type `fm_voice_config`.
`n`              :: Object of type `v_type::note`.
`patch`          :: Object of a type that conforms to `{Patcher}<v_type::note>`,
                    e.g. a {dx_patcher}.
`key`            :: `std::uint8_t` value for a MIDI key number, 0 to 127.
`velocity`       :: Floating point value from 0.0 to 1.0.
`master`         :: Object of type `{phase_iterator}`: the pitch to play.
`w`              :: Floating point value from 0.0 to 1.0 for the mod wheel.
`m`              :: Object of type `fm_routing::mask` (see {fm_routing}): a bit
                    per operator, bit 0 for the first.
`i`              :: `std::size_t` operator index, from 0 to `v_type::size - 1`.
`sps`            :: Floating point value for samples per second.

NOTE: Every operator of the voice needs its own entry in `n.op`, and in
`cfg.amp_mod` and `cfg.amp_mod_wheel`. A voice reads the first
`v_type::size` entries.

=== Example

Play DX7 patches on a pool of voices, as in the poly synth example, at
`sps` samples per second, starting a note on a key:

```c++
#include <q/synth/fm/fm_voice.hpp>
#include <q/synth/fm/dx_patcher.hpp>
#include <q/midi/note.hpp>  // For note_frequency
#include <algorithm>
#include <vector>
...
namespace q = cycfi::q;

std::uint8_t key;                   // the MIDI key
float velocity;                     // 0 to 1
...
q::dx_patch preset;                 // a DX7 patch, e.g. from dx_cartridge
q::dx_patcher patch{preset, sps};   // compiled once, shared by the pool

std::vector<q::fm_voice> pool(16, q::fm_voice{patch});           <1>
std::vector<q::phase_iterator> pitch(16);

// A note on: take a free voice, give it the key's pitch, and start it
auto free = std::find_if(pool.begin(), pool.end(),
   [](auto& v) { return !v.active(); });                          <2>

if (free != pool.end())
{
   auto i = free - pool.begin();
   pitch[i].set(q::midi::note_frequency(key), sps);
   free->attack(patch, key, velocity);                            <3>
}

// Per sample: every voice that is still sounding, at its own pitch
float out = 0;
for (std::size_t i = 0; i != pool.size(); ++i)
   if (pool[i].active())
      out += pool[i](pitch[i]++);                                 <4>
```

<1> Construct a voice from the patcher, and copy it to fill the pool.
<2> Find a voice that is not sounding.
<3> Start the note the patcher compiles for the key and the velocity.
<4> Generate one sample of each sounding voice at its own pitch, then
    advance that pitch.

Each voice has its own master iterator, so a pitch bend or a per-string
detector can move one note without touching the others.
