= DX Envelope Generator

include::../../../common.adoc[]

== Overview

`dx_envelope_gen` is a four rate, four level envelope in the log domain. The
four-and-four shape and the attack curve are the DX7's, and the envelope
serves any synth. Its constants, `floor`, `attack_from` and `fastest`, come
from the DX7. Its parameters are in decibels and seconds; {dx_patcher} maps
a patch's own 0 to 99 counts to them.

image::dx_envelope.svg[alt="The attack curve against a constant slope, and a whole note", width=700px, align=center, title="Top: the attack climbs faster the further below full it is, reaching 0 dB in 124 ms where a constant slope of the same rate is still 39 dB down. Bottom: the DX7's own front panel diagram of the envelope, R1 up to L1, R2 to L2, R3 to L3, the hold, and R4 to L4 at key off. It is a schematic, as the panel's is, and the plot above is what the attack really does.", link={imagesdir}/dx_envelope.svg]

Levels are `{decibel}`, 0 dB being full and negative below. A rate is a
slope, given as a `{duration}`: the time a segment would take to travel the
envelope's whole range, floor to full. A segment covering less of the range
takes proportionally less time, so a rate is a speed, not a segment length.

`attack()` runs R1 to L1, R2 to L2, R3 to L3 and holds there. `release()`
runs R4 to L4 from wherever the level is, then goes idle once silent, or
holds at L4 if L4 is audible. Both start from the current level, so a
retrigger or an early key-off is click-free.

Each call returns the linear gain of the current level, times a master
volume, `gain`, which is 1 by default.

=== The Attack Curve

A decay falls at its rate. An attack climbs faster: its rate times 2 plus the
number of doublings (6 dB) it is below full, so it is quick at the bottom and
slows toward the top. From silence it starts at `attack_from`, about -50 dB,
skipping the climb from the floor.

With a rate of one second for the whole range, the attack climbs 810 dB a
second at -48 dB, 450 at -24, 270 at -12, and 180 through the last 6 dB. It
takes 124 ms, where a constant slope takes 555 ms, and 27 percent of that
time goes on the final 6 dB. A constant-slope attack in the log domain is an
exponential rise: inaudible for most of its travel, then a rush at the end.
This law spends 45 percent of the attack in the top 12 dB, where it is
heard; a constant slope spends 24 percent there.

A quieter operator reaches its peak sooner, by more than its level ratio,
since its target sits in a band where the multiplier is still large.
Velocity and keyboard scaling therefore change a DX7's attack timing as well
as its loudness.

NOTE: The law is as measured on a DX7s, published on the Music Synthesizer
for Android wiki. `dx_envelope_gen` models an `{EnvelopeGenerator}`, so an
operator or a voice can take a different envelope in its place.

== Include

```c++
#include <q/synth/fm/dx_envelope_gen.hpp>
```

== Declaration

```c++
struct dx_envelope_gen
{
   static constexpr decibel floor = dB(-89.93);
   static constexpr decibel attack_from = dB(-49.95);
   static constexpr decibel range = dB(89.93);
   static constexpr duration fastest = duration{0.00556};

   struct config
   {
      duration       rate[4] = {fastest, fastest, fastest, fastest};
      decibel        level[4] = {dB(0), dB(0), dB(0), floor};
   };

   enum phase_index : std::uint8_t
   {
      r1, r2, r3, sustain, release_phase, idle
   };

                  dx_envelope_gen();
                  dx_envelope_gen(config const& cfg, float sps);

   void           set(config const& cfg, float sps);

   void           attack();
   void           release();
   void           reset();

   void           gain(float g);
   float          gain() const;

   float          operator()();
   float          level() const;
   std::size_t    index() const;
   bool           in_idle_phase() const;
   bool           in_release_phase() const;
};
```

== Expressions

`dx_envelope_gen` is a model of `{EnvelopeGenerator}`. In addition to valid
expressions for {EnvelopeGenerator}, `dx_envelope_gen` allows these
expressions.

=== Notation

`e`            :: Object of type `dx_envelope_gen`.
`cfg`          :: Object of type `dx_envelope_gen::config`.
`i`            :: `std::size_t` segment index, from 0 (R1 and L1) to 3 (R4
                  and L4).

=== Constructors

[cols="1,1"]
|===
| Expression                 | Semantics

| `dx_envelope_gen()`        | Construct an idle, silent `dx_envelope_gen`
                               with the default configuration at 44.1 kHz.
|===

=== Accessors

[cols="1,1,1"]
|===
| Expression          | Semantics                                   | Return Type

| `e.level()`         | Get the current level in decibels.          | `float`
| `e.index()`         | Get the current phase, a `phase_index`
                        value.                                      | `std::size_t`
|===

=== Access

[cols="1,1,1"]
|===
| Expression                        | Semantics                     | Return Type

| `dx_envelope_gen::floor`          | Get the level below which the
                                      envelope is silent,
                                      -89.93 dB.                    | `{decibel}`
| `dx_envelope_gen::attack_from`    | Get the level an attack from
                                      silence starts at, -49.95 dB. | `{decibel}`
| `dx_envelope_gen::range`          | Get the range a rate's time
                                      covers, floor to full,
                                      89.93 dB.                     | `{decibel}`
| `dx_envelope_gen::fastest`        | Get the DX7's fastest rate,
                                      5.56 ms.                      | `{duration}`
| `cfg.rate[i]`                     | Get the rate of segment `i`:
                                      the time the whole range
                                      would take at that slope.
                                      Defaults to `fastest`.        | `{duration}`
| `cfg.level[i]`                    | Get the target level of
                                      segment `i`, 0 dB full. A
                                      level below `floor` is
                                      silent. Defaults to 0 dB, and
                                      to `floor` for L4.            | `{decibel}`
|===

=== Example

Shape a sine with an electric piano's envelope: a quick attack, a long
decay, and a short release, at `sps` samples per second:

```c++
#include <q/synth/fm/dx_envelope_gen.hpp>
#include <q/synth/sin_osc.hpp>  // For sin
#include <span>
...
namespace q = cycfi::q;
using namespace q::literals;

std::span<float> buffer;            // the output
...
q::dx_envelope_gen::config cfg = {
   .rate = {
      3_ms,     // R1: the strike
      700_ms,   // R2: down to the body of the note
      4_s,      // R3: the long tail
      120_ms    // R4: the release
   },
   .level = {
      0_dB,                       // L1: full
      -12_dB,                     // L2
      -40_dB,                     // L3: where it holds until key off
      q::dx_envelope_gen::floor   // L4: silence
   }
};

q::dx_envelope_gen env{cfg, sps};                <1>
env.attack();                                    <2>

q::phase_iterator ph{440_Hz, sps};
for (auto& s : buffer)
   s = q::sin(ph++) * env();                     <3>
```

<1> Construct the envelope from the configuration.
<2> Start the attack, R1 to L1.
<3> Scale the sine by the envelope's gain for this sample.

To make the same envelope 12 dB quieter the way a DX7 does, subtract 12 dB
from every level instead of scaling the output: the attack then reaches its
peak sooner, as on a DX7.
