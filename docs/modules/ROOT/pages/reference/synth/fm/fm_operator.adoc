= FM Operator

include::../../../common.adoc[]

== Overview

An FM operator is an oscillator with its own phase and its own envelope. It
is the unit an FM synthesizer is built from: one operator's output bends
another's phase, and a handful wired that way make the whole instrument.
{fm_algorithm} does the wiring; an operator holds its own phase, its
envelope, and this sample's modulation.

image::fm_operator_flow.svg[alt="One operator: the master's step scaled by ratio, the modulation added to the phase, the oscillator, and the envelope", width=750px, align=center, title="One operator, one sample. The master's step times `ratio` advances the operator's own phase, this sample's modulation is added to that phase, the oscillator is called there, and the envelope scales what comes out. A fixed step goes straight to the phase and ignores the master.", link={imagesdir}/fm_operator_flow.svg]

* `master` is the voice's `{phase_iterator}`. Its step times `ratio` advances the operator's own phase.
* `fixed(step)` sets the step directly and ignores the master.
* `modulation(mod)` adds this sample's modulation to the phase.
* The envelope takes attack, release and gain, and the output is `osc(phase + mod) * env()`.

`basic_fm_operator` takes both parts as template parameters, the oscillator
and the envelope generator, and `fm_operator` is the pairing the DX7 uses, a
sine with the DX7 shaped envelope. Any `{Oscillator}` and any
`{EnvelopeGenerator}` will do, so an operator can be a saw, or carry an
`{adsr_envelope_gen}` instead, for example.

```c++
#include <q/synth/fm/fm_operator.hpp>
#include <q/synth/va/saw_osc.hpp>
...
namespace q = cycfi::q;
...
// The usual pairing: the same type as q::fm_operator
using sine_operator = q::basic_fm_operator<q::sin_osc, q::dx_envelope_gen>;

// A saw instead, for a modulator with harmonics of its own
using saw_operator = q::basic_fm_operator<q::basic_saw_osc, q::dx_envelope_gen>;
```

The pitch comes from the caller. Every sample the operator takes a
`{phase_iterator}`, the voice's master, and derives its own step from it by
`ratio`, so one iterator drives every operator and the whole voice
follows a pitch change within a sample. An operator set to a `fixed`
frequency ignores the master. Its own phase accumulates separately, since a
ratio of 1.5 or a detuned 1.0 cannot share a phase with the master, and
`sync` restarts it.

NOTE: The operator does not advance the master; the caller does. The
operator advances its own phase on every call.

=== Modulation and Gain

Phase modulation is an offset added to the operator's phase before the
oscillator is called, and the gain is a multiplier on its output.
{fm_algorithm} sets the modulation every sample, from the modulators'
outputs, and {fm_voice} sets the gain every sample, from its tremolo. Both
are properties, so the call keeps the form of an oscillator call:
`op(master)`.

The operator's output level is in its envelope's levels, so scaling by
velocity or key is one addition in decibels.

== Declaration

```c++
template <
   concepts::Oscillator Osc = sin_osc
 , concepts::EnvelopeGenerator Env = dx_envelope_gen
>
struct basic_fm_operator
{
   using envelope_type = Env;

                  basic_fm_operator();

   void           ratio(double r);
   void           fixed(phase step);
   void           envelope(typename Env::config const& cfg, float sps);

   void           attack();
   void           release();
   void           sync();
   bool           active() const;

   void           modulation(phase mod);
   phase          modulation() const;
   void           gain(float g);
   float          gain() const;

   float          operator()(phase_iterator master);

   Osc            osc;
};

using fm_operator = basic_fm_operator<sin_osc, dx_envelope_gen>;
```

== Expressions

=== Notation

`Osc`          :: A type that conforms to `{Oscillator}`.
`Env`          :: A type that conforms to `{EnvelopeGenerator}`.
`op_type`      :: A `basic_fm_operator<Osc, Env>` type.
`op`, `a`, `b` :: Objects of type `op_type`.
`master`       :: Object of type `{phase_iterator}`: the pitch the voice plays.
`r`            :: `double` value for the frequency ratio to the master.
`step`         :: Object of type `{phase}`: the per sample step of a fixed frequency.
`cfg`          :: Object of type `Env::config`.
`sps`          :: Floating point value for samples per second.
`mod`          :: Object of type `{phase}`: this sample's phase offset.
`g`            :: Floating point value for a linear gain.

=== Type Construction

[cols="1,1"]
|===
| Expression                       | Semantics

| `basic_fm_operator<Osc, Env>`    | Instantiate a `basic_fm_operator` type
                                     given the oscillator type `Osc` and the
                                     envelope generator type `Env`.
| `basic_fm_operator<Osc>`         | Instantiate a `basic_fm_operator` type
                                     given `Osc`, with a `dx_envelope_gen`.
| `basic_fm_operator<>`            | Instantiate a `basic_fm_operator` type
                                     with a `sin_osc` and a `dx_envelope_gen`.
| `fm_operator`                    | Pre declared `basic_fm_operator<sin_osc,
                                     dx_envelope_gen>` type.
|===

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression                       | Semantics

=== Function Call

[cols="1,1,1"]
|===
| Expression          | Semantics                                   | Return Type

| `op(master)`        | Generate one sample at the pitch of
                        `master` and advance the operator's own
                        phase.                                      | `float`
|===

=== Operation

[cols="1,1,1"]
|===
| Expression          | Semantics                                   | Return Type

| `op.attack()`       | Start the envelope, from its current
                        level.                                      | `void`
| `op.release()`      | Release the envelope, from its current
                        level.                                      | `void`
| `op.sync()`         | Restart the operator's phase at zero.       | `void`
|===

=== Mutators

[cols="1,1,1"]
|===
| Expression              | Semantics                               | Return Type

| `op.ratio(r)`           | Set the frequency to `r` times the
                            master's.                               | `void`
| `op.fixed(step)`        | Set a fixed frequency given `step`
                            (phase step per sample), ignoring the
                            master.                                 | `void`
| `op.envelope(cfg, sps)` | Set the envelope given `cfg`
                            (configuration) and `sps` (samples per
                            second). The level the operator sounds
                            at is in `cfg`.                         | `void`
| `op.modulation(mod)`    | Set this sample's phase offset.         | `void`
| `op.gain(g)`            | Set the output gain, the envelope's
                            master volume.                          | `void`
|===

=== Accessors

[cols="1,1,1"]
|===
| Expression              | Semantics                               | Return Type

=== Example

Wire two operators by hand, one modulating the other an octave up, at
`sps` samples per second:

```c++
#include <q/synth/fm/fm_operator.hpp>
#include <q/synth/fm/fm_algorithm.hpp>  // For fm_algorithm
#include <span>
...
namespace q = cycfi::q;
using namespace q::literals;

std::span<float> buffer;            // the output
...
constexpr auto silent = q::dx_envelope_gen::floor;

q::dx_envelope_gen::config mod_env = {
   .rate  = {5_ms, 150_ms, 1_s, 300_ms},
   .level = {-6_dB, -18_dB, -30_dB, silent}
};

q::dx_envelope_gen::config car_env = {
   .rate  = {5_ms, 200_ms, 1_s, 300_ms},
   .level = {0_dB, -6_dB, -12_dB, silent}
};

q::fm_operator mod, car;                                      <1>

mod.ratio(2.0);                                               <2>
mod.envelope(mod_env, sps);
car.ratio(1.0);
car.envelope(car_env, sps);

mod.attack();                                                 <3>
car.attack();

q::phase_iterator master{440_Hz, sps};
constexpr auto index = 4 * q::pi;   // radians per unit of modulator

for (auto& s : buffer)
{
   auto deviation = q::fm_algorithm::deviation(mod(master) * index);   <4>
   car.modulation(deviation);                                 <5>
   s = car(master++);                                         <6>
}
```

<1> Construct two sine operators with the DX7 shaped envelope.
<2> Set the modulator an octave above the note, and give it its envelope.
<3> Start both envelopes.
<4> Generate the modulator's sample and convert it to a phase offset of up
    to `index` radians, using {fm_algorithm}.
<5> Set the carrier's phase offset for this sample.
<6> Generate the carrier's sample, then advance the master.
