= Audio Device

include::../../common.adoc[]

== Overview

NOTE: This page documents *q_io*, the optional audio and MIDI I/O library, not *q_lib*. See {q_io}.

`audio_device` represents individual audio interfaces on the host platform. There are typically one or more audio devices available. Each device has a name, device identifier, and specific capabilities, including sample rate and the number of input and output channels supported.

Device IDs are assigned by Q: 1, 2, 3 and so on, in the order the devices are found, and they stay the same for the life of the program. On Windows the list holds the devices of every audio API Q was built with, ASIO and WASAPI alike. A device that goes away stays in the list; opening a stream on it fails with "The audio device is not available."

`audio_device::default_id` stands for the device chosen as default in the OS settings. It is not in the list. `get(default_id)` returns an entry named "Default" carrying the channel counts of the default input and output devices and the default output device's sample rate, read on the first call to `get(default_id)`. A stream opened on it uses whatever device is the OS default when the stream opens. On Windows the default is never an ASIO driver; reach ASIO by choosing its device from the list.

== Include

```c++
#include <q_io/audio_device.hpp>
```

== Declaration

```c++
class audio_device
{
public:

   using device_list = std::vector<audio_device>;

   static constexpr int    default_id = -1;

   static device_list      list();
   static audio_device     get(int device_id);

   int                     id() const;
   std::string             name() const;
   std::size_t             input_channels() const;
   std::size_t             output_channels() const;
   double                  default_sample_rate() const;
};
```

== Expressions

=== Notation

`ad`, `b`       :: Objects of type `audio_device`.
`id`            :: Integer value for an audio device ID.

=== Constructors

[cols="1,1"]
|===
| Expression            | Semantics

| `audio_device(b)`     | Copy construct from `audio_device b`.
|===

NOTE: C++ brace initialization may also be used.

* There are no public constructors. Instead, see `list()` and `get(id)` below.
* `audio_device`s are lightweight handles that can be cheaply passed by value.

=== Instantiation

[cols="1,1,1"]
|===
| Expression                    | Semantics                                     | Return Type

| `audio_device::list()`        | Get the list of available audio devices.      | `std::vector<audio_device>`
| `audio_device::get(id)`       | Get the audio device with the given ID.
                                  An ID that is not in the list returns the
                                  first device in the list.                     | `audio_device`
| `audio_device::get(
   audio_device::default_id)`   | Get the "Default" entry, standing for the
                                  OS default device.                            | `audio_device`
|===

* To get an `audio_device`, first get the list of currently available audio devices via `audio_device::list()`,
  then choose, or let the user choose, the one suitable for your needs.
* Alternatively, if you know the unique `audio_device` ID, you can use `audio_device::get(id)` to obtain
  a specific `audio_device`.

=== Access

[cols="1,1,1"]
|===
| Expression                    | Semantics                                     | Return Type

| `audio_device::default_id`    | Get the pseudo ID of the OS default device.   | `int`
|===

=== Accessors

[cols="1,1,1"]
|===
| Expression                    | Semantics                                     | Return Type

| `ad.id()`                     | Get the unique ID.                            | `int`
| `ad.name()`                   | Get the name. Two devices can share a name;
                                  a stream opened on either uses the first.     | `std::string`
| `ad.input_channels()`         | Get the maximum number of input channels.     | `std::size_t`
| `ad.output_channels()`        | Get the maximum number of output channels.    | `std::size_t`
| `ad.default_sample_rate()`    | Get the default sample rate.                  | `double`
|===

=== Example

List all available audio devices, with their IDs, names and channel counts:

```c++
#include <q_io/audio_device.hpp>
#include <iostream>
#include <string>

namespace q = cycfi::q;

int main()
{
   std::cout << "Available Audio Devices: " << std::endl;
   for (auto const& device : q::audio_device::list())            <1>
   {
      std::cout
         << "id: " << device.id() << std::endl                     <2>
         << "name: \"" << device.name() << '"' << std::endl
         << "number of input channels: " << device.input_channels() << std::endl
         << "number of output channels: " << device.output_channels() << std::endl
         ;
   }
   return 0;
}
```

<1> Get the list of available audio devices.
<2> Print each device's ID, name, and number of input and output channels.
