= midi_input_stream and midi_output_stream

include::../../common.adoc[]

== Overview

NOTE: This page documents *q_io*, the optional audio and MIDI I/O library, not *q_lib*. See {q_io}.

The `midi_input_stream` class facilitates MIDI communication and data transmission of MIDI messages between a MIDI device and an application.

`midi_input_stream` dispatches MIDI messages to a MIDI processor: a user-defined construct that follows a specific C++ concept for receiving and interpreting MIDI messages. The MIDI processor acts as an intermediary between MIDI devices and the application. Its purpose is to receive incoming MIDI messages, analyze their content, and extract relevant information. This may include extracting note data, control change values, program change commands, or any other MIDI message content that is of interest to the user. See {midi_processor}. `midi_input_stream` conforms to the {midi_source} concept, so a processor written for it runs unchanged on any other source. Channel messages dispatch as the messages of {midi_messages}; a system exclusive arrives whole as a `sysex_view`, its markers stripped, up to 16 KB.

`midi_output_stream` sends MIDI 1.0 to a device, or out of a virtual port of a given name that other programs may open. `send` takes one whole message, system exclusive included, as a `byte_span`, or a message struct such as `note_on` directly. It is a {midi_sink} over `byte_span`, so the MIDI-CI responders of {midi_ci} send through it as they are. For Universal MIDI Packets see {midi2_stream}.

== Include

```c++
#include <q_io/midi_stream.hpp>
```

== Declaration

```c++
class midi_input_stream : non_copyable
{
public:
                        midi_input_stream();
                        midi_input_stream(midi_device const& device);
                        ~midi_input_stream();

   bool                 is_valid() const;

                        template <typename P>
                        requires concepts::midi::Processor<P>
   void                 process(P&& proc);

                        template <typename Processor>
   void                 process_raw(Processor&& proc);

   static void          set_default_device(int id);
};

class midi_output_stream : non_copyable
{
public:
                        midi_output_stream(midi_device const& device);
                        midi_output_stream(char const* virtual_port);
                        ~midi_output_stream();

   bool                 is_valid() const;
   void                 send(byte_span bytes);

                        template <int N>
   void                 send(midi_1_0::message<N> const& msg);
};
```

== Expressions

=== Notation

`ms`           :: Object of type `midi_input_stream`.
`out`          :: Object of type `midi_output_stream`.
`md`           :: Object of type `midi_device`, see {midi_device}.
`id`           :: A unique MIDI device ID (integer).
`name`         :: A `char const*`, the name of a virtual port to create.
`proc`         :: Object that conforms to the `Processor` concept on {midi_processor}.
`bytes`        :: A `byte_span`, one whole MIDI 1.0 message. See {base}.
`msg`          :: A MIDI 1.0 message struct of {midi_messages}, such as `note_on`.

=== Constructors

[cols="1,1"]
|===
| Expression                  | Semantics

| `midi_input_stream()`       | Construct a default `midi_input_stream`. See `set_default_device` below.
| `midi_input_stream(md)`     | Construct a `midi_input_stream` using the `midi_device`, `md`.
| `midi_output_stream(md)`    | Open the MIDI 1.0 device `md` for output.
| `midi_output_stream(name)`  | Create a virtual output port called `name`, which other programs may receive from.
|===

Both streams are non-copyable.

=== Default MIDI device

[cols="1,1"]
|===
| Expression                  | Semantics

| `set_default_device(id)`    | Set the default `midi_device` used by the default constructor above
                                to the `midi_device` with the given ID. Once set, the default
                                `midi_input_stream` constructor will use this `midi_device`.
|===

=== Accessor

[cols="1,1,1"]
|===
| Expression                     | Semantics                               | Return Type

| `ms.is_valid()`                | Check if the `midi_input_stream` is
                                   valid. Do this before any operation on
                                   the `midi_input_stream`. Any operation
                                   on an invalid stream is undefined
                                   behavior.                               | `bool`
| `out.is_valid()`               | The same for the output stream.         | `bool`
|===

=== Process MIDI

[cols="1,1"]
|===
| Expression            | Semantics

| `ms.process(proc)`    | Process incoming MIDI messages, given a user provided MIDI processor `proc`. A system exclusive arrives whole, as the `sysex_view` of {midi_readers}, so the MIDI-CI responders of {midi_ci} run on this stream.
| `ms.process_raw(proc)` | The same for channel messages, but `proc.process_midi(msg, time)` receives the `raw_message` of {midi_messages} undispatched, for a processor that reads the bytes itself. System exclusive is not delivered on this path.
|===

Call this function in a loop to process incoming MIDI messages. This function blocks. It is advisable to place this processing loop in a separate thread.

=== Send MIDI

[cols="1,1"]
|===
| Expression            | Semantics

| `out.send(bytes)`     | Send one whole message: a channel message of one to three bytes, or a system exclusive from its 0xF0 to its 0xF7.
| `out.send(msg)`       | Send the message struct `msg`.
|===

`send` may be called from anywhere a message is ready, including from inside a processor that `process` is running, so a MIDI-CI responder replies through it directly.

=== Example

Monitor incoming MIDI messages:

```c++
q::midi_input_stream stream;              <1>
if (stream.is_valid())                    <2>
{
   while (true)                           <3>
      stream.process(midi_processor{});   <4>
}
```

<1> Instantiate a default MIDI stream.
<2> Check if the MIDI `stream` is valid.
<3> Infinite loop, processing incoming MIDI messages from the `stream`.
<4> `midi_processor` is a user defined struct implemented below.

```c++
struct midi_processor : midi::processor
{
   using midi::processor::operator();

   void operator()(midi::note_on msg, std::size_t time)
   {
      std::cout
         << "Note On  {"
         << "Channel: "    << int(msg.channel())
         << ", Key: "      << int(msg.key())
         << ", Velocity: " << int(msg.velocity())
         << '}'            << std::endl;
   }

   void operator()(midi::note_off msg, std::size_t time)
   {
      std::cout
         << "Note Off {"
         << "Channel: "    << int(msg.channel())
         << ", Key: "      << int(msg.key())
         << ", Velocity: " << int(msg.velocity())
         << '}'            << std::endl;
   }

   void operator()(midi::poly_pressure msg, std::size_t time)
   {
      std::cout
         << "Poly Pressure {"
         << "Channel: "    << int(msg.channel())
         << ", Key: "      << int(msg.key())
         << ", Pressure: " << int(msg.pressure())
         << '}'            << std::endl;
   }

   void operator()(midi::control_change msg, std::size_t time)
   {
      std::cout
         << "Control Change {"
         << "Channel: "       << int(msg.channel())
         << ", Controller: "  << int(msg.controller())
         << ", Value: "       << int(msg.value())
         << '}'               << std::endl;
   }

   void operator()(midi::program_change msg, std::size_t time)
   {
      std::cout
         << "Program Change {"
         << "Channel: "    << int(msg.channel())
         << ", Preset: "   << int(msg.preset())
         << '}'            << std::endl;
   }

   void operator()(midi::channel_pressure msg, std::size_t time)
   {
      std::cout
         << "Channel Pressure {"
         << "Channel: "    << int(msg.channel())
         << ", Pressure: " << int(msg.pressure())
         << '}'            << std::endl;
   }

   void operator()(midi::pitch_bend msg, std::size_t time)
   {
      std::cout
         << "Pitch Bend             {"
         << "Channel: "    << int(msg.channel())
         << ", Value: "    << int(msg.value())
         << '}'            << std::endl;
   }
};
```

Send a note to the first MIDI 1.0 output device listed, then a system exclusive, which goes as one message from its 0xF0 to its 0xF7:

```c++
for (auto const& device : q::midi_device::list())
{
   if (device.num_outputs() != 0)
   {
      q::midi_output_stream out{device};
      out.send(midi::note_on{0, 60, 100});

      std::uint8_t const identity_request[] =
         {0xF0, 0x7E, 0x7F, 0x06, 0x01, 0xF7};
      out.send(q::byte_span{identity_request});
      break;
   }
}
```
