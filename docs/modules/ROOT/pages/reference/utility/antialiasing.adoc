= Antialiasing

include::../../common.adoc[]

== Overview

A trivially generated waveform with a sharp corner, such as the ±1 jump of a saw or square, contains energy well above the Nyquist frequency. Sampling that ideal shape folds the excess back into the audible band as aliasing. `poly_blep` and `poly_blamp` remove it at the source: each is a small polynomial *residual* that is added to the plain waveform only in the neighborhood of a discontinuity, canceling the components that would otherwise alias.

The two functions target different orders of discontinuity:

* *`poly_blep`* (polynomial band-limited step) corrects a *step*, a jump in the value itself. This is the ±1 wrap of a {saw_osc}, {square_osc}, or {pulse_osc}.
* *`poly_blamp`* (polynomial band-limited ramp) corrects a *corner*, a break in the slope where the value stays continuous. This is the peak and trough of a {triangle_osc}.

Both take a `{phase}` `p` (the position in the cycle) and a `{phase}` `dt` (how far the phase advances per sample, which equals the oscillator frequency divided by the sample rate). The residual is nonzero only when `p` lies within `dt` of the start or end of the cycle, so the caller offsets `p` to place each discontinuity there. Away from it the functions return zero and the plain waveform passes through untouched.

In the time domain, the plain sample plus the correction turns the sharp edge into a smooth, rounded transition. The figure below runs at a high frequency (`dt = 0.25`, a quarter cycle per sample), where the correction spans a visible part of the cycle; at normal audio frequencies it is confined to a sample or two around each edge. `poly_blep` rounds the saw's ±1 wrap (a step); `poly_blamp` rounds the triangle's peaks (a corner).

Aliasing shows in the spectrum. A sawtooth has a harmonic at every multiple of its fundamental; the harmonics above Nyquist cannot be represented and *fold back* down to lower frequencies as aliases. The fold point is Nyquist, `fs/2`, so it moves with the sample rate: 22.05 kHz at 44.1 kSPS, 24 kHz at 48 kSPS. In the log-frequency spectra below, every partial that is not on a true-harmonic marker (green) is a fold. `basic_saw` has folds all the way down below the fundamental; the band-limited `saw` holds them tens of dB lower.

The fold point tracks the sample rate.", link={imagesdir}/antialias_spectrum.svg]

The band-limited oscillators ({saw_osc}, {square_osc}, {pulse_osc}, {triangle_osc}) apply these corrections internally. Call `poly_blep` and `poly_blamp` directly to build a custom oscillator, or any generator that emits a piecewise-polynomial shape with known discontinuities.

NOTE: The `scale` argument to `poly_blamp` is half the slope change at the corner, measured per cycle. A triangle wave, whose slope flips between +4 and −4 over a unit cycle (a change of 8), uses `scale = 4`.

WARNING: These corrections assume `dt` is small relative to a cycle (the usual audio case, many samples per period). As the oscillator frequency approaches Nyquist, `dt` approaches `0.5` and a single-step correction can no longer fully band-limit the waveform.

== Include

```c++
#include <q/utility/antialiasing.hpp>
```

== Declaration

```c++
constexpr float     poly_blep(phase p, phase dt);
constexpr double    poly_blamp(phase p, phase dt, float scale);
```

== Expressions

=== Notation

`p`      :: Object of type `{phase}`: the current position in the cycle.
`dt`     :: Object of type `{phase}`: the phase advance per sample (oscillator frequency ÷ sample rate).
`scale`  :: Floating point value: half the slope change at the corner, per cycle (`poly_blamp` only).

=== Functions

[cols="1,1,1"]
|===
| Expression                   | Semantics                                    | Return Type

| `poly_blep(p, dt)`           | Get the step residual at `p`: nonzero
                                 only when `p` is within `dt` of the start
                                 or end of the cycle.                         | `float`
| `poly_blamp(p, dt, scale)`   | Get the corner residual at `p` for a slope
                                 change of `2 * scale`: nonzero only when
                                 `p` is within `dt` of the start or end of
                                 the cycle.                                   | `double`
|===

Add the residual to the plain value, or subtract it, by the direction of the discontinuity: subtract `poly_blep` at a downward step, and `poly_blamp` at a peak. Both functions are stateless, `constexpr`, and free of side effects.

=== Example

Compute a band-limited sawtooth and a band-limited triangle at one phase of an oscillator, with the plain triangle `basic_triangle` of the {triangle_osc}:

```c++
#include <q/utility/antialiasing.hpp>
#include <q/synth/va/triangle_osc.hpp>  // For basic_triangle
...
namespace q = cycfi::q;

q::phase p;                         // the phase
q::phase dt;                        // the phase step per sample
...
constexpr float x = 2.0f / q::phase::one_cyc;
float saw = (p.rep * x) - 1.0f;                       // plain saw, ±1
saw -= q::poly_blep(p, dt);                           <1>

constexpr auto end = q::phase::end();
constexpr auto peak = q::phase::middle();             // where the plain triangle turns
float tri = q::basic_triangle(p);                     // plain triangle, ±1
tri += q::poly_blamp(p, dt, 4);                       <2>
tri -= q::poly_blamp(p + (end - peak), dt, 4);        <3>
```

<1> Subtract the step residual at the wrap, where the plain saw jumps from
    +1 to -1.
<2> Add the corner residual at the trough, at phase 0, with `scale = 4` for
    the ±4 slope of a unit-amplitude triangle.
<3> Offset `p` by `end - peak` to move the peak to the end of the cycle,
    and subtract its corner residual.

See {saw_osc} and {triangle_osc} for the full oscillators these fragments come from.
