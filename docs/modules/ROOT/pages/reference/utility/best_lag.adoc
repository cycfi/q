= Best Lag

include::../../common.adoc[]

== Overview

`best_lag` finds the lag at which the recent signal most resembles itself. For each candidate lag in a range, it scores the newest `window` samples against the samples `lag` back by *normalized cross-correlation* (NCC): their dot product divided by the square root of the product of their energies, so the score ignores level. A score of 1 is a perfect shape match, 0 is no correlation.

On a periodic signal the score peaks when the lag equals the period: the newest window and the window one period back are the same shape.

image::best_lag_selfsim.svg[alt="Self-similarity at lag = period", width=700px, align=center, title="On a periodic signal the NCC peaks at lag = period: the newest window matches the window one lag back", link={imagesdir}/best_lag_selfsim.svg]

When the best integer lag lies inside the range, away from `min_lag` and `max_lag`, it is then refined to *sub-sample precision* by a parabola fit through it and its two neighbors:

image::best_lag_ncc.svg[alt="Normalized cross-correlation vs lag", width=700px, align=center, title="Zoomed view of the NCC peak (periodic signal, period 100.25): the parabola fit refines the integer best at lag 100 to a sub-sample peak at 100.25", link={imagesdir}/best_lag_ncc.svg]

`best_lag` makes no assumption of a fundamental, harmonics, or octaves. On a single note the lag is the period; on polyphonic material it is the best common quasi-period in range; on noise the similarity stays low. It serves loop and splice-point selection (sustain and freeze effects, WSOLA) and grain re-anchoring (PSOLA), and the similarity score measures how loopable the material is at that lag.

NOTE: The cost is O(window × (max_lag - min_lag)). `best_lag` suits occasional, event-driven use: per hold, per splice, per grain. The search reads only integer indices, so a buffer whose integer indexing is cheap, such as a `{ring_buffer}`, serves best.

== Include

```c++
#include <q/utility/best_lag.hpp>
```

== Declaration

```c++
struct lag_result
{
   float    lag;
   float    similarity;
};

template <typename Buffer>
lag_result best_lag(
   Buffer const& buf
 , std::size_t window
 , std::size_t min_lag
 , std::size_t max_lag
);
```

== Expressions

=== Notation

`buf`                 :: A buffer indexable with `std::size_t`, where index 0 refers to the newest element, e.g. `{ring_buffer}`.
`window`              :: Object of type `std::size_t`: the comparison window length, in samples.
`min_lag`, `max_lag`  :: Objects of type `std::size_t`: the inclusive lag search range, in samples.
`r`                   :: Object of type `lag_result`.

=== Functions

[cols="1,1,1"]
|===
| Expression                                | Semantics                                | Return Type

| `best_lag(buf, window, min_lag, max_lag)` | Search [`min_lag`, `max_lag`] for the
                                              lag at which the newest `window`
                                              samples best match themselves
                                              `lag` samples ago.                      | `lag_result`
|===

WARNING: The buffer must hold at least `window + max_lag` samples of history (plus the interpolation margin, if the buffer interpolates fractional indices). Searching beyond the available history is undefined behavior.

=== Access

[cols="1,1,1"]
|===
| Expression          | Semantics                                | Return Type

| `r.lag`             | Get the best lag, refined to sub-sample
                        precision unless it is `min_lag` or
                        `max_lag`.                               | `float`
| `r.similarity`      | Get the normalized cross-correlation at
                        the best integer lag: 1 for a perfect
                        match, 0 for no correlation.             | `float`
|===

=== Example

Measure the period of the input's history, at `sps` samples per second, between 40 Hz and 500 Hz, and take it as the loop length when the material is loopable:

```c++
#include <q/utility/best_lag.hpp>
#include <q/utility/ring_buffer.hpp>
...
namespace q = cycfi::q;

extern q::ring_buffer<float> hist;  // the input's history, newest first
float loop;                         // the loop length, in samples
...
auto min_lag = std::size_t(sps / 500);
auto max_lag = std::size_t(sps / 40);

auto r = q::best_lag(hist, 2048, min_lag, max_lag);       <1>
if (r.similarity > 0.95f)                                 <2>
   loop = r.lag;
```

<1> Search lags from 1/500 s to 1/40 s, comparing the newest 2048 samples.
    `hist` holds at least 2048 samples plus the longest lag.
<2> Accept the lag when the two windows match closely.
