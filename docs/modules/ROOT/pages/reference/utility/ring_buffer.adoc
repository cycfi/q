= Ring Buffer

include::../../common.adoc[]

== Overview

The ring buffer is a fixed-size buffer that is regarded as if it were circular. When data is written to the buffer, it is stored in sequential order up to its size, after which new data will overwrite the oldest data in the buffer. `ring_buffer` is a template class parameterized by the underlying element type, `T`, and the type of storage used, which defaults to `std::vector<T>`, although it is also possible to use fixed sized storage such as `std::array` as long as the size is a power of 2. For efficiency, the ring buffer storage will maintain a size that is the power of 2. The `ring_buffer` is not resizable after construction.

== Ring Buffer

=== Include

```c++
#include <q/utility/ring_buffer.hpp>
```

=== Declaration

```c++
template <typename T, typename Storage = std::vector<T>>
class ring_buffer
{
public:

   using value_type = T;
   using storage_type = Storage;
   using index_type = std::size_t;
   using interpolation_type = sample_interpolation::none;

                     explicit ring_buffer();
                     explicit ring_buffer(std::size_t size);
                     ring_buffer(ring_buffer const& rhs) = default;
                     ring_buffer(ring_buffer&& rhs) = default;

   ring_buffer&      operator=(ring_buffer const& rhs) = default;
   ring_buffer&      operator=(ring_buffer&& rhs) = default;

   std::size_t       size() const;
   void              push(T val);
   T const&          front() const;
   T&                front();
   T const&          back() const;
   T&                back();
   T const&          operator[](std::size_t index) const;
   T&                operator[](std::size_t index);
   void              clear();
   void              pop_front();

   Storage&          store();
   const Storage&    store() const;
};
```

==== Constructors and Assignment

[cols="1,1"]
|===
| Expression            | Semantics

| `rb_type()`           | Default construct a ring buffer. This constructor is only
                          applicable when a fixed sized storage is specified.
| `rb_type(s)`          | Construct a ring buffer with specified size, `s`. This
                          constructor is only applicable when a resizable storage
                          is specified. The actual buffer size will be the smallest
                          power of 2 not less than `s`.
| `rb_type(rb)`         | Copy construct from `rb_type rb`.
| `a = b`               | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used.

==== Operation

[cols="1,1,1"]
|===
| Expression         | Semantics                         | Return Type

| `rb.push(val)`     | Push the latest element,
                       overwriting the oldest element.   | `void`
| `rb.pop_front()`   | Pop the latest element. This
                       operation will not destruct the
                       element, but will instead allow
                       the ring buffer to overwrite the
                       element on the next `push`.       | `void`
| `rb.clear()`       | Clear the ring buffer.            | `void`
|===

==== Indexing

[cols="1,1,1"]
|===
| Expression         | Semantics                         | Return Type

| `rb[i]`            | Get the element at index `i`. `rb[0]`
                       refers to the latest element.
                       `rb[rb.size()-1]` refers to the
                       oldest element.                   | `T&` or `T const&` if `rb`
                                                           is const.
| `rb.size()`        | Get the ring buffer's size.       | `std::size_t`
|===

WARNING: `i > rb.size()-1` is undefined behavior.

==== Accessors

[cols="1,1,1"]
|===
| Expression         | Semantics                         | Return Type

| `rb.front()`       | Get the latest element.           | `T&` or `T const&` if `rb`
                                                           is const.
| `rb.back()`        | Get the oldest element.           | `T&` or `T const&` if `rb`
                                                           is const.
| `rb.store()`       | Get a reference to the storage.   | `S&` or `S const&` if `rb`
                                                           is const.
|===

==== Example

Mix the input samples `in` with a copy of themselves delayed by 100 samples:

```c++
namespace q = cycfi::q;

auto rb = q::ring_buffer<float>{128};                     <1>

for (auto& s : in)
{
   rb.push(s);                                            <2>
   s = (s + rb[100]) / 2;                                 <3>
}
```

<1> Construct a ring buffer of 128 elements, all zero.
<2> Push the latest sample, which becomes `rb[0]`.
<3> Mix the sample with the one pushed 100 samples earlier.

== Mirrored Ring Buffer

`mirrored_ring_buffer` stores every element twice, at its position and again `size()` elements further on. Any stretch of the history is then one contiguous run of memory, wherever the write position has wrapped to. `span(age)` returns a pointer to the element `age` back, and the elements after it ascend in age. A correlation or FIR kernel can walk the history with plain pointer reads, and a compiler can vectorize the loop.

image::mirrored_ring_buffer.svg[alt="The storage of ring_buffer and mirrored_ring_buffer", width=760px, align=center, title="The same history of 8 samples in each buffer, the newest at storage index 5. In the ring_buffer, the window of ages 1 to 5 is split where the storage wraps. In the mirrored_ring_buffer, the same window is one contiguous run.", link={imagesdir}/mirrored_ring_buffer.svg]

The cost is twice the memory and a second store on every push. The capacity is exactly the size given to the constructor, with no rounding to a power of two, and the storage must be resizable. Elements are read only: writing one through a reference would put its two copies out of step.

```c++
template <typename T, typename Storage = std::vector<T>>
class mirrored_ring_buffer
{
public:

   using value_type = T;
   using storage_type = Storage;
   using index_type = std::size_t;
   using interpolation_type = sample_interpolation::none;

   explicit          mirrored_ring_buffer(std::size_t size);

   std::size_t       size() const;
   void              push(T val);
   T const&          front() const;
   T const&          back() const;
   T const&          operator[](std::size_t index) const;
   T const*          span(std::size_t age) const;

};
```

==== Indexing

[cols="1,1,1"]
|===
| Expression         | Semantics                         | Return Type

| `mrb[i]`           | Get the element `i` back. `mrb[0]`
                       is the latest element.            | `T const&`
| `mrb.span(age)`    | Get a pointer `p` to the element
                       `age` back. `p[k]` is the element
                       `age + k` back.                   | `T const*`
| `mrb.size()`       | Get the capacity.                 | `std::size_t`
|===

WARNING: `mrb[i]` requires `i < mrb.size()`, and `mrb.span(age)[k]` requires `age + k < mrb.size()`. Anything past that is undefined behavior.

[cols="1,1,1"]

| `mrb.front()`      | Get the latest element.           | `T const&`
| `mrb.back()`       | Get the oldest element.           | `T const&`
| `mrb.store()`      | Get the storage, `2 * size()`
                       elements.                         | `S const&`
|===

==== Example

Correlate the newest 256 of the input samples `in` with the 256 samples a lag earlier:

```c++
#include <q/utility/ring_buffer.hpp>
...
namespace q = cycfi::q;

std::size_t lag;                    // the lag, in samples
...
auto hist = q::mirrored_ring_buffer<float>{1024};         <1>

for (auto s : in)
   hist.push(s);                                          <2>

float const* now = hist.span(0);                          <3>
float const* then = hist.span(lag);

float sum = 0;
for (std::size_t k = 0; k != 256; ++k)
   sum += now[k] * then[k];
```

<1> Construct a mirrored ring buffer with a capacity of exactly 1024 samples.
<2> Push each sample, writing both of its copies.
<3> Get the two windows as contiguous arrays, wherever the history has wrapped. `lag` can be up to 768, where `lag + 255` is the oldest element.
