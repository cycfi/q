= Bitset

include::../../common.adoc[]

== Overview

`bitset` is a fixed-size array of bits packed into machine words. The size is fixed at construction: you ask for a number of bits, and the storage rounds up to a whole number of words. It gives *raw word access*, so an algorithm can process the bits a whole word at a time.

Bits are stored in a `{std-vector}` of unsigned integers of type `T` (default `natural_uint`, the widest native unsigned word, 64 bits on a 64-bit target). Bit `i` lives in word `i / value_size` at position `i % value_size`, least significant bit first, where `value_size` is the number of bits in one word.

image::bitset_layout.svg[alt="Bits packed into machine words", width=700px, align=center, title="An 8-bit-word example: bitset<uint8_t>(20) rounds up to 3 words (24 bits of capacity). Bit i sits in word i / 8 at position i % 8, LSB first. set(5, 10, true) sets the range 5..14 a word at a time.", link={imagesdir}/bitset_layout.svg]

The class can set a single bit, set a contiguous *range* of bits, get a single bit, and clear everything to zero. The range set writes the leading partial word, then whole words `value_size` bits at a time, then the trailing partial word, so filling a long run costs far less than setting its bits one at a time.

`data()` gives the underlying words. `bitset` is the storage behind the {bitstream_acf}: a one-bit quantization of the signal is packed into a `bitset`, and correlated by XOR and population count over the raw 64-bit words.

NOTE: `size()` reports *capacity* in bits (words times `value_size`), which may be larger than the number of bits requested at construction, because the storage rounds up to a whole word. In the figure, `bitset<uint8_t>(20)` reports `size() == 24`.

WARNING: Valid bit indices are `0 <= i < size()`. `T` must be an unsigned type (enforced by a `static_assert`).

== Include

```c++
#include <q/utility/bitset.hpp>
```

== Declaration

```c++
template <typename T = natural_uint>
class bitset
{
public:

   using value_type = T;
   using vector_type = std::vector<T>;

   static constexpr auto value_size = CHAR_BIT * sizeof(T);
   static constexpr auto one = T{1};

                  bitset(std::size_t num_bits);
                  bitset(bitset const& rhs) = default;
                  bitset(bitset&& rhs) = default;

   bitset&        operator=(bitset const& rhs) = default;
   bitset&        operator=(bitset&& rhs) = default;

   std::size_t    size() const;
   void           clear();
   void           set(std::size_t i, bool val);
   void           set(std::size_t i, std::size_t n, bool val);
   bool           get(std::size_t i) const;

   T*             data();
   T const*       data() const;
};
```

== Expressions

=== Notation

`T`         :: The unsigned word type. Defaults to `natural_uint`.
`a`, `b`    :: Objects of type `bitset<T>`.
`num_bits`  :: Object of type `std::size_t`: the number of bits requested.
`i`         :: Object of type `std::size_t`: a bit index.
`n`         :: Object of type `std::size_t`: a count of bits.
`val`       :: Object of type `bool`: the value to write.

=== Type Definitions

[cols="1,1,1"]
|===
| Expression                 | Semantics                          | Type

| `bitset<T>::value_type`    | Get the word type.                 | `T`
| `bitset<T>::vector_type`   | Get the underlying storage type.   | `std::vector<T>`
|===

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression            | Semantics

| `bitset<T>(num_bits)` | Construct a `bitset` with at least `num_bits` bits, rounded
                          up to a whole number of words, all 0.
| `bitset<T>(b)`        | Copy construct from `b`.
| `a = b`               | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used. `bitset<>` uses the default `natural_uint` words.

=== Mutators

[cols="1,1,1"]
|===
| Expression         | Semantics                                     | Return Type

| `b.set(i, n, val)` | Set the `n` bits starting at index `i` to
                       `val`, a word at a time. A run past `size()`
                       is clamped to the end.                        | `void`
| `b.set(i, val)`    | Set the bit at index `i` to `val`.            | `void`
|===

=== Operation

[cols="1,1,1"]
|===
| Expression         | Semantics                                     | Return Type

| `b.clear()`        | Set every bit to 0.                           | `void`
|===

=== Accessors

[cols="1,1,1"]
|===
| Expression         | Semantics                                     | Return Type

| `b.get(i)`         | Get the bit at index `i`.                     | `bool`
| `b.size()`         | Get the capacity in bits: `value_size` times
                       the number of words.                          | `std::size_t`
| `b.data()`         | Get a pointer to the first storage word.      | `T*` or `T const*` if `b`
                                                                       is const.
|===

=== Access

[cols="1,1,1"]
|===
| Expression                 | Semantics                          | Return Type

| `bitset<T>::value_size`    | Get the number of bits per word,
                               `CHAR_BIT * sizeof(T)`.            | `std::size_t`
| `bitset<T>::one`           | Get the word value 1.              | `T`
|===

=== Example

Quantize a block of samples to a one-bit stream, one bit per sample, setting each run of positive samples with one range set, then get the packed words:

```c++
#include <q/utility/bitset.hpp>
#include <span>
...
namespace q = cycfi::q;

std::span<float const> block;       // the samples
...
auto bits = q::bitset<>{block.size()};                    <1>

std::size_t start = 0;
bool high = false;
for (std::size_t i = 0; i != block.size(); ++i)
{
   bool positive = block[i] > 0.0f;
   if (positive && !high)
      start = i;
   else if (!positive && high)
      bits.set(start, i - start, true);                   <2>
   high = positive;
}
if (high)
   bits.set(start, block.size() - start, true);

auto const* words = bits.data();                          <3>
auto n_words = bits.size() / bits.value_size;
```

<1> Construct a `bitset` of `natural_uint` words, all 0, with at least one
    bit per sample.
<2> Set the bits of a run of positive samples, a word at a time.
<3> Get the packed words, `n_words` of them, for a word-wise consumer.
