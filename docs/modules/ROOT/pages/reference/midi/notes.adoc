= MIDI Notes

include::../../common.adoc[]

== Overview

IMPORTANT: Read {midi_messages} first for prerequisite information.

The note helpers convert between MIDI note numbers, note names and frequencies.

== Include

```c++
#include <q/midi/note.hpp>
```

== Namespace

```c++
namespace cycfi::q::midi { /**...**/ }
```

The note helpers live in `namespace midi`, beside the controller numbers. `midi_1_0` names all of them, and `midi_2_0` names `note_frequency`. See {midi_cc} for how the two protocols share these names.

== Note Frequency

`note_frequency` converts a MIDI note number to its frequency in equal temperament, with A4, note 69, at 440 Hz.

```c++
constexpr frequency note_frequency(std::uint8_t key);
```

Example:

```c++
namespace midi = cycfi::q::midi_1_0;

auto f = midi::note_frequency(69); // 440_Hz
```

NOTE: The function covers notes 9 to 119, A-1 to B8, and returns a frequency of 0 outside them.

== Note

`note` names the MIDI note numbers from `C0`, 12, to `G9`, 127. A sharp is written with an `s` and a flat with a `b`, and the two names of one key are the same value: `note::Cs4` and `note::Db4` are both 61.

```c++
enum class note : std::uint8_t
{
   C0 = 12, Cs0, Db0 = Cs0, D0, /**...**/ G9
};
```

Example:

```c++
namespace midi = cycfi::q::midi_1_0;

auto key = std::uint8_t(midi::note::A4); // 69
```

== Note Name

The `note_name` utility function can be used to convert a MIDI note number to a string representing the key.

```c++
constexpr char const* note_name(std::uint8_t key);
```

Example:

```c++
#include <iostream>
...
namespace midi = cycfi::q::midi_1_0;

std::cout << midi::note_name(60) << std::endl; // Prints "C4"
```

NOTE: The function returns `"--"` for a key above 127.

== Note Number

Conversely, the `note_number` utility function can be used to convert a string representing the key to a MIDI note number.

```c++
inline int note_number(std::string_view note);
```

The syntax is as follows:

1. A letter `a`-`g` or `A`-`G`
2. Optionally followed by `#` or `b`
3. Followed by the octave, `-1` to `9`

The range is from `C-1`, 0, to `G9`, 127, the whole of MIDI, so every name `note_name` gives reads back as the number it came from.

Example:

```c++
#include <iostream>
...
namespace midi = cycfi::q::midi_1_0;

std::cout << midi::note_number("C4") << std::endl; // Prints 60
```

NOTE: The function returns -1 when given invalid input, or a key that is not a MIDI note, such as `A9`.

== Example

Transpose a pattern stored by note names up a fifth, and print the result:

```c++
#include <q/midi/note.hpp>
#include <iostream>

namespace midi = cycfi::q::midi_1_0;

void transpose()
{
   char const* pattern[] = {"C4", "E4", "G4"};
   for (auto name : pattern)
   {
      auto key = midi::note_number(name) + 7;                    <1>
      std::cout << midi::note_name(std::uint8_t(key)) << ' ';    <2>
   }
}
```

<1> Convert the name to a MIDI note number, and add seven semitones.
<2> Convert the result back to a name. This prints `G4 B4 D5`.
