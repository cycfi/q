= Fast RMS Envelope Follower

include::../../common.adoc[]

== Overview

The Fast RMS Envelope Follower is a variation of the {fast_envelope_follower}. It is a simple composite class that contains a {fast_ave_envelope_follower} member.

image:fast-rms.svg[alt="Fast RMS: square root of the smoothed held peak of the squared signal", width=340, role=right]The signal path is as follows:

1. Square the signal.
2. Apply the fast averaging envelope follower: hold the peak of the squared signal over the `hold` window, then smooth the resulting staircase with a moving average filter.
3. Return the square root of the result.

Note the `max` under the radical: the {true_rms_envelope_follower} has a `mean` there, averaging the squared signal itself, and therefore measures actual power.

This is embodied in the `fast_rms_envelope_follower` class. Following the fast envelope follower API, the function call operator accepts a floating point sample, transforms it, and returns an envelope, also a floating point.

IMPORTANT: The fast RMS envelope follower is a fast level _detector_ computed in the power domain. Step 2 holds the _peak_ of the squared signal, so a steady sine of amplitude `A` reads `A` (its RMS level is `A/√2`), and the reading depends on the waveform's crest factor. Use it where transients must be caught with low ripple, such as dynamics side-chains. For a power measurement (level matching, envelope ratios, metering), use the {true_rms_envelope_follower}: it reads the same for any two signals of equal power.

The `fast_rms_envelope_follower_db` variant works in the dB domain, for the dynamic range processors (compressor, expander and agc) that already work in decibels. It saves a linear to decibel conversion, and takes the square root as a division by 2.

== Declaration

```c++
struct fast_rms_envelope_follower
{
    static constexpr auto threshold = lin_float(-120_dB);

            fast_rms_envelope_follower(duration hold, float sps);

    float   operator()(float s);
    float   operator()() const;
    float   peak_square() const;
};

struct fast_rms_envelope_follower_db : fast_rms_envelope_follower
{
    using fast_rms_envelope_follower::fast_rms_envelope_follower;

    decibel operator()(float s);
    decibel operator()() const;
};
```

`fast_rms_envelope_follower` essentially follows the same API as {fast_envelope_follower}. The `fast_rms_envelope_follower_db` variant works in the dB domain and returns `decibel` instead of `float`.

== Expressions

=== Notation

`env_t`             :: A `fast_rms_envelope_follower` or `fast_rms_envelope_follower_db`.
`env`, `a`, `b`     :: Objects of type `fast_rms_envelope_follower` or `fast_rms_envelope_follower_db`.
`hold`              :: Object of type `duration`
`sps`               :: Floating point value for samples per second.
`s`                 :: Floating point value for the latest input sample.

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression            | Semantics

| `env_t(hold, sps)`    | Construct an `env_t` given `hold` (hold duration) and `sps` (samples per second).
| `env_t(env)`          | Copy construct from `env`.
| `a = b`               | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used.

`env_t` is a shortcut notation for `fast_rms_envelope_follower` or `fast_rms_envelope_follower_db`.

=== Function Call

[cols="1,1,1"]
|===
| Expression        | Semantics                             | Return Type

| `env(s)`          | Process the input sample `s` and
                      return the detected envelope.         | `float` (`decibel` for the `_db` variant)
| `env()`           | Get the latest detected envelope
                      without processing a sample.          | `float` (`decibel` for the `_db` variant)
| `env.peak_square()` | Get the raw smoothed peak of the
                      squared signal: the value under the
                      radical (no square root).             | `float`
|===

NOTE: Readings whose smoothed peak square falls below `threshold` (-120 dB,
an RMS level of -60 dB) return 0.

TIP: `peak_square()` is the counterpart of `mean_square()` in the {true_rms_envelope_follower}. To compare against a squared threshold, stay in the squared domain and skip the square root.

=== Access

[cols="1,1,1"]
|===
| Expression          | Semantics                             | Return Type

| `env_t::threshold`  | Get the floor of the smoothed peak
                        square: -120 dB as a linear value.  | `float`
|===

=== Example

Drive a {compressor} from the fast RMS envelope, in decibels:

```c++
#include <q/fx/envelope.hpp>
#include <q/fx/dynamic.hpp>
#include <q/support/literals.hpp>
#include <span>
...
namespace q = cycfi::q;
using namespace q::literals;

float sps;                       // samples per second
std::span<float> in;             // the input samples
...
auto env = q::fast_rms_envelope_follower_db{10_ms, sps};  <1>
auto comp = q::compressor{-18_dB, 1.0f / 4};

for (auto& s : in)
   s *= lin_float(comp(env(s)));                          <2>
```

<1> Construct a fast RMS envelope follower in the dB domain, with a 10 ms
    hold.
<2> Follow the sample (the follower squares it), compute the compressor
    gain from the envelope in decibels, and apply it to the sample.
