= AGC

include::../../common.adoc[]

== Overview

image:agc.svg[alt="AGC", width=400, role=right]The AGC, or automatic gain control, compares the envelope, `env`, to an external reference, `ref`, and increases or decreases the gain to maintain a constant output level. A class named `agc` implements AGC. It is the `double` instantiation of a class template, `basic_agc<T>`, where `T` is the type of its `{decibel}`; `basic_agc<float>` keeps the dynamics in `float` for a single-precision FPU.

Envelope tracking is done externally using an external envelope follower to make it possible to use different types of envelope tracking schemes, the output of which is the supplied argument to the function call operator.

The `agc` is an envelope processor that operates on the envelope of the audio signal, performs computations in the logarithmic domain, and returns a processed envelope.

NOTE: See xref:reference/dynamic.adoc[Dynamic] for further details.

`agc` is a feedforward type AGC. In contrast to feedback AGCs, feedforward AGCs derive their control signal only from the input signal and an external reference set-point.

== Declaration

```c++
template <typename T>
struct basic_agc
{
   using decibel_type = basic_decibel<T>;

                  basic_agc(decibel_type max);

   decibel_type   operator()(decibel_type env, decibel_type ref) const;
   void           max(decibel_type max_);
   decibel_type   max() const;
};

using agc = basic_agc<double>;
```

== Template Instantiations

`agc`:: An `agc` on `decibel`, in `double`.

```c++
using agc = basic_agc<double>;
```

== Expressions

=== Notation

`C`                 :: A `basic_agc<T>` type.
`g`, `a`, `b`       :: Objects of type `C`
`max`, `ref`, `env` :: Objects of type `basic_decibel<T>`

|===

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression    | Semantics

| `C(max)`      | Construct an `agc` from `max` (maximum) gain.
| `C(g)`        | Copy construct from `g`.
| `a = b`       | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used.

As previously stated, the `agc` compares the envelope, `env`, to an external reference, `ref`, and adjusts the gain accordingly to maintain a constant output level. However, there is a maximum gain that can be applied when the signal falls below the reference. The `max` constructor parameter specifies this "maximum" gain.

=== Function Call

[cols="1,1,1"]
|===
| Expression        | Semantics                             | Return Type

| `g(env, ref)`     | Process the input envelope `env`
                      by increasing or decreasing the gain
                      if `env` goes above or falls below
                      `ref`, to maintain a constant output
                      level.                                | `basic_decibel<T>`
|===

The output is the adjusted gain, also in decibels. Simply multiply the signal by the result converted to a linear `float` using `lin_float` (or `double` using `lin_double`). For example:

```c++
#include <q/fx/dynamic.hpp>
#include <q/support/literals.hpp>
...
namespace q = cycfi::q;
using namespace q::literals;

q::agc g{30_dB};
q::decibel env = -12_dB;                 // from an envelope follower
q::decibel ref = -18_dB;                 // the reference level
float signal;                            // the input
...
auto gain = lin_float(g(env, ref));      <1>
auto out = signal * gain;               <2>
```

<1> `env` is the envelope computed (e.g.) using an envelope follower.
    `gain` is obtained from the `env` processed by `agc` and converted to a linear `float`.
<2> The `signal` multiplied by `gain`.
