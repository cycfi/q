= Moog Ladder Filter

include::../../common.adoc[]

== Overview

The `moog_ladder` is a 4-pole (24 dB/octave) lowpass *ladder* filter with
resonance, the classic "fat" subtractive-synthesizer voice. It is four
topology-preserving one-pole lowpasses in series wrapped in a global resonance
feedback loop, after Vadim Zavalishin's _The Art of VA Filter Design_ and Will
Pirkle's _Designing Software Synthesizer Plug-Ins in C++_.

image::ladder_block.svg[alt="Moog ladder block diagram", width=750px, align=center, title="Building blocks: four one-pole lowpass stages and a resonance feedback inverted back into the summer. An optional tanh sits in the feedback for the saturating Moog tone.", link={imagesdir}/ladder_block.svg]

* Each one-pole stage has the gain `g = tan(pi * fc / fs)`.
* `k = 4r` scales the lowpass output, and `× −1` subtracts it from the input.
* In the nonlinear mode a `tanh` saturates the feedback.

In the default *linear* mode the instantaneous (zero-delay) feedback is resolved
analytically, so, like {svf}, the filter stays stable and free of zipper noise
when the cutoff is modulated every sample.

Parametrization is exact: the cutoff coefficient is the bilinear prewarp
`g = tan(pi * fc / fs)`, and the resonance is a normalized `r` in `[0, 1]`
(internally `k = 4r`). In the linear mode the filter reaches self-oscillation
exactly at `r = 1`.
As resonance rises the passband thins, the characteristic ladder behavior.

image::ladder_response.svg[alt="Moog ladder magnitude response", width=720px, align=center, title="The 24 dB/oct lowpass at rising resonance: the passband thins and a peak climbs toward self-oscillation as r approaches 1.", link={imagesdir}/ladder_response.svg]

The optional *nonlinear* mode runs a `tanh` saturation in the feedback path for
the saturating Moog character. That path uses the previous output for the
nonlinearity (a one-sample delay in the saturation only; the four stages stay
TPT), the standard inexpensive nonlinear ladder. That delay adds phase to the
loop, so at a high cutoff the nonlinear mode self-oscillates before `r = 1`;
see {basic_ladder}. The linear mode has no such approximation.

It is the most expensive of the resonant filters: about ten multiplies per
sample, plus two divides when the cutoff or resonance changes. See
{resonant_filters} for a comparison.

`moog_ladder` is a {basic_ladder} with the cell of a transistor ladder. The
{basic_ladder} page documents the topology, the pole count and the resonance
scaling. Its sibling {ota_ladder} has the variable gain cell of the Curtis
chips, which adds mostly second harmonic.

NOTE: For a 12 dB/oct multimode filter (lowpass, bandpass, highpass, ...), see
{svf}; for the cheaper Chamberlin state-variable filter, see {chamberlin_filter}.

== Include

```c++
#include <q/fx/ladder.hpp>
```

== Declaration

```c++
struct moog_ladder : basic_ladder<moog_cell, 4>
{
   using base_type = basic_ladder<moog_cell, 4>;
   using base_type::operator=;

                  moog_ladder(
                     frequency f
                   , float sps
                   , float reso = 0.0f
                   , bool nonlinear = false
                  );

   void           nonlinear(bool on);
   bool           nonlinear() const;
};
```

== Expressions

As a subclass of `{basic_ladder}`, `moog_ladder` inherits all the publicly
accessible member functions, member variables, and types of its base class.
In addition to valid expressions for {basic_ladder}, `moog_ladder` allows
these expressions.

=== Notation

`ld`              :: Object of type `moog_ladder`.
`f`               :: Object of type `{frequency}`: the cutoff.
`sps`             :: Floating point value for samples per second.
`r`               :: Floating point value for the normalized resonance, from 0.0 to 1.0.
`nl`              :: Object of type `bool`: the nonlinear (tanh) mode.

=== Constructors

[cols="1,1"]
|===
| Expression                        | Semantics

| `moog_ladder(f, sps [, r [, nl]])` | Construct a `moog_ladder` given `f`
                                      (cutoff), `sps` (samples per second),
                                      `r` (normalized resonance, 0 by
                                      default) and `nl` (nonlinear mode,
                                      `false` by default).
|===

NOTE: C++ brace initialization may also be used.

=== Example

Filter the input samples `in`, at `sps` samples per second, with the cutoff
rising from 200 Hz to 5 kHz:

```c++
#include <q/support/literals.hpp>  // For the literals
#include <algorithm>               // For std::min

namespace q = cycfi::q;
using namespace q::literals;

auto filter = q::moog_ladder{200_Hz, sps, 0.7f};          <1>
filter.nonlinear(true);                                   <2>

float fc = 200;
for (auto s : in)
{
   filter.cutoff(q::frequency{fc}, sps);                  <3>
   auto y = filter(s);                                    <4>
   fc = std::min(fc * 1.0001f, 5000.0f);
   // Use y
}
```

<1> Construct a `moog_ladder` with a cutoff of 200 Hz and a resonance of 0.7.
<2> Turn on the tanh saturation in the feedback path.
<3> Set the cutoff, every sample.
<4> Process the sample and return the 24 dB/oct lowpass output.
