= Chamberlin Filter

include::../../common.adoc[]

== Overview

The `chamberlin_filter` is a Chamberlin state-variable filter, the *cheap*
resonant filter: two integrators with feedback, the textbook digital SVF (Hal
Chamberlin, _Musical Applications of Microprocessors_). It shares the
two-integrator structure shown for the {svf} (summer, two integrators, a damping
feedback, and lowpass/bandpass/highpass/notch taps), with forward-Euler
integrators in place of the trapezoidal ones.

The coefficient is `f = 2 * sin(pi * fc / fs)` and the damping is `q = 1/Q`,
decoupled from the cutoff. One tick yields lowpass, bandpass, highpass and
notch.

image::chamberlin_response.svg[alt="Chamberlin magnitude response", width=720px, align=center, title="Lowpass at rising Q (peak height equals Q). The cutoff is valid below the fs/6 stability ceiling, where the coefficient f reaches 1.", link={imagesdir}/chamberlin_response.svg]

The trade-offs versus the {svf}:

* It is stable only below `fs/6` (~7.35 kHz at 44.1k). The cutoff is clamped
  just below that limit (see `max_coeff`), so a swept cutoff stops at the top.
* The `2*sin` coefficient warps the cutoff placement slightly versus the exact
  bilinear prewarp, most noticeably as the cutoff approaches `fs/6`.

Use it where the exact frequency and Q do not matter, for example a synth
filter swept by an envelope. For an exact, full-range filter use {svf}; for a
4-pole ladder use {moog_ladder}.

It is the cheapest of the resonant filters: about three multiplies per sample,
and the coefficient update is a `sin` with no divide. See {resonant_filters} for
a comparison.

#include <q/fx/svf.hpp>

== Declaration

```c++
struct chamberlin_filter
{
   static constexpr double default_q = 0.707106781186548;   // 1/sqrt(2)
   static constexpr float  max_coeff = 0.99f;

                  chamberlin_filter(frequency f, float sps, double q = default_q);
                  chamberlin_filter(frequency f, float sps, duration tau);
                  chamberlin_filter(float coeff, double q = default_q);

   float          operator()(float s);
   float          operator()() const;

   float          lowpass() const;
   float          bandpass() const;
   float          highpass() const;
   float          notch() const;

   void           cutoff(frequency f, float sps);
   void           cutoff(float coeff);
   void           resonance(double q);
   void           normalized_resonance(float r);

   chamberlin_filter& operator=(float y);
};
```

== Expressions

=== Notation

`cf`, `a`, `b`    :: Objects of type `chamberlin_filter`.
`f`               :: Object of type `{frequency}`: the cutoff.
`sps`             :: Floating point value for samples per second.
`q`               :: Floating point value for the quality factor, `Q`.
`tau`             :: Object of type `{duration}`: the 1/e decay time.
`coeff`           :: Floating point value for the coefficient `2 * sin(pi * fc / fs)`, from 0.0 to `max_coeff`.
`r`               :: Floating point value for the normalized resonance, from 0.0 to 1.0.
`s`               :: Floating point value for the latest input sample.
`y`               :: Floating point value.

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression                          | Semantics

| `chamberlin_filter(f, sps [, q])`   | Construct a `chamberlin_filter` given
                                        `f` (cutoff), `sps` (samples per
                                        second) and `q` (quality factor,
                                        `default_q` by default).
| `chamberlin_filter(f, sps, tau)`    | Construct a `chamberlin_filter` that
                                        rings at `f` and decays by 1/e every
                                        `tau` (`Q = pi * f * tau`). See
                                        `q_from_decay` on the {svf} page.
| `chamberlin_filter(coeff [, q])`    | Construct a `chamberlin_filter` given
                                        `coeff` (coefficient) and `q`
                                        (quality factor, `default_q` by
                                        default).
| `chamberlin_filter(cf)`             | Copy construct from `chamberlin_filter cf`.
| `a = b`                             | Assign `b` to `a`.
| `a = y`                             | Set the lowpass state to `y` and clear
                                        the bandpass and highpass states.
|===

NOTE: C++ brace initialization may also be used.

=== Function Call

[cols="1,1,1"]
|===
| Expression  | Semantics                                       | Return Type

| `cf(s)`     | Process the input sample `s` and return the
                lowpass output.                                 | `float`
| `cf()`      | Get the latest lowpass output.                  | `float`
|===

=== Accessors

[cols="1,1,1"]
|===
| Expression       | Semantics                                   | Return Type

| `cf.lowpass()`   | Get the lowpass output of the latest tick.  | `float`
| `cf.bandpass()`  | Get the bandpass output of the latest tick. | `float`
| `cf.highpass()`  | Get the highpass output of the latest tick. | `float`
| `cf.notch()`     | Get the notch output of the latest tick.    | `float`
|===

The outputs are valid after a call to `cf(s)`.

=== Mutators

[cols="1,1,1"]
|===
| Expression                       | Semantics                            | Return Type

| `cf.cutoff(f, sps)`              | Set the cutoff given `f` (cutoff)
                                     and `sps` (samples per second),
                                     clamped below `fs/6`.               | `void`
| `cf.cutoff(coeff)`               | Set the coefficient, clamped to
                                     [0, `max_coeff`].                   | `void`
| `cf.resonance(q)`                | Set the resonance given `q`
                                     (quality factor).                   | `void`
| `cf.normalized_resonance(r)`     | Set the resonance given `r`
                                     (normalized resonance), clamped to
                                     [0, 1]: 0 gives `Q = 0.5`, and `Q`
                                     grows without bound as `r`
                                     approaches 1.                       | `void`
|===

=== Access

[cols="1,1,1"]
|===
| Expression                        | Semantics                              | Return Type

| `chamberlin_filter::default_q`    | Get the default quality factor,
                                      `1/sqrt(2)` (Butterworth).           | `double`
| `chamberlin_filter::max_coeff`    | Get the largest coefficient, just
                                      below the `fs/6` stability limit
                                      (0.99).                              | `float`
|===

=== Example

Filter the input samples `in`, at `sps` samples per second, with a resonant
lowpass swept by an envelope:

```c++
#include <q/fx/svf.hpp>
#include <q/support/literals.hpp>  // For the literals
#include <span>
...
namespace q = cycfi::q;
using namespace q::literals;

std::span<float const> env;         // the envelope, one value per sample, 0 to 1
...
auto filter = q::chamberlin_filter{1_kHz, sps, 2.0};          <1>

for (std::size_t i = 0; i != in.size(); ++i)
{
   filter.cutoff(q::frequency{60.0 + env[i] * 6000.0}, sps);  <2>
   auto y = filter(in[i]);                                    <3>
   // Use y
}
```

<1> Construct a `chamberlin_filter` with a cutoff of 1 kHz and a `Q` of 2.
<2> Sweep the cutoff from 60 Hz up with the envelope, every sample. The
    cutoff stops below `fs/6`.
<3> Process the sample and return the lowpass output.
