= State Variable Filter

include::../../common.adoc[]

== Overview

The `svf` is a *topology-preserving-transform* (TPT) state-variable filter: the
continuous-time analog SVF discretized with trapezoidal integration, with the
unit-delay-free feedback resolved analytically (zero-delay feedback). It is
based on Andrew Simper's link:https://cytomic.com/files/dsp/SvfLinearTrapOptimised2.pdf[Solving the continuous SVF equations using trapezoidal integration]
(© Andrew Simper, Cytomic, 2013) and Vadim Zavalishin's _The Art of VA Filter
Design_.

The filter is two integrators in a loop with a single damping feedback. Each
integrator is a building block with gain `g`; the input summer subtracts the
lowpass and the damped (`× k`) bandpass. The three primary outputs are taps at
the summer (highpass), after the first integrator (bandpass), and after the
second (lowpass); the notch, peak, and allpass are linear combinations of those
taps and the input.

image::svf_block.svg[alt="SVF block diagram", width=750px, align=center, title="Building blocks and output taps: two integrators, a damping feedback, and the HP/BP/LP taps (notch/peak/allpass are sums of these).", link={imagesdir}/svf_block.svg]

* Each integrator has the gain `g = tan(pi * fc / fs)`.
* `k = 1/Q` scales the bandpass. The lowpass is added to it, and `× −1` subtracts the sum from the input.
* The notch is HP + LP, the peak is LP − HP, and the allpass is the input − 2k·BP.

A single tick produces *every* second-order response from the same two states:
lowpass, bandpass, highpass, notch, peak, and allpass.

image::svf_response.svg[alt="svf magnitude response", width=820px, align=center, title="Left: the responses available from one filter. Right: the lowpass at rising Q, whose peak height equals Q.", link={imagesdir}/svf_response.svg]

The parametrization is exact. The cutoff coefficient is the bilinear *prewarp*
`g = tan(pi * fc / fs)`, so the actual cutoff (the -3 dB / resonant point) lands
precisely at `fc` at any frequency up to Nyquist. Resonance is the true quality
factor `Q` (internally `k = 1/Q`): `Q = 1/sqrt(2)` is maximally flat
(Butterworth), larger `Q` sharpens the peak, and as `Q -> inf` the filter self
oscillates. A normalized `0..1` resonance control is also provided for
synth-style sweeps.

Because the two states are integrator outputs with a consistent physical
meaning, the cutoff may be changed *every sample* and the filter stays stable
and free of zipper noise, even at high resonance and into self-oscillation. A
direct-form {biquad} stores past input and output samples that match only the
coefficients that produced them, so changing its coefficients during an
envelope or LFO sweep clicks and can ring or become unstable. The filter is
unconditionally stable for `g > 0` and `k >= 0`.

Cost is about six multiplies per sample, plus one divide when the cutoff or `Q`
changes; see {resonant_filters} for a comparison.

NOTE: For the cheaper (but range-limited and less accurate) Chamberlin
state-variable filter, see {chamberlin_filter}; for a 4-pole ladder, see
{moog_ladder}.

== Modal Placement

For modal synthesis the filter may also be placed by center frequency and
amplitude decay time constant `tau` (the 1/e time of the impulse-response
envelope), the two numbers a mode table specifies. The mapping follows from
the resonator bandwidth relation `BW = 1/(pi*tau)`: `Q = pi * f * tau` (the
free function `q_from_decay`). Excited by an impulse, the filter rings at `f`
with an envelope that decays by 1/e every `tau` seconds; a bank of these is
the classic modal voice.

The bandpass and lowpass taps are 90 degrees apart at resonance, so
`bg * bandpass + lg * lowpass` gives an arbitrary *complex* per-mode transfer
gain, magnitude and phase, with two multiply-adds on taps that one tick
already computes.

#include <q/fx/svf.hpp>

== Declaration

```c++
struct svf
{
   static constexpr double default_q = 0.707106781186548;   // 1/sqrt(2)

                  svf(frequency f, float sps, double q = default_q);
                  svf(frequency f, float sps, duration tau);

   float          operator()(float x);

   float          lowpass() const;
   float          bandpass() const;
   float          highpass() const;
   float          notch() const;
   float          peak() const;
   float          allpass() const;

   void           cutoff(frequency f, float sps);
   void           resonance(double q);
   void           normalized_resonance(float r);
   void           config(frequency f, float sps, double q);
   void           config(frequency f, float sps, duration tau);

   svf&           operator=(float y);
};

// Free functions
constexpr double  q_from_decay(frequency f, duration tau);
```

== Expressions

=== Notation

`sv`, `a`, `b`    :: Objects of type `svf`.
`f`               :: Object of type `{frequency}`: the cutoff.
`sps`             :: Floating point value for samples per second.
`q`               :: Floating point value for the quality factor, `Q`.
`tau`             :: Object of type `{duration}`: the 1/e decay time.
`r`               :: Floating point value for the normalized resonance, from 0.0 to 1.0.
`x`               :: Floating point value for the latest input sample.
`y`               :: Floating point value.

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression                | Semantics

| `svf(f, sps [, q])`       | Construct an `svf` given `f` (cutoff), `sps`
                              (samples per second) and `q` (quality
                              factor, `svf::default_q` by default).
| `svf(f, sps, tau)`        | Construct an `svf` that rings at `f` and
                              decays by 1/e every `tau`
                              (`Q = pi * f * tau`).
| `svf(sv)`                 | Copy construct from `svf sv`.
| `a = b`                   | Assign `b` to `a`.
| `a = y`                   | Set the state to the steady state of a
                              constant input `y`.
|===

NOTE: C++ brace initialization may also be used.

=== Function Call

[cols="1,1,1"]
|===
| Expression  | Semantics                                       | Return Type

| `sv(x)`     | Process the input sample `x` and return the
                lowpass output.                                 | `float`
|===

=== Accessors

[cols="1,1,1"]
|===
| Expression       | Semantics                                   | Return Type

| `sv.lowpass()`   | Get the lowpass output of the latest tick.  | `float`
| `sv.bandpass()`  | Get the bandpass output of the latest tick. | `float`
| `sv.highpass()`  | Get the highpass output of the latest tick. | `float`
| `sv.notch()`     | Get the notch output of the latest tick.    | `float`
| `sv.peak()`      | Get the peak output of the latest tick.     | `float`
| `sv.allpass()`   | Get the allpass output of the latest tick.  | `float`
|===

The outputs are valid after a call to `sv(x)`, and all come from the same tick.

=== Mutators

[cols="1,1,1"]
|===
| Expression                       | Semantics                            | Return Type

| `sv.cutoff(f, sps)`              | Set the cutoff given `f` (cutoff)
                                     and `sps` (samples per second).
                                     Cheap enough to call every sample.  | `void`
| `sv.resonance(q)`                | Set the resonance given `q`
                                     (quality factor).                   | `void`
| `sv.normalized_resonance(r)`     | Set the resonance given `r`
                                     (normalized resonance): 0 gives
                                     `Q = 0.5`, and `Q` grows without
                                     bound as `r` approaches 1.          | `void`
| `sv.config(f, sps, q)`           | Set the cutoff and the resonance.   | `void`
| `sv.config(f, sps, tau)`         | Set the cutoff to `f` and the
                                     resonance to decay by 1/e every
                                     `tau` (`Q = pi * f * tau`).         | `void`
|===

WARNING: `sv.normalized_resonance(r)` does not clamp `r`. At `r = 1` the
damping is 0 and the filter self-oscillates; above 1 the damping is negative
and the output grows without bound.

=== Access

[cols="1,1,1"]
|===
| Expression          | Semantics                                  | Return Type

| `svf::default_q`    | Get the default quality factor, `1/sqrt(2)`
                        (Butterworth).                             | `double`
|===

=== Functions

[cols="1,1,1"]
|===
| Expression              | Semantics                             | Return Type

| `q_from_decay(f, tau)`  | Get the quality factor of a mode at
                            `f` that decays by 1/e every `tau`:
                            `pi * f * tau`.                       | `double`
|===

=== Example

Filter the input samples `in`, at `sps` samples per second, with a resonant
lowpass swept by an envelope, as in the {tutorial-square_synth} tutorial:

```c++
#include <q/fx/svf.hpp>
#include <q/support/literals.hpp>  // For the literals
#include <span>
...
namespace q = cycfi::q;
using namespace q::literals;

std::span<float const> env;         // the envelope, one value per sample, 0 to 1
...
auto filter = q::svf{1_kHz, sps, 2.0};                       <1>

for (std::size_t i = 0; i != in.size(); ++i)
{
   filter.cutoff(q::frequency{60.0 + env[i] * 6000.0}, sps); <2>
   auto y = filter(in[i]);                                   <3>
   // Use y
}
```

<1> Construct an `svf` with a cutoff of 1 kHz and a `Q` of 2.
<2> Sweep the cutoff from 60 Hz up with the envelope, every sample.
<3> Process the sample and return the lowpass output.
