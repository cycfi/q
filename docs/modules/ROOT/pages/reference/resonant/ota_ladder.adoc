= OTA Ladder Filter

include::../../common.adoc[]

== Overview

The OTA ladder filter is the four-pole lowpass of the polysynths of the
early 1980s: four variable gain (OTA) stages in series inside a global
resonance loop. `ota_ladder` is a {basic_ladder} with the cell of those
instruments; it differs from {moog_ladder} only in the cell.

A transistor ladder saturates symmetrically and adds odd harmonics, the
Moog growl. An OTA cell runs off center and distorts asymmetrically: the
Curtis CEM3320 data sheet gives a passband distortion of 0.1 percent typical,
"predominantly second harmonic". That chip is the filter in the Prophet-5
Rev 3, the OB-Xa and the OB-8.

`drive` sets how hard the cell is driven, and `asymmetry` how far off center
it sits, 0 being the symmetric curve of a transistor ladder. The curve is a
`tanh` taken off center, shifted so zero maps to zero and scaled so the small
signal gain is 1: the asymmetry changes the harmonic mix without changing the
level or adding a DC step.

At drive 0 the filter is linear and resolves the zero-delay feedback exactly,
sample for sample the same as {moog_ladder} in its linear mode. Above 0, the
cell works from the previous output (see {basic_ladder}); the four stages stay
TPT, and the cell costs one `tanh` per sample.

NOTE: `ota_ladder` takes the topology and the distortion character from the
data sheets of those instruments' filter chip. It does not model a particular
synthesizer.

== Drive and Resonance

With the default asymmetry of 0.9 and no resonance, a drive of 0.5 to 2 puts
the second harmonic 17 to 24 times above the third.

The cell takes the feedback along with the signal, so resonance raises the
level at the cell, and the same drive distorts more. At resonance 0.3 the
ratio runs from 17 down to 5 across that drive range, and at 0.7 from 12 down
to 0.55, where the odd harmonics dominate. Reduce the drive as resonance rises
to keep the second-harmonic character.

== Include

```c++
#include <q/fx/ladder.hpp>
```

== Declaration

```c++
struct ota_ladder : basic_ladder<detail::ota_cell, 4>
{
   using base_type = basic_ladder<detail::ota_cell, 4>;
   using base_type::base_type;
   using base_type::operator=;

   void           drive(float amount);
   float          drive() const;
   void           asymmetry(float amount);
   float          asymmetry() const;
};
```

== Expressions

As a subclass of `{basic_ladder}`, `ota_ladder` inherits all the publicly
accessible member functions, member variables, and types of its base class.
In addition to valid expressions for {basic_ladder}, `ota_ladder` allows
these expressions.

=== Notation

`ld`           :: Object of type `ota_ladder`.
`f`            :: Object of type `{frequency}`: the cutoff.
`sps`          :: Floating point value for samples per second.
`r`            :: Floating point value for the normalized resonance, from 0.0 to 1.0.
`amount`       :: Floating point value.

=== Constructors

[cols="1,1"]
|===
| Expression                | Semantics

| `ota_ladder(f, sps [, r])` | Construct an `ota_ladder` given `f`
                              (cutoff), `sps` (samples per second) and
                              `r` (normalized resonance, 0 by default).
|===

NOTE: C++ brace initialization may also be used.

=== Mutators

[cols="1,1,1"]
|===
| Expression               | Semantics                                  | Return Type

| `ld.drive(amount)`       | Set the drive. 0 is linear, and the filter
                             then takes the exact zero-delay path; a
                             negative `amount` is taken as 0.           | `void`
| `ld.asymmetry(amount)`   | Set the asymmetry. 0 is the symmetric
                             curve of a transistor ladder.              | `void`
|===

=== Accessors

[cols="1,1,1"]
|===
| Expression               | Semantics                                  | Return Type

| `ld.drive()`             | Get the drive (0 by default).              | `float`
| `ld.asymmetry()`         | Get the asymmetry (0.9 by default).        | `float`
|===

=== Example

A bass patch of the era: filter the input samples `in`, at `sps` samples per
second, with the cutoff swept by an envelope and the cell driven enough to thicken
the note:

```c++
#include <q/fx/ladder.hpp>
#include <q/support/literals.hpp>  // For the literals
#include <span>
...
namespace q = cycfi::q;
using namespace q::literals;

std::span<float const> env;         // the envelope, one value per sample, 0 to 1
...
auto filter = q::ota_ladder{220_Hz, sps, 0.35f};                  <1>
filter.drive(2.0f);                                               <2>

for (std::size_t i = 0; i != in.size(); ++i)
{
   auto e = env[i];
   filter.cutoff(q::frequency{220 + 3000 * e * e}, sps);          <3>
   auto y = filter(in[i]);                                        <4>
   // Use y
}
```

<1> Construct an `ota_ladder` with a cutoff of 220 Hz and a resonance of 0.35.
<2> Set the drive of the cell.
<3> Sweep the cutoff from 220 Hz up with the envelope, every sample.
<4> Process the sample and return the lowpass output.

TIP: Sweep `asymmetry` from 0 to 1 at a steady drive to move the tone from
the odd harmonics of a transistor ladder to the even-harmonic character of
the OTA instruments.
