= Moving Average

include::../../common.adoc[]

== Overview

The moving_average is the simplest and most efficient FIR filter. It is also the most common filter in DSP primarily due to its simplicity. But while it is technically a low pass FIR filter, it performs poorly in the frequency domain with very slow roll-off and dreadful stopband
attenuation. On the other hand, it performs admirably in the time domain. The moving average filter is optimal in reducing random noise while retaining a sharp step response.

Averaging N samples (the moving average window size) increases the SNR by the square root of N. For example, N=16 improves SNR by 4 (12dB). The filter delay is exactly (N−1)/2.

image::moving-average.svg[alt="Moving Average", width=500px, align=center, title="Moving Average"]

When data is pushed into a moving average, the element indices are shifted by one position to accommodate the incoming data. This logical shifting ensures that the newest data is stored in the first index (index 0), while the oldest data is pushed out of the buffer. The physical location of data does not actually change, only the indices.

The data type, `T`, is a template parameter, allowing both floating point as well as integer computations. Integers are typically faster than floating point and are not prone to round-off errors.

`moving_average` is a subclass of the `{mono-moving_sum}`.

`basic_moving_average_ref` computes the same moving average over a history the caller owns, with no buffer of its own.

== Moving Average

=== Include

```c++
#include <q/fx/moving_average.hpp>
```

=== Declaration

```c++
template <typename T, typename Accumulator = decltype(promote(T()))>
struct basic_moving_average : basic_moving_sum<T, Accumulator>
{
   using base_type = basic_moving_sum<T, Accumulator>;
   using base_type::base_type;
   using value_type = T;

   T  operator()(T s);
   T  operator()() const;
};

using moving_average = basic_moving_average<float>;
```

=== Expressions

As a subclass of {moving_sum}, `moving_average` inherits all the publicly accessible member functions, member variables, and types of its base class.

In addition to valid expressions for {moving_sum}, `moving_average` allows these expressions.

`T`            :: Element type, e.g. `float`.
`A`            :: Accumulator type, e.g. `double`.
`ma`           :: Object of type `basic_moving_average<T, A>`.
`s`            :: Object of type `T`.

                                    the element type, e.g. `float`, and optionally

==== Example

Smooth the input samples `in`, in place, with a 16-sample moving average:

```c++
namespace q = cycfi::q;

auto ma = q::moving_average{16};                         <1>

for (auto& s : in)
   s = ma(s);                                            <2>
```

<1> Construct a moving average with a window of 16 samples.
<2> Add the sample and return the average over the window.

== Moving Average Ref

`basic_moving_average_ref` is the moving average over a history the caller owns. It is to `basic_moving_average` what `basic_moving_sum_ref` is to `basic_moving_sum`: the same arithmetic, with no storage of its own.

=== Include

```c++
#include <q/fx/moving_average.hpp>
```

=== Declaration

```c++
template <typename T>
struct basic_moving_average_ref : basic_moving_sum_ref<T>
{
   using basic_moving_sum_ref<T>::basic_moving_sum_ref;
   using value_type = T;

   T  operator()(value_type s, value_type departing);

   template <concepts::IndexableContainer History>
   T  operator()(value_type s, History const& hist);

   T  operator()() const;
};

using moving_average_ref = basic_moving_average_ref<float>;
```

:moving_sum_ref: xref:reference/misc/moving_sum.adoc#_moving_sum_ref[Moving Sum Ref]

=== Expressions

As a subclass of `basic_moving_sum_ref` (see {moving_sum_ref}), `basic_moving_average_ref` inherits all the publicly accessible member functions, member variables, and types of its base class.

In addition to valid expressions for {moving_sum_ref}, `basic_moving_average_ref` allows these expressions.

==== Notation

`T`            :: Element type, e.g. `float`.
`mar`          :: Object of type `basic_moving_average_ref<T>`.
`s`            :: Object of type `T`: the latest input sample.
`x`            :: Object of type `T`: the departing sample.
`hist`         :: Object of a type that conforms to `{indexable-concept}`: the history, `hist[0]` the most recent sample.

==== Type Construction

[cols="1,1"]
|===
| Expression                      | Semantics

| `basic_moving_average_ref<T>`   | Instantiate a `basic_moving_average_ref` type
                                    given `T`, the element type, e.g. `float`.
| `moving_average_ref`            | Pre declared `basic_moving_average_ref<float>` type.
|===

==== Function Call

[cols="1,1,1"]
|===
| Expression      | Semantics                                  | Return Type

| `mar(s, hist)`  | Process the input sample `s`, reading the
                    departing sample from `hist`, and return
                    the current average.                       | `T`
| `mar(s, x)`     | Process the input sample `s`, given `x`
                    (the departing sample), and return the
                    current average.                           | `T`
| `mar()`         | Get the current average.                   | `T`
|===

WARNING: The history holds at least `mar.size()` samples. The caller owns it and pushes it exactly once per sample, after every view has read it. See {moving_sum_ref}.

==== Example

Average the absolute value of the input samples `in` over 32 samples, from a
history of the raw signal:

```c++
namespace q = cycfi::q;

auto hist = q::ring_buffer<float>{32};
hist.clear();
auto mean_abs = q::moving_average_ref{32};                     <1>

for (auto s : in)
{
   auto departing = hist[mean_abs.size() - 1];
   auto level = mean_abs(std::abs(s), std::abs(departing));    <2>
   hist.push(s);                                               <3>
   // Use level, the mean absolute value
}
```

<1> Construct a moving average with a window of 32 samples over the history.
<2> Average the absolute values: the sample entering the window and the one
    leaving it.
<3> Push the raw sample once, after every view has read the history.

== Exponential Moving Average

An exponential moving average approximates the moving average with a one-pole recursion, `y = b * s + (1 - b) * y`. It keeps no history: it costs two multiplies and one add per sample for any window, and its window can change at no cost. A sample leaves the moving average after N samples; in the exponential average, its weight decays without reaching zero.

With `b = 2 / (n + 1)`, both averages give the input the same mean age, `(n - 1) / 2` samples, so an exponential average of span `n` tracks a moving average of `n` samples closely. `n` is that span; the 1/e time constant is about `n / 2`. The envelope followers use the same convention.

image::exp_moving_average.svg[alt="Weights and step responses of moving_average and exp_moving_average", width=700px, align=center, title="moving_average and exp_moving_average of the same span, 16. Left, the weight each gives a sample by its age: equal weights for 16 samples, against weights that fade without end, with the same mean age. Right, their step responses.", link={imagesdir}/exp_moving_average.svg]

Q provides two forms:

* `exp_moving_average<n>` fixes the span at compile time and computes `b` there.
* `rt_exp_moving_average` takes the span at run time, in samples or as a duration, and can change it.

=== Include

```c++
#include <q/fx/moving_average.hpp>
```

=== Declaration

```c++
template <std::size_t n>
struct exp_moving_average
{
   static constexpr float b = 2.0f / (n + 1);
   static constexpr float b_ = 1.0f - b;

                        exp_moving_average(float y = 0.0f);

   float                operator()(float s);
   float                operator()() const;
   exp_moving_average&  operator=(float y);

   float                y = 0.0f;
};

struct rt_exp_moving_average
{
   using self_type = rt_exp_moving_average;

                        rt_exp_moving_average(float n, float y = 0.0f);
                        rt_exp_moving_average(
                           duration d
                         , float sps
                         , float y = 0.0f
                        );

   float                operator()(float s);
   float                operator()() const;
   self_type&           operator=(float y);

   void                 width(float n);

   float                y = 0.0f;
   float                b, b_;
};
```

=== Expressions

==== Notation

`n`         :: `std::size_t` constant: the span in samples.
`w`         :: Floating point value for the span in samples.
`E`         :: The type `exp_moving_average<n>` or `rt_exp_moving_average`.
`e`, `e2`  :: Objects of type `E`.
`r`         :: Object of type `rt_exp_moving_average`.
`d`         :: Object of type `duration`: the span as a time.
`sps`       :: Floating point value for samples per second.
`s`         :: Floating point value for the latest input sample.
`v`         :: Floating point value.

==== Constructors and Assignment

[cols="1,1"]
|===
| Expression                              | Semantics

| `exp_moving_average<n>([v])`            | Construct an `exp_moving_average<n>`
                                            given `v` (initial value, default 0).
| `rt_exp_moving_average(w [, v])`        | Construct an `rt_exp_moving_average`
                                            given `w` (span in samples) and `v`
                                            (initial value, default 0).
| `rt_exp_moving_average(d, sps [, v])`   | Construct an `rt_exp_moving_average`
                                            given `d` (span), `sps` (samples per

|===

[cols="1,1,1"]
|===
| Expression      | Semantics                                  | Return Type

| `e(s)`          | Process the input sample `s` and return
                    the average.                               | `float`

|===

==== Mutators

[cols="1,1,1"]
|===
| Expression      | Semantics                                  | Return Type

==== Access

[cols="1,1,1"]
|===
| Expression      | Semantics                                  | Return Type

| `e.y`           | Get or set the current value.              | `float`

==== Example

Measure the level of the input samples `in`, at `sps` samples per second, with
a span the user can change:

```c++
namespace q = cycfi::q;
using namespace q::literals;

auto meter = q::rt_exp_moving_average{300_ms, sps};      <1>

float level = 0;
for (auto s : in)
   level = meter(std::abs(s));                           <2>

meter.width(0.05f * sps);                                <3>
```

<1> Construct an exponential moving average with a span of 300 ms.
<2> Average the absolute value of the sample.
<3> Change the span to 50 ms, in samples, for example when the user picks a
    faster meter.

== Two Point Average

`moving_average2` is the moving average of the last two samples, `(s + prev) / 2`, without the history buffer. It puts a zero at Nyquist, so a signal that alternates sample by sample averages out to its mean, and its delay is half a sample.

image::moving_average2.svg[alt="Magnitude response of moving_average2", width=700px, align=center, title="The magnitude response of moving_average2 at 48 kHz: down 3 dB at a quarter of the sample rate, and a zero at Nyquist.", link={imagesdir}/moving_average2.svg]

=== Include

```c++
#include <q/fx/moving_average.hpp>
```

=== Declaration

```c++
struct moving_average2
{
   float    operator()(float s);
   float    operator()() const;

   float    y = 0.0f;
};
```

=== Expressions

==== Notation

`ma2`, `a`, `b`  :: Objects of type `moving_average2`.
`s`              :: Floating point value for the latest input sample.

==== Constructors and Assignment

[cols="1,1"]
|===
| Expression              | Semantics

| `moving_average2()`     | Construct a `moving_average2`, with the average
                            and the previous sample at 0.
| `moving_average2(ma2)`  | Copy construct from `moving_average2 ma2`.
| `a = b`                 | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used.

==== Function Call

[cols="1,1,1"]
|===
| Expression      | Semantics                                  | Return Type

| `ma2(s)`        | Process the input sample `s` and return
                    the average of `s` and the previous
                    sample.                                    | `float`

|===

==== Access

[cols="1,1,1"]
|===
| Expression      | Semantics                                  | Return Type

| `ma2.y`         | Get or set the latest average.             | `float`
|===

==== Example

Remove the sample-to-sample jitter from the sensor readings `in`, in place,
with half a sample of latency:

```c++
namespace q = cycfi::q;

auto ma2 = q::moving_average2{};                         <1>

for (auto& r : in)
   r = ma2(r);                                           <2>
```

<1> Construct a two point average, with the previous sample at 0.
<2> Replace each reading with the average of it and the previous reading.
