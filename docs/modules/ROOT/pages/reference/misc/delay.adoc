= Delay

include::../../common.adoc[]

== Overview

Delays are important DSP building blocks. They introduce repetitions of the original signal, resulting in spacious soundscapes and echoes. The number of repetitions is controlled via feedback. The interval between the initial signal and the repetitions is altered by adjusting the delay time. Longer durations provide echoes, whereas shorter delays produce doubling effects. Filters can shape the repeating signals, influencing their tonal properties.

Delays are also essential for modulation effects such as flangers and choruses, which are created by dynamically modulating delay times using low-frequency oscillators (LFOs).

== Basic Delay

`basic_delay` is a basic class for delays. The actual delay duration parameter is decoupled from, and managed outside the class to allow both single and multi-tapped delays. The delay is implemented using a base ring buffer with provisions for non-fractional (exact) and fractional (sub-sample) indexing. Fractional element indexing is required for fractional delays that are not integer multiples of the sampling period. Fractional indexing uses one of the `{sample_interpolation}` types. For delays whose tap positions are modulated, see the guidance on choosing an interpolation type there.

image::delay-line.svg[alt="Delay Line", width=500px, align=center, title="Delay Line"]

`basic_delay` is a template class whose `Base` template parameter should be the ring buffer storage type it inherits from. See {ring_buffer} and {fractional_ring_buffer}.

=== Include

```c++
#include <q/fx/delay.hpp>
```

=== Declaration

```c++
template <typename Base>
class basic_delay : public Base
{
public:

   using base_type = Base;
   using value_type = typename Base::value_type;
   using storage_type = typename Base::storage_type;
   using index_type = typename Base::index_type;
   using interpolation_type = typename Base::interpolation_type;

            basic_delay(duration max_delay, float sps);
   explicit basic_delay(std::size_t max_delay_samples);

   float    operator()() const;
   float    operator()(index_type i) const;
   float    operator()(value_type val, index_type i);
};

// Fractional delay
using delay = basic_delay<fractional_ring_buffer<float>>;

// Non-fractional delay
using nf_delay = basic_delay<ring_buffer<float>>;
```

=== Expressions

In addition to valid expressions for the `Base` class that the `basic_delay` inherits from (See {ring_buffer} and {fractional_ring_buffer}), `basic_delay` allows these expressions.

==== Notation

`Base`            :: Ring buffer storage type, e.g. `ring_buffer<float>`.
`d_type`          :: A `basic_delay<Base>` type.
`d`, `a`, `b`     :: Objects of type `basic_delay<Base>`.
`val`             :: Object of type `d_type::value_type`.
`i`               :: Object of type `d_type::index_type`.
`max_delay`       :: Object of type `duration`.
`n`               :: Object of type `std::size_t`, a maximum delay in samples.
`sps`             :: Floating point value representing samples per second.

==== Type Construction

[cols="1,1"]
|===
| Expression            | Semantics

| `basic_delay<Base>`   | Instantiate a `basic_delay` type given `Base`
                          ring buffer storage type.
| `delay`               | Pre declared fractional delay type.
| `nf_delay`            | Pre declared non-fractional delay type.

|===

===== Examples:

```c++
using my_delay_type1 = basic_delay<fractional_ring_buffer<float>>;
using my_delay_type2 = delay;
```

==== Type Definitions

[cols="1,1,1"]
|===
| Expression                      | Semantics                     | Type

| `d_type::base_type`             | Get the ring buffer type.     | `Base`
| `d_type::value_type`            | Get the element type.         | `Base::value_type`
| `d_type::storage_type`          | Get the storage type.         | `Base::storage_type`
| `d_type::index_type`            | Get the index type.           | `Base::index_type`
| `d_type::interpolation_type`    | Get the interpolation type.   | `Base::interpolation_type`
|===

==== Constructors and Assignment

[cols="1,1"]
|===
| Expression                  | Semantics

| `d_type(max_delay, sps)`    | Construct a `basic_delay` with maximum duration,
                                `max_delay` and samples per second, `sps`.
| `d_type(n)`                 | Construct a `basic_delay` given `n` (maximum
                                delay in samples). The ring buffer rounds `n`
                                up to its capacity.
| `d_type(d)`                 | Copy construct from `d_type d`.
| `a = b`                     | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used.

==== Function Call

[cols="1,1,1"]
|===
| Expression      | Semantics                                  | Return Type

| `d()`           | Get the delayed signal (maximum delay).    | `float`
| `d(i)`          | Get the delayed signal at index `i`.       | `float`
| `d(val, i)`     | Push a new signal and return the delayed
                    signal at index `i+1`.                     | `float`
|===

NOTE: `d(val, i)` is the simplest (common) case for single delays. For multi-tapped delays, you need to access the individual delays using the indexing operator for various tap-points before pushing the latest sample.

==== Example

Mix the input samples `in`, at `sps` samples per second, with an echo 250 ms later, at half the level:

```c++
namespace q = cycfi::q;
using namespace q::literals;

auto dly = q::delay{1_s, sps};                  <1>
auto const i = q::as_float(250_ms) * sps;       <2>

for (auto& s : in)
   s += 0.5f * dly(s, i);                       <3>
```

<1> Construct a fractional delay with a maximum delay of 1 second.
<2> Compute the delay index of the 250 ms tap, in samples.
<3> Push the sample, and add the delayed signal at index `i+1` at half the
    level.

== One and Two Sample Delays

`delay1` and `delay2` are fixed delays of one and two samples, the z^-1^ and z^-2^ of a filter diagram. They keep their samples in members, with no buffer to index, so a sample costs a copy or two. Use them where a filter structure calls for a unit delay, or to keep a dry path in step with a processed path that lags it by a sample or two.

image::delay1_delay2.svg[alt="An input and its delay1 and delay2 outputs", width=700px, align=center, title="The same input through delay1 and delay2. Each output is the input moved one or two samples later; the dotted lines follow the first sample through.", link={imagesdir}/delay1_delay2.svg]

=== Include

```c++
#include <q/fx/delay.hpp>
```

=== Declaration

```c++
struct delay1
{
   float    operator()(float s);
   float    operator()() const;

   void     reset();
};

struct delay2
{
   float    operator()(float s);
   float    operator()() const;

   void     reset();
};
```

=== Expressions

==== Notation

`D`             :: `delay1` or `delay2`.
`z`, `a`, `b`   :: Objects of type `D`.
`s`             :: Floating point value for the latest input sample.

==== Constructors and Assignment

[cols="1,1"]
|===
| Expression      | Semantics

| `D()`           | Construct a `D` with its stored samples at 0.
| `D(z)`          | Copy construct from `D z`.
| `a = b`         | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used.

==== Function Call

[cols="1,1,1"]
|===
| Expression      | Semantics                                  | Return Type

| `z(s)`          | Process the input sample `s` and return
                    the sample from one call ago (`delay1`) or
                    two calls ago (`delay2`).                  | `float`
| `z()`           | Get the sample the next `z(s)` will
                    return.                                    | `float`
|===

==== Operation

[cols="1,1,1"]
|===
| Expression      | Semantics                                  | Return Type

| `z.reset()`     | Reset the stored samples to 0.             | `void`
|===

==== Example

Blend the input samples `in` with their rate of change. `{central_difference}` estimates the slope at the previous sample, one sample behind its input. A `delay1` keeps the dry path in step with it.

```c++
#include <q/fx/delay.hpp>
#include <q/fx/differentiator.hpp>  // For central_difference
...
namespace q = cycfi::q;

float amount;                       // the share of the slope in the blend
...
auto diff = q::central_difference{};
auto dry = q::delay1{};                         <1>

for (auto& s : in)
   s = dry(s) + amount * diff(s);               <2>
```

<1> Construct a `delay1` for the dry path.
<2> Delay the dry sample by one sample and add the slope, scaled by `amount`.
