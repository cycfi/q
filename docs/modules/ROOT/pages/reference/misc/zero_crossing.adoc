= Zero Crossing

include::../../common.adoc[]

== Overview

`zero_crossing` generates pulses that coincide with the zero crossings of a signal: the output is high for the positive part of each cycle. It turns a continuous waveform into the rectangular pulses that period and timing analysis work from. To keep noise near the zero line from producing spurious transitions, it applies hysteresis: the output goes high when the signal rises above half the hysteresis amount, and goes low when the signal falls below the negative of that half.

image::zero_crossing.svg[alt="Zero-crossing pulses and the extended edge information", width=700px, align=center, title="Left: the boolean pulse (green) goes high once the input clears the upper edge of the hysteresis band (amber) and releases only after it clears the lower edge. Right: zero_crossing_ex marks the leading edge of each pulse (magenta) and records the peak height of the waveform it bounds (green), the raw material for period and pulse-width measurement.", link={imagesdir}/zero_crossing.svg]

`zero_crossing_ex` is the extended form, for the timing measurements that pitch detection needs. It records the leading and trailing edges of each pulse, the samples around each crossing, and the peak height of the waveform each pulse bounds.

== Zero Crossing

The hysteresis is given as a floating point value or in decibels. The band runs from `-h/2` to `+h/2`, centered on zero.

==== Example

Turn the input samples `in` into pulses that are high for the positive part
of each cycle:

```c++
namespace q = cycfi::q;

auto zc = q::zero_crossing{0.03f};                        <1>

for (auto& s : in)
   s = zc(s);                                             <2>
```

<1> Construct a `zero_crossing` with a hysteresis of 0.03, a band of
    ±0.015 around zero.
<2> Process the sample and replace it with the state, 1 or 0.

== Extended Zero Crossing

The function call of `zero_crossing_ex` returns an `int` event code: `1` at the leading edge (the sample where the pulse opens), `-1` at the trailing edge (where it closes), and `0` otherwise. Each pulse has an `info` record, returned by `get_info()`, holding the samples around the crossing, the peak height of the bounded waveform, and the leading and trailing edge positions. From two consecutive `info` records, `period` gives the period in whole samples, and `fractional_period` gives it to a fraction of a sample, from a linear interpolation of each crossing. The leading edge and crossing data are valid as soon as the pulse opens, which is enough for the period; the `width` and `height` are valid after the trailing edge.

The {zero_crossing_collector} uses the `info` records to propose candidate periods to the pitch detector.


=== Declaration

```c++
class zero_crossing_ex
{
public:

   static constexpr float pulse_height_diff = 0.6;

   class info
   {
   public:

      using crossing_data = std::pair<float, float>;

                        info() = default;
                        info(
                           crossing_data const& crossing_
                         , float peak_
                         , std::size_t leading_edge_
                        );

      static constexpr std::size_t undefined_edge
         = int_traits<std::size_t>::max/2;

      // Available after the leading edge
      crossing_data     crossing() const;
      std::size_t       leading_edge() const;
      std::size_t       period(info const& next) const;
      float             fractional_period(info const& next) const;
      void              update(float height);

      // Available after the trailing edge
      std::size_t       width() const;
      float             height() const;
      std::size_t       trailing_edge() const;
      bool              similar(info const& next) const;
   };

                        zero_crossing_ex(float hysteresis);
                        zero_crossing_ex(decibel hysteresis);

   int                  operator()(float s);
   int                  operator()(float s, float hysteresis);
   bool                 operator()() const;

   info const&          get_info() const;
   void                 reset();
};
```

==== Accessors

[cols="1,1,1"]
|===
| Expression                  | Semantics                             | Return Type

| `zx.get_info()`             | Get the `info` record of the current
                                pulse.                                | `zero_crossing_ex::info const&`
| `i.crossing()`              | Get the samples before and after the
                                leading edge, measured from the
                                hysteresis edge.                      | `std::pair<float, float>`
| `i.leading_edge()`          | Get the leading edge position, in
                                samples.                              | `std::size_t`
| `i.trailing_edge()`         | Get the trailing edge position, in
                                samples.                              | `std::size_t`
| `i.period(next)`            | Get the period from this pulse to
                                `next`, in whole samples.             | `std::size_t`
| `i.fractional_period(next)` | Get the period from this pulse to
                                `next`, in samples, to a fraction of
                                a sample.                             | `float`
| `i.width()`                 | Get the pulse width, in samples.      | `std::size_t`
| `i.height()`                | Get the peak height of the waveform
                                the pulse bounds, measured from
                                zero.                                 | `float`
| `i.similar(next)`           | Return `true` if the peak heights of
                                this pulse and `next` differ by no
                                more than 40% of the larger.          | `bool`
|===

Edge positions count samples from construction or the latest `reset()`.

WARNING: Before the trailing edge, only `crossing()` and `leading_edge()` are valid, which is enough for `period` and `fractional_period`. `width()`, `height()`, `trailing_edge()` and `similar()` are valid after the trailing edge.

`height()` is the crest of the pulse measured from zero. `crossing()` holds the two samples that straddle the upper edge of the hysteresis band, `+h/2`, measured from that edge: the first is at or below zero and the second above it. That is what makes the interpolation `-prev / (curr - prev)` in `fractional_period` work.

==== Example

Measure the period of the input samples `in`, in samples, to a fraction of a
sample:

```c++
namespace q = cycfi::q;

auto zx = q::zero_crossing_ex{0.03f};                     <1>
auto prev = q::zero_crossing_ex::info{};
float period = 0;

for (auto s : in)
{
   if (zx(s) == 1)                                        <2>
   {
      auto const& next = zx.get_info();                   <3>
      if (prev.leading_edge() != prev.undefined_edge)
         period = prev.fractional_period(next);           <4>
      prev = next;
   }
}
```

<1> Construct a `zero_crossing_ex` with a hysteresis of 0.03.
<2> Process the sample. `1` marks the leading edge of a new pulse.
<3> Get the `info` record of the new pulse.
<4> Get the period from the previous pulse to the new one, once there is a
    previous pulse.
