= Integrator

include::../../common.adoc[]

== Overview

The integrator accumulates a scaled copy of every input sample into a running total. Each call adds `gain * s` to the total and returns it. A constant input produces a linear ramp; a square wave produces a triangle. It is the discrete counterpart of continuous-time integration, for a signal's running total, area, or first antiderivative. The integrator is implemented by a class named `integrator`.

image::integrator.svg[alt="An integrator turning a square wave into a triangle wave", width=700px, align=center, title="With a constant input the accumulator ramps linearly; with a square wave it integrates each half into a rising then falling slope, producing a triangle.", link={imagesdir}/integrator.svg]

The `gain` (default `0.1`) scales each increment before it is summed. It sets how fast the total moves and, together with the input, how large it grows. The sum has no leak term. The running total is the public member `y`: it can be seeded, read back without advancing, or reset to zero between passes.

== Include

```c++
#include <q/fx/integrator.hpp>
```

== Declaration

```c++
struct integrator
{
               integrator(float gain = 0.1);

   float       operator()(float s);
   float       operator()() const;
   integrator& operator=(float y);

   void        reset();

   float       y = 0.0f;
};
```

== Expressions

=== Notation

`i`, `a`, `b`   :: Objects of type `integrator`.
`gain`          :: Floating point value for the gain applied to each input sample.
`s`             :: Floating point value for the latest input sample.
`v`             :: Floating point value.

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression              | Semantics

| `integrator([gain])`    | Construct an `integrator` given `gain` (default 0.1).
| `integrator(i)`         | Copy construct from `integrator i`.
| `a = b`                 | Assign `b` to `a`.
| `a = v`                 | Set the running total of `a` to `v`.
|===

NOTE: C++ brace initialization may also be used.

=== Function Call

[cols="1,1,1"]
|===
| Expression   | Semantics                                          | Return Type

| `i(s)`       | Process the input sample `s` and return the
                 running total. Each call adds `gain * s`.          | `float`
| `i()`        | Get the running total.                             | `float`
|===

WARNING: The accumulator has no leak. A non-zero mean (DC) input grows without bound over time. Drive the integrator with a zero-mean signal, or place a {dc_block} ahead of it.

=== Operation

[cols="1,1,1"]
|===
| Expression   | Semantics                               | Return Type

| `i.reset()`  | Reset the running total to zero.        | `void`
|===

=== Access

[cols="1,1,1"]
|===
| Expression   | Semantics                               | Return Type

| `i.y`        | Get or set the running total.           | `float`
|===

=== Example

Integrate the input samples `in`, a zero-mean signal, and clear the running
total afterwards:

```c++
namespace q = cycfi::q;

auto integ = q::integrator{0.01f};       <1>

for (auto s : in)
{
   auto y = integ(s);                     <2>
   // Use y, the running total
}

integ.reset();                            <3>
```

<1> Construct an integrator with a gain of 0.01.
<2> Add `0.01 * s` to the running total and return it.
<3> Reset the running total to zero for the next pass.
