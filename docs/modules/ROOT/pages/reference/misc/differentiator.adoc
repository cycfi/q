= Differentiators

include::../../common.adoc[]

== Overview

`first_difference`, `central_difference`, and `slope` estimate how fast a signal is changing, the discrete-time counterpart to a derivative. Each subtracts an earlier sample from the current one. They differ in how far back the earlier sample is: reaching further back rejects more noise and adds latency.

== First Difference

`first_difference` is the plain one-sample difference, `y(n) = x(n) - x(n-1)`. It has no latency and stores one sample. Use it for edge and peak detection, where responsiveness matters more than smoothness. It responds to every sample-to-sample jump, so it also amplifies high-frequency noise.

=== Include

```c++
#include <q/fx/differentiator.hpp>
```

=== Declaration

```c++
struct first_difference
{
               first_difference();

   float       operator()(float s);
};
```

=== Expressions

==== Notation

`fd`, `a`, `b`  :: Objects of type `first_difference`.
`s`             :: Floating point value for the latest input sample.

==== Constructors and Assignment

[cols="1,1"]
|===
| Expression                | Semantics

| `first_difference()`      | Construct a `first_difference` with its stored
                              sample at 0.
| `first_difference(fd)`    | Copy construct from `first_difference fd`.
| `a = b`                   | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used.

==== Function Call

[cols="1,1,1"]
|===
| Expression   | Semantics                                          | Return Type

| `fd(s)`      | Process the input sample `s` and return
                 `s - x(n-1)`, the change since the previous
                 sample.                                            | `float`
|===

==== Example

Mark the peaks of the input samples `in`. The previous sample is a peak where the first difference turns from positive to zero or negative.

```c++
namespace q = cycfi::q;

auto diff = q::first_difference{};        <1>
float prev = 0.0f;

for (auto s : in)
{
   float d = diff(s);                     <2>
   bool peak = prev > 0.0f && d <= 0.0f;
   prev = d;
   // Use peak, true when the previous sample is a peak
}
```

<1> Construct a `first_difference`.
<2> Process the sample and get the change since the previous sample.

== Central Difference

`central_difference` is the difference across two samples, `y(n) = (x(n) - x(n-2)) / 2`, centred on `x(n-1)`. It is a more accurate (second-order) estimate of the slope at `x(n-1)`, and its gain rolls off to zero at Nyquist, so it is gentler on high-frequency noise. Its estimate is one sample late.

=== Include

```c++
#include <q/fx/differentiator.hpp>
```

=== Declaration

```c++
struct central_difference
{
   float       operator()(float s);
};
```

=== Expressions

==== Notation

`cd`, `a`, `b`  :: Objects of type `central_difference`.
`s`             :: Floating point value for the latest input sample.

==== Constructors and Assignment

[cols="1,1"]
|===
| Expression                  | Semantics

| `central_difference()`      | Construct a `central_difference` with its stored
                                samples at 0.
| `central_difference(cd)`    | Copy construct from `central_difference cd`.
| `a = b`                     | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used.

==== Function Call

[cols="1,1,1"]
|===
| Expression   | Semantics                                          | Return Type

| `cd(s)`      | Process the input sample `s` and return
                 `(s - x(n-2)) / 2`, the slope estimate at the
                 previous sample.                                   | `float`
|===

NOTE: `central_difference` lags its input by one sample.

==== Example

Estimate the rate of change of the input samples `in`, with less high-frequency noise than `first_difference`:

```c++
namespace q = cycfi::q;

auto diff = q::central_difference{};      <1>

for (auto s : in)
{
   float rate = diff(s);                  <2>
   // Use rate, the slope at the previous sample
}
```

<1> Construct a `central_difference`.
<2> Process the sample and get the slope estimate at the previous sample.

== Slope

`slope` is the difference across a window of `m` samples, `y(n) = x(n) - x(n-(m-1))`. Constructed from a `{duration}` and a sample rate, it gives the total change over that span of time, for tracking a trend with less sensitivity to sample-scale wiggle. It buffers `m` samples in a `{ring_buffer}`.

=== Include

```c++
#include <q/fx/differentiator.hpp>
```

=== Declaration

```c++
struct slope
{
               slope(std::size_t max_size);
               slope(duration dt, float sps);

   float       operator()(float s);
   float       operator()() const;
};
```

=== Expressions

==== Notation

`sl`, `a`, `b`  :: Objects of type `slope`.
`m`             :: Object of type `std::size_t` for the window in samples.
`dt`            :: Object of type `duration`, the window as a span of time.
`sps`           :: Floating point value for samples per second.
`s`             :: Floating point value for the latest input sample.

==== Constructors and Assignment

[cols="1,1"]
|===
| Expression          | Semantics

| `slope(m)`          | Construct a `slope` given `m` (window in samples).
| `slope(dt, sps)`    | Construct a `slope` given `dt` (window duration)
                        and `sps` (samples per second). The window is
                        `sps * dt` samples.
| `slope(sl)`         | Copy construct from `slope sl`.
| `a = b`             | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used.

==== Function Call

[cols="1,1,1"]
|===
| Expression   | Semantics                                          | Return Type

| `sl(s)`      | Process the input sample `s` and return
                 `s - x(n-(m-1))`, the change over the window.      | `float`
| `sl()`       | Get the latest result.                             | `float`
|===

NOTE: `slope` lags its input by `(m-1)/2` samples, the centre of its window.

==== Example

Track the trend of an envelope, at `sps` samples per second, over a 10 ms window: rising during the attack, falling during the decay.

```c++
#include <q/fx/differentiator.hpp>
#include <span>
...
namespace q = cycfi::q;
using namespace q::literals;

std::span<float const> env;         // the envelope samples
...
auto trend = q::slope{10_ms, sps};        <1>

for (auto e : env)
{
   bool rising = trend(e) > 0.0f;         <2>
   // Use rising, true during the attack
}
```

<1> Construct a `slope` with a 10 ms window.
<2> Process the envelope sample and test the change over the window.
