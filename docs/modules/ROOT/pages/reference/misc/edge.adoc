= Edge Detectors

include::../../common.adoc[]

== Overview

`rising_edge` and `falling_edge` turn a boolean signal into single-sample events. A `rising_edge` returns `1` on the one sample where its input transitions from `0` to `1`, and `0` everywhere else. A `falling_edge` is its mirror: it returns `1` on the transition from `1` to `0`. Both hold the previous input in a single `bool` of state, so a steady input, whether high or low, produces no output; only the change is reported.

image::edge.svg[alt="Rising and falling edge events on a boolean input", width=700px, align=center, title="A boolean input with `rising_edge` firing on each 0 to 1 transition and `falling_edge` firing on each 1 to 0 transition. Each fire is a single-sample event; the steady stretches in between produce nothing.", link={imagesdir}/edge.svg]

A {schmitt_trigger}, a {window_comparator}, or a plain threshold test yields a boolean that stays latched for as long as the condition holds. A `rising_edge` after it isolates the instant it first went true, for a trigger, a counter, or a one-shot such as the `{mono-monostable}`. Both detectors are `constexpr`.

== Include

```c++
#include <q/fx/edge.hpp>
```

== Declaration

```c++
struct rising_edge
{
   constexpr bool    operator()(bool val);
};

struct falling_edge
{
   constexpr bool    operator()(bool val);
};
```

== Expressions

=== Notation

`E`             :: `rising_edge` or `falling_edge`.
`e`, `a`, `b`   :: Objects of type `E`.
`re`            :: Object of type `rising_edge`.
`fe`            :: Object of type `falling_edge`.
`val`           :: A `bool` input.

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression   | Semantics

| `E()`        | Construct an `E` with a previous input of `0`.
| `E(e)`       | Copy construct from `E e`.
| `a = b`      | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used.

A first call with `val == 1` therefore reports a rising edge, and a first `val == 0` reports no falling edge.

=== Function Call

[cols="1,1,1"]
|===
| Expression   | Semantics                                          | Return Type

| `re(val)`    | Process `val` and return `1` on the sample where
                 it transitions from `0` to `1`, otherwise `0`.     | `bool`
| `fe(val)`    | Process `val` and return `1` on the sample where
                 it transitions from `1` to `0`, otherwise `0`.     | `bool`
|===

=== Example

Start a 50 ms one-shot each time the level of the input samples `in`, at `sps` samples per second, rises above a threshold, with a hysteresis of -40 dB (0.01):

```c++
#include <q/fx/edge.hpp>
#include <q/support/literals.hpp>  // For the literals
#include <q/fx/schmitt_trigger.hpp>  // For schmitt_trigger
#include <q/fx/monostable.hpp>    // For monostable
...
namespace q = cycfi::q;
using namespace q::literals;

float ref;                          // the threshold
...
auto gate = q::schmitt_trigger{-40_dB};
auto opened = q::rising_edge{};                  <1>
auto hold = q::monostable{50_ms, sps};

for (auto s : in)
{
   bool is_open = gate(std::abs(s), ref);
   bool pulse = hold(opened(is_open));          <2>
   // Use pulse, true for 50 ms after the gate opens
}
```

<1> Construct a `rising_edge` for the gate output.
<2> Take the instant the gate opens, and start the one-shot on it.
