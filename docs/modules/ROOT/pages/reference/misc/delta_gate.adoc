= Delta Gate

include::../../common.adoc[]

== Overview

`delta_gate` is true when a signal stands a given ratio above its own value about a duration `d` ago. The past value comes from a `{mono-sample_hold}`, so "about `d` ago" means `d` to `1.5 d` before. A ratio makes it a comparison in dB: a 6 dB rise is the same test at any level. It takes the ratio as a `decibel` or as a plain factor.

`delta_gate_bipolar` is true on a change either way: above the reference times the ratio, or below it divided by the ratio. Both the signal and the reference must be positive. A zero on either side, meaning no reading yet (a pitch detector with no pitch, for instance), keeps it shut.

It opens on each pick, and also on the smaller rise just before it, out of the noise floor. Bottom, delta_gate_bipolar(a semitone, 20 ms) on a pitch trace: the vibrato stays inside the band and does not open it; the whole-tone step does; the gap with no pitch keeps it shut, and so does the return from it.", link={imagesdir}/delta_gate.svg]

Things to know when using the gates:

* The gate is a plain comparison, made sample by sample. It has no hysteresis and no hold, so during one attack it can open and close several times while the reference catches up. For one event per attack, follow it with a `{mono-monostable}` and a `{rising_edge}`, as in the example.
* A ratio is independent of the level: a quiet rise out of the noise floor counts as much as a loud one, as the top of the figure shows. If only loud rises matter, add a floor on the level.
* The reference is 0 for the first `1.5 d`, and `delta_gate` is true for any positive input then. Any level is a rise against zero, so a signal rising out of silence fires it. `delta_gate_bipolar` stays shut.

== Include

```c++
#include <q/fx/delta_gate.hpp>
```

== Declaration

```c++
struct delta_gate
{
               delta_gate(float ratio, duration d, float sps);
               delta_gate(decibel ratio, duration d, float sps);

   bool        operator()(float s);
   bool        operator()() const;

   float       then() const;
};

struct delta_gate_bipolar
{
               delta_gate_bipolar(float ratio, duration d, float sps);
               delta_gate_bipolar(decibel ratio, duration d, float sps);

   bool        operator()(float s);
   bool        operator()() const;

   float       then() const;
};
```

== Expressions

=== Notation

`G`             :: `delta_gate` or `delta_gate_bipolar`.
`g`, `a`, `b`   :: Objects of type `G`.
`r`             :: Floating point value for the ratio, above 1.0.
`db`            :: Object of type `decibel` for the ratio, above 0 dB.
`d`             :: Object of type `duration`, the lookback.
`sps`           :: Floating point value for samples per second.
`s`             :: Floating point value for the latest input sample.

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression        | Semantics

| `G(r, d, sps)`    | Construct a `G` given `r` (ratio), `d` (lookback)
                      and `sps` (samples per second).
| `G(db, d, sps)`   | Construct a `G` given `db` (ratio in decibels), `d`
                      (lookback) and `sps` (samples per second).
| `G(g)`            | Copy construct from `G g`.
| `a = b`           | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used.

=== Function Call

[cols="1,1,1"]
|===
| Expression      | Semantics                                  | Return Type

| `g(s)`          | Process the input sample `s` and return
                    its comparison with the reference.         | `bool`
| `g()`           | Get the latest result.                     | `bool`
|===

The reference is the signal about `d` ago, as it was before `s`. `delta_gate` returns true if `s` is above the reference times the ratio. `delta_gate_bipolar` returns true if both `s` and the reference are positive, and `s` is above the reference times the ratio or below the reference divided by the ratio.

=== Accessors

[cols="1,1,1"]
|===
| Expression      | Semantics                                  | Return Type

| `g.then()`      | Get the reference the next sample is
                    compared with.                             | `float`
|===

=== Example

Detect each pick in a guitar phrase from the level of the input samples `in`, at `sps` samples per second: a rise of 6 dB against about 20 ms ago, with the level above -40 dB so that small rises out of the noise floor do not count. The monostable holds for 100 ms and does not retrigger in that time; its rising edge is one event per pick. On the phrase in the figure, this gives one event for each of the four picks, each on the pick's rise.

```c++
#include <q/support/literals.hpp>  // For the literals
#include <q/fx/envelope.hpp>      // For peak_envelope_follower
#include <q/fx/monostable.hpp>    // For monostable
#include <q/fx/edge.hpp>          // For rising_edge

namespace q = cycfi::q;
using namespace q::literals;

auto env = q::peak_envelope_follower{50_ms, sps};
auto rise = q::delta_gate{6_dB, 20_ms, sps};         <1>
auto hold = q::monostable{100_ms, sps};
auto edge = q::rising_edge{};

for (auto s : in)
{
   float level = env(std::abs(s));
   bool up = rise(level) && level > 0.01f;          <2>
   bool pick = edge(hold(up));                      <3>
   // Use pick, for example to trigger a note
}
```

<1> Construct a `delta_gate` that opens on a rise of 6 dB against the level
    about 20 ms ago.
<2> Compare the level with the reference, and keep only the rises above
    -40 dB (0.01).
<3> Hold for 100 ms and take the rising edge, one event per pick.

NOTE: Call the gate on every sample, as here, even when its result is not used: each call also advances its reference. Written the other way round, `level > 0.01f && rise(level)` would skip the call below the floor and leave the reference stale.

Detect a new note from a run of pitch estimates, at `sps` samples per second: a step of more than a semitone either way, against the pitch about 20 ms ago.

```c++
#include <q/fx/delta_gate.hpp>
#include <q/support/literals.hpp>  // For the literals
#include <span>
...
namespace q = cycfi::q;
using namespace q::literals;

std::span<float const> pitch;       // the pitch estimates in Hz, 0 while there is none
...
auto step = q::delta_gate_bipolar{1.0595f, 20_ms, sps};   <1>

for (auto f : pitch)
{
   bool new_note = step(f);                               <2>
   // Use new_note, for example to start a note
}
```

<1> Construct a `delta_gate_bipolar` with a ratio of a semitone and a
    lookback of 20 ms.
<2> Compare the pitch with the pitch about 20 ms ago, either way.
