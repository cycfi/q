= All-Pass Phase Shifters

include::../../common.adoc[]

== Overview

`one_pole_allpass` and `polyphase_allpass` are all-pass sections: they pass every frequency at unity gain and shift only the phase. A single section on a static signal is inaudible. The phase shift is the building block of phasers, fractional-delay lines, quadrature networks, and the polyphase filters used for resampling. These are raw time-domain sections. The biquad xref:reference/biquad/allpass.adoc[All Pass Filter] is a second-order all-pass in the general cookbook form.

== One-Pole All-Pass

`one_pole_allpass` is the first-order section, `H(z) = (a + z^-1) / (1 + a z^-1)`. Its coefficient `a`, the pole location in the range `-1..1`, sets the frequency where the phase passes through `-90` degrees: the pivot. Construct it with `a` directly, or with a `{frequency}` and a sample rate, which places the pivot at that frequency (`a = tan(pi * f / sps - pi/4)`). `pivot` retunes it while it runs. Sweeping the pivot makes a phaser.

=== Include

```c++
#include <q/fx/allpass.hpp>
```

=== Declaration

```c++
struct one_pole_allpass
{
               one_pole_allpass(float a);
               one_pole_allpass(frequency f, float sps);

   float       operator()(float s);

   void        pivot(frequency f, float sps);

   float       a;
};
```

=== Expressions

==== Notation

`ap`, `a`, `b`  :: Objects of type `one_pole_allpass`.
`k`             :: Floating point value from -1.0 to 1.0 for the pole location.
`f`             :: Object of type `{frequency}`, the pivot frequency.
`sps`           :: Floating point value for samples per second.
`s`             :: Floating point value for the latest input sample.

==== Constructors and Assignment

[cols="1,1"]
|===
| Expression                    | Semantics

| `one_pole_allpass(k)`         | Construct a `one_pole_allpass` given `k`
                                  (pole location).
| `one_pole_allpass(f, sps)`    | Construct a `one_pole_allpass` given `f`
                                  (pivot frequency) and `sps` (samples per
                                  second).
| `one_pole_allpass(ap)`        | Copy construct from `one_pole_allpass ap`.
| `a = b`                       | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used.

==== Function Call

[cols="1,1,1"]
|===
| Expression    | Semantics                                 | Return Type

| `ap(s)`       | Process the input sample `s` and return
                  the phase-shifted output.                 | `float`
|===

==== Mutators

[cols="1,1,1"]
|===
| Expression            | Semantics                                 | Return Type

| `ap.pivot(f, sps)`    | Set the pivot frequency given `f` (pivot
                          frequency) and `sps` (samples per
                          second).                                  | `void`
|===

==== Access

[cols="1,1,1"]
|===
| Expression    | Semantics                                 | Return Type

| `ap.a`        | Direct access to the pole location.       | `float`
|===

WARNING: The pole location must stay within `-1..1`; outside that range the section is unstable. The `(f, sps)` constructor and `pivot` keep it within range for any `f` between 0 and Nyquist.

==== Example

Cancel 1 kHz in the input samples `in`, at `sps` samples per second, with one phaser stage: two sections shift 1 kHz by `-180` degrees, and the shifted signal is mixed with the dry signal.

```c++
namespace q = cycfi::q;
using namespace q::literals;

auto ap1 = q::one_pole_allpass{1_kHz, sps};   <1>
auto ap2 = q::one_pole_allpass{1_kHz, sps};

for (auto& s : in)
   s = 0.5f * (s + ap2(ap1(s)));              <2>
```

<1> Construct two first-order all-pass sections, each with its pivot at
    1 kHz.
<2> Shift the sample through both sections and mix it with the dry sample.

== Polyphase All-Pass

`polyphase_allpass` is a second-order section in `z^-2`, `H(z) = (a - z^-2) / (1 - a z^-2)`, following the design by Olli Niemitalo (see http://yehar.com/blog/?p=368[yehar.com]). Cascaded, these sections form polyphase IIR filters: half-band filters for 2x resampling, and the two chains inside {hilbert_quadrature}. The coefficient `a` of each section comes from a published coefficient set for the filter.
