= Schmitt Trigger

include::../../common.adoc[]

== Overview

The output of a simple comparator is determined by its inputs. The output is `1` if the input signal is greater than the reference signal plus a specified hysteresis. The output is `0` if the input signal is less than the reference signal minus the specified hysteresis. Otherwise, the previous result is retained.

The Schmitt trigger is implemented by a class named `schmitt_trigger`.

image::schmitt_trigger.svg[alt="Schmitt trigger hysteresis", width=700px, align=center, title="A noisy input crosses the hysteresis band (amber) around the reference. The output only switches when the signal clears the upper or lower threshold; noise within the band causes no spurious transitions.", link={imagesdir}/schmitt_trigger.svg]

== Include

```c++
#include <q/fx/schmitt_trigger.hpp>
```

== Declaration

```c++
struct schmitt_trigger
{
               schmitt_trigger(float hysteresis);
               schmitt_trigger(decibel hysteresis);

   bool        operator()(float s, float ref);
   bool        operator()() const;

   bool        y = 0;
};
```

== Expressions

=== Notation

`st`              :: Object of type `schmitt_trigger`.
`h`               :: Floating point value representing hysteresis.
`hdb`             :: Object of type `decibel` representing the hysteresis in decibels.
`s`               :: Input sample.
`ref`             :: A reference signal.

=== Constructors

[cols="1,1"]
|===
| Expression               | Semantics

| `schmitt_trigger(h)`     | Construct a `schmitt_trigger` with specified
                             hysteresis, `h`.
| `schmitt_trigger(hdb)`   | Construct a `schmitt_trigger` with specified
                             hysteresis, `hdb` (in decibels).
| `schmitt_trigger(st)`    | Copy construct a `schmitt_trigger` from `st`.
|===

NOTE: C++ brace initialization may also be used.

`schmitt_trigger` is not copy assignable.

=== Function Call

[cols="1,1,1"]
|===
| Expression      | Semantics                            | Return Type

| `st(s, ref)`    | Output is `1` if the input signal `s`
                    is greater than the reference signal
                    `ref` plus the specified hysteresis.
                    Otherwise, the output is `0` if the
                    input signal `s` is less than the
                    reference signal `ref` minus the
                    specified hysteresis. Otherwise, the
                    previous result is retained.         | `bool`
| `st()`          | Return the latest result.            | `bool`
|===

=== Access

[cols="1,1,1"]
|===
| Expression      | Semantics                            | Return Type

| `st.y`          | Direct access to the latest result.  | `bool`
|===

=== Example

Square up the input samples `in` around zero, ignoring noise within ±0.01:

```c++
namespace q = cycfi::q;

auto st = q::schmitt_trigger{0.01f};                     <1>

for (auto& s : in)
   s = st(s, 0.0f) ? 1.0f : -1.0f;                        <2>
```

<1> Construct a `schmitt_trigger` with a hysteresis of 0.01.
<2> Compare the sample with a reference of 0. The output switches to `1`
    above 0.01 and to `0` below -0.01.
