= BACF Period Detector

include::../../common.adoc[]
:xrefstyle: short

== Overview

The BACF period detector finds the period of a monophonic signal as it plays. It is the core of the {bacf_pitch_detector}. It pairs the {zero_crossing_collector}, which records the pulses between zero crossings, with the {bitstream_acf}, which scores how well the signal matches itself one candidate period later. The detector is implemented by a class named `bacf_period_detector`.

The detector takes one sample at a time. Every half window the collector is ready (`is_ready()`), and the detector:

. builds the bitset from the collected pulses (see <<_bitset>>),
. proposes candidate periods from pairs of leading edges,
. scores each candidate with one {bitstream_acf} pass, and
. settles harmonics and sub-harmonics on the fundamental (see <<_sub_collector>>).

The result, `fundamental()`, holds the `_period` in samples and the `_periodicity` from 0 to 1, where 1 is perfectly periodic. `harmonic(index)` gives the periodicity at the period of harmonic `index`, to follow the harmonics of a note as it evolves, in the time domain. For lower latency, `predict_period()` gives a period from the similarity of the zero-crossing edges alone, before an analysis completes.

`bacf_period_detector` reports period and periodicity. The {bacf_pitch_detector} turns them into a stable frequency, with bias, smoothing and note-shift detection.

== Bitset

The analysis window spans two periods of the lowest frequency of interest, so that a cycle can be correlated with the next. Every half window, the detector transfers the pulses of the window to a `bitset`, which stores the bits in integers of the platform's native size, 32 or 64 bits.

Only significant pulses go in: those whose peak is at least `pulse_threshold` (60%) of the highest pulse in the window. Dropping the spurious low-level pulses improves detection. In the graphs of {pitch_detection}, the grey trace is every zero crossing and the blue one the bitset.

== Sub-Collector

Standard autocorrelation shifts the signal window lag by lag, and correlates each shift against the unshifted signal. BACF correlates only at the lags between zero-crossing edges, a handful a window: a further speedup.

The candidate periods are the distances between the leading edges of the significant pulses, up to half the window and no shorter than `minimum_period()`. For each candidate, the detector computes the BACF and collects the most significant results. Longer periods typically, but not always, score better, with more samples to resolve them. A longer period may also be a sub-harmonic of a shorter one, a multiple of it, and the sub-collector detects that from the ratio of their durations.

The sub-collector returns the period of the edge pair with the best periodicity, divided by its multiple of the shortest edge pair with a good enough periodicity: within `harmonic_periodicity_factor` (16) mismatched bits. The BACF score is used only as a hint, to choose the edges that bound the cycle. The period computed from the interpolated zero crossings of those edges is more accurate than the lag of the BACF peak.

<<fig-pd-sub-collector>> is the detector at work on a guitar's low E, a second after the pick, from the test suite. The first two leading edges of the first analysis give three candidate periods: p1, 224 samples; p2, 540; and p3, 316. Their lags are dashed on the analysis's BACF. p1 and p3 are fractions of the cycle, with periodicities of 0.61 and 0.66. p2 spans a whole cycle, at the peak, with a periodicity of 0.98. It is the best candidate, and the detector returns its period, from its interpolated edges, with the periodicity.

Higher notes have more peaks within the window: an octave above the lowest frequency, two; two octaves above, four. The detector uses the multiples for precision: a longer span holds more samples, so its period, divided by its multiple, is more precise. With the interpolated zero crossings, precision holds from the lowest frequency to the highest (see the Results in {pitch_detection}).

== Declaration

```c++
class bacf_period_detector
{
public:

   static constexpr float  pulse_threshold = 0.6;
   static constexpr float  harmonic_periodicity_factor = 16;
   static constexpr float  periodicity_diff_factor = 0.008;

   struct info
   {
      float                _period = -1;
      float                _periodicity = 0.0f;
   };

                           bacf_period_detector(
                              frequency lowest_freq
                            , frequency highest_freq
                            , float sps
                            , decibel hysteresis
                           );

   bool                    operator()(float s);
   bool                    operator()() const;

   bool                    is_ready() const;
   std::size_t const       minimum_period() const;
   bitset<> const&         bits() const;
   zero_crossing_collector const& edges() const;
   float                   predict_period() const;

   info const&             fundamental() const;
   float                   harmonic(std::size_t index) const;
};
```

== Expressions

=== Notation

`pd`, `a`, `b`                :: Objects of type `bacf_period_detector`.
`i`                           :: Object of type `bacf_period_detector::info`.
`lowest_freq`, `highest_freq` :: Objects of type `{frequency}`: the detection range.
`sps`                         :: Floating point value for samples per second.
`hysteresis`                  :: Object of type `{decibel}`: the zero-crossing hysteresis (e.g. `-30_dB`).
`s`                           :: Floating point value for the latest input sample.
`index`                       :: Object of type `std::size_t`: a harmonic number, 1 being the fundamental.

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression                    | Semantics

| `bacf_period_detector(lowest_freq, highest_freq, sps, hysteresis)`
                                | Construct a `bacf_period_detector` given
                                  `lowest_freq` and `highest_freq` (the
                                  detection range), `sps` (samples per
                                  second) and `hysteresis` (zero-crossing
                                  hysteresis).

NOTE: C++ brace initialization may also be used.

The analysis window spans two periods of `lowest_freq`, rounded up to whole words of the bitset.

WARNING: `highest_freq` must be greater than `lowest_freq`. The constructor throws `std::runtime_error` otherwise, when exceptions are enabled.

[cols="1,1,1"]
|===
| Expression            | Semantics                                 | Return Type

| `pd.fundamental()`    | Get the detected period and periodicity.  | `bacf_period_detector::info const&`
| `pd.harmonic(index)`  | Get the periodicity at the period of
                          harmonic `index`.                         | `float`

                          zero-crossing edges, in samples.          | `float`
| `pd.is_ready()`       | Return `true` when an analysis window
                          is ready.                                 | `bool`

                          samples (from `highest_freq`).            | `std::size_t`

NOTE: `pd.fundamental()._period` is -1 until an analysis finds a period, and again after the zero-crossing collector resets in silence. Check `_periodicity` before using the period. `pd.predict_period()` is -1 when the edges give no prediction, and `pd.harmonic(index)` is 0 when the period of the harmonic is out of range.

=== Example

Detect the period of the input samples `in`, at `sps` samples per second, between 50 Hz and 500 Hz:

```c++
namespace q = cycfi::q;
using namespace q::literals;

auto pd = q::bacf_period_detector{50_Hz, 500_Hz, sps, -30_dB};   <1>
float freq = 0;

for (auto s : in)
{
   if (pd(s))                                                     <2>
   {
      auto const& f = pd.fundamental();                           <3>
      if (f._periodicity > 0.9f)
         freq = sps / f._period;
   }
   // Use freq
}
```

<1> Construct a `bacf_period_detector` for 50 Hz to 500 Hz, with a zero-crossing hysteresis of -30 dB.
<2> Process the sample; the result is `true` when an analysis completes.
<3> Get the period and periodicity, and convert a confident period to a frequency.
