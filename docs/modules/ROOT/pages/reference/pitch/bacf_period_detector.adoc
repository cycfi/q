= BACF Period Detector

include::../../common.adoc[]

== Overview

The BACF period detector estimates the period of a monophonic signal in real time. It combines the {zero_crossing_collector}, which records the zero-crossing pulses of the signal, with the {bitstream_acf}, which scores candidate periods, and it is the basis of the {pitch_detector}. The detector is implemented by a class named `bacf_period_detector`.

The detector processes one sample at a time. The {zero_crossing_collector} becomes ready (`is_ready()`) every half window. On a ready window, `bacf_period_detector`:

. builds a bitstream from the collected zero-crossing pulses,
. proposes candidate periods from pairs of edges,
. scores each candidate with one {bitstream_acf} pass, and
. reconciles harmonics and sub-harmonics to settle on the fundamental.

The BACF score selects the pair of zero-crossing edges that bounds the cycle. The period is the distance between those edges, interpolated to sub-sample precision. The interpolated edges give a more accurate period than the whole-sample lag of the BACF minimum.

The detector finds the period even when the fundamental is weak or missing: the composite waveform still repeats at the fundamental period, and the BACF minimum falls there.

image::bacf_missing_fundamental.svg[alt="Period found despite a missing fundamental", width=720px, align=center, title="A signal made only of the 2nd, 3rd and 4th harmonics (top) still repeats at the fundamental period, and the bitstream correlation's deepest notch (bottom) lands on that period", link={imagesdir}/bacf_missing_fundamental.svg]

The result, `fundamental()`, holds the `_period` in samples and the `_periodicity` in [0, 1], where 1 is perfectly periodic. `harmonic(index)` gives the periodicity at the period of a harmonic. For lower latency, `predict_period()` gives a sub-sample period from the similarity of the zero-crossing edges alone, available before the autocorrelation completes.

`bacf_period_detector` reports period and periodicity. The {pitch_detector} converts them to a stable frequency, with bias, smoothing and note-shift detection.

```c++
#include <q/pitch/bacf_period_detector.hpp>
```

== Declaration

```c++
class bacf_period_detector
{
public:

   static constexpr float  pulse_threshold = 0.6;
   static constexpr float  harmonic_periodicity_factor = 16;
   static constexpr float  periodicity_diff_factor = 0.008;

   struct info
   {
      float                _period = -1;
      float                _periodicity = 0.0f;
   };

                           bacf_period_detector(
                              frequency lowest_freq
                            , frequency highest_freq
                            , float sps
                            , decibel hysteresis
                           );

   bool                    operator()(float s);
   bool                    operator()() const;

   bool                    is_ready() const;
   std::size_t const       minimum_period() const;
   bitset<> const&         bits() const;
   zero_crossing_collector const& edges() const;
   float                   predict_period() const;

   info const&             fundamental() const;
   float                   harmonic(std::size_t index) const;
};
```

== Expressions

=== Notation

`pd`, `a`, `b`                :: Objects of type `bacf_period_detector`.
`i`                           :: Object of type `bacf_period_detector::info`.
`lowest_freq`, `highest_freq` :: Objects of type `{frequency}`: the detection range.
`sps`                         :: Floating point value for samples per second.
`hysteresis`                  :: Object of type `{decibel}`: the zero-crossing hysteresis (e.g. `-30_dB`).
`s`                           :: Floating point value for the latest input sample.
`index`                       :: Object of type `std::size_t`: a harmonic number, 1 being the fundamental.

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression                    | Semantics

| `bacf_period_detector(lowest_freq, highest_freq, sps, hysteresis)`
                                | Construct a `bacf_period_detector` given
                                  `lowest_freq` and `highest_freq` (the
                                  detection range), `sps` (samples per
                                  second) and `hysteresis` (zero-crossing
                                  hysteresis).
| `bacf_period_detector(pd)`    | Copy construct from `bacf_period_detector pd`.
| `a = b`                       | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used.

The analysis window spans two periods of `lowest_freq`, rounded up to whole words of the bitset.

WARNING: `highest_freq` must be greater than `lowest_freq`. The constructor throws `std::runtime_error` otherwise, when exceptions are enabled.

=== Function Call

[cols="1,1,1"]
|===
| Expression   | Semantics                                     | Return Type

| `pd(s)`      | Process the input sample `s` and return
                 `true` when an analysis completes.            | `bool`
| `pd()`       | Get the zero-crossing state.                  | `bool`
|===

=== Accessors

[cols="1,1,1"]
|===
| Expression            | Semantics                                 | Return Type

| `pd.fundamental()`    | Get the detected period and periodicity.  | `bacf_period_detector::info const&`
| `pd.harmonic(index)`  | Get the periodicity at the period of
                          harmonic `index`.                         | `float`
| `pd.predict_period()` | Get the period predicted from the
                          zero-crossing edges, in samples.          | `float`
| `pd.is_ready()`       | Return `true` when an analysis window
                          is ready.                                 | `bool`
| `pd.minimum_period()` | Get the shortest detectable period, in
                          samples (from `highest_freq`).            | `std::size_t`
| `pd.edges()`          | Get the zero-crossing collector.          | `zero_crossing_collector const&`
| `pd.bits()`           | Get the bitstream of the latest analysis. | `bitset<> const&`
|===

NOTE: `pd.fundamental()._period` is -1 until an analysis finds a period, and again after the zero-crossing collector resets in silence. Check `_periodicity` before using the period. `pd.predict_period()` is -1 when the edges give no prediction, and `pd.harmonic(index)` is 0 when the period of the harmonic is out of range.

=== Access

[cols="1,1,1"]
|===
| Expression                                          | Semantics                             | Return Type

| `i._period`                                         | Get the period, in samples.           | `float`
| `i._periodicity`                                    | Get the periodicity, from 0 to 1.     | `float`

                                                        pulse below which pulses are
                                                        ignored (0.6).                      | `float`
| `bacf_period_detector::harmonic_periodicity_factor` | Get the periodicity margin, in
                                                        mismatched bits, within which a
                                                        candidate at a multiple of the

                                                        period (16).                        | `float`

                                                        candidate periods are the
                                                        same (0.008).                       | `float`
|===

=== Example

Detect the period of the input samples `in`, at `sps` samples per second, between 50 Hz and 500 Hz:

```c++
namespace q = cycfi::q;
using namespace q::literals;

auto pd = q::bacf_period_detector{50_Hz, 500_Hz, sps, -30_dB};   <1>
float freq = 0;

for (auto s : in)
{
   if (pd(s))                                                     <2>
   {
      auto const& f = pd.fundamental();                           <3>
      if (f._periodicity > 0.9f)
         freq = sps / f._period;
   }
   // Use freq
}
```

<1> Construct a `bacf_period_detector` for 50 Hz to 500 Hz, with a zero-crossing hysteresis of -30 dB.
<2> Process the sample; the result is `true` when an analysis completes.
<3> Get the period and periodicity, and convert a confident period to a frequency.
