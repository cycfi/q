= Zero Crossing Collector

include::../../common.adoc[]

== Overview

The zero crossing collector is the front end of the pitch detectors. It detects the zero crossings of the signal and records each pulse: the {bacf_period_detector} takes candidate periods from the pulse edges, and sets the bits of the bitstream that the {bitstream_acf} correlates. The collector is implemented by a class named `zero_crossing_collector`.

A crossing is detected with *hysteresis*: the state goes high when the signal rises above half the `hysteresis` level, and low when it falls below minus half of it, so noise riding on a slow waveform does not produce spurious edges. Each pulse is saved as an `info` record holding the peak height of the waveform it bounds, the pulse width, the leading and trailing edge frame positions, and the two samples straddling the leading edge (for sub-sample timing).

image::zero_crossing_event.svg[alt="A zero-crossing pulse with sub-sample interpolation", width=720px, align=center, title="One positive pulse: the leading (rising) and trailing (falling) crossings bound the pulse, and the crossing is located to sub-sample precision by interpolating between the two samples P1 and P2 that straddle it", link={imagesdir}/zero_crossing_event.svg]

Only the most recent pulses are kept, bounded by a sliding `window` measured in samples. `is_ready()` becomes true every half window, when the window holds at least two edges: the cadence at which the period analysis runs. As the window advances, edge frame positions are shifted by `-window/2` so an edge keeps a consistent coordinate from one window to the next, and a pulse straddling the boundary is kept as long as its trailing edge is still within the window.

The collected edges serve two purposes: pairs of edges propose candidate periods (the lag between two like edges), and the pulses define where the bitstream bits are set.

== Declaration

```c++
class zero_crossing_collector
{
public:

   static constexpr float  pulse_height_diff = 0.8;
   static constexpr float  pulse_width_diff = 0.85;
   static constexpr auto   undefined_edge = int_min<int>();

   struct info
   {
      using crossing_data = std::pair<float, float>;

      std::size_t          period(info const& next) const;
      float                fractional_period(info const& next) const;
      bool                 similar(info const& next) const;

      crossing_data        _crossing;
      float                _peak;
      int                  _leading_edge = undefined_edge;
      int                  _trailing_edge = undefined_edge;
      float                _width = 0.0f;
   };

                           zero_crossing_collector(decibel hysteresis, duration window, float sps);
                           zero_crossing_collector(decibel hysteresis, std::uint32_t window);

   std::size_t             num_edges() const;
   std::size_t             capacity() const;
   std::size_t             frame() const;
   std::size_t             window_size() const;
   bool                    is_ready() const;
   float                   peak_pulse() const;
   bool                    is_reset() const;

   bool                    operator()(float s);
   bool                    operator()() const;
   info const&             operator[](std::size_t index) const;
   info&                   operator[](std::size_t index);
};
```

== Expressions

=== Notation

`zc`, `a`, `b`    :: Objects of type `zero_crossing_collector`.
`e1`, `e2`        :: Objects of type `zero_crossing_collector::info`, `e1` the earlier edge.
`hysteresis`      :: Object of type `{decibel}`: the hysteresis level.
`window`          :: Object of type `{duration}`: the window length.
`n`               :: Object of type `std::uint32_t`: the window length, in samples.
`sps`             :: Floating point value for samples per second.
`s`               :: Floating point value for the latest input sample.
`i`               :: Object of type `std::size_t`: an edge index, from 0 (oldest) to `zc.num_edges() - 1` (latest).

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression                                          | Semantics

| `zero_crossing_collector(hysteresis, window, sps)`  | Construct a `zero_crossing_collector` given
                                                        `hysteresis` (hysteresis level), `window`
                                                        (window length) and `sps` (samples per second).
| `zero_crossing_collector(hysteresis, n)`            | Construct a `zero_crossing_collector` given
                                                        `hysteresis` (hysteresis level) and `n`
                                                        (window length in samples).
| `zero_crossing_collector(zc)`                       | Copy construct from `zero_crossing_collector zc`.
| `a = b`                                             | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used.

The window is rounded up to a whole number of `bitset<>` words, at least two. `zc.window_size()` gives the result.

=== Function Call

[cols="1,1,1"]
|===
| Expression   | Semantics                                     | Return Type

                 zero-crossing state.                          | `bool`
| `zc()`       | Get the zero-crossing state.                  | `bool`
|===

The zero-crossing state is `true` from a leading (rising) edge to the next trailing (falling) edge.

                                                  leading edge.                           | `std::pair<float, float>`

                                                  yet reached.                            | `int`

`e1._trailing_edge` is `undefined_edge` while the pulse is still high.

=== Example

On each ready window of the input samples `in`, at `sps` samples per second, measure the period between the two latest edges when their pulses are similar:

```c++
namespace q = cycfi::q;
using namespace q::literals;

auto zc = q::zero_crossing_collector{-30_dB, 30_ms, sps};       <1>
float period = 0;

for (auto s : in)
{
   zc(s);                                                        <2>
   if (zc.is_ready())                                            <3>
   {
      auto n = zc.num_edges();
      auto const& e1 = zc[n - 2];                                <4>
      auto const& e2 = zc[n - 1];
      if (e1.similar(e2))
         period = e1.fractional_period(e2);                      <5>
   }
   // Use period
}
```

<1> Construct a `zero_crossing_collector` with a hysteresis of -30 dB and a window of 30 ms.
<2> Process the sample.
<3> Analyze when the window is ready; it then holds at least two edges.
<4> Get the two latest edges.
<5> Get the period between them, to sub-sample precision.
