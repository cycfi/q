= Formant Table

include::../../common.adoc[]

CAUTION: {unstable}

== Overview

The formant table holds the spectral envelope `F` and the moved spectral envelope `F(f/r)` for every ratio on a grid: `steps` a semitone, from `lo` to `hi` semitones. Each row is an all-pole model of the spectral envelope. A table is plain data, about 13 KB at order 32: allocate it, have a `{formant_learner}` fit it, and hand it to a `{formant_corrector}`.

Each row is an all-pole model of the spectral envelope: its reflection coefficients, as many as the model's order, which the corrector's lattice filters take, and its level. The coefficients are held in 16 bits, as a reflection coefficient is under 1 in magnitude, and the rows are a quarter of a semitone apart. Against 32-bit rows an eighth of a semitone apart, the correction stays within 0.2 dB in every third-octave band, on single notes and chords alike. See `{formant_preservation}` for how the rows are learned and used.

The order is given at construction, 32 by default. On a smaller core 24 costs the corrector about a quarter less, and on four guitars its correction stayed within 3 dB of the order-32 one; both sound good, 32 is the more accurate. The learner and the corrector are constructed with the order too, and take only tables of it.

The formant table is implemented by a class named `formant_table`.

== Include

```c++
#include <q/fx/formant_corrector.hpp>
```

== Declaration

```c++
class formant_table
{
public:

   static constexpr int          lo = -24;
   static constexpr int          hi = 24;
   static constexpr int          steps = 4;
   static constexpr std::size_t  num_rows = (hi - lo) * steps + 1;

   explicit                formant_table(std::size_t order = 32);

   std::size_t             order() const;

   void                    row(
                              std::size_t i
                            , std::span<float> k
                            , float& level
                           ) const;
   void                    set(
                              std::size_t i
                            , std::span<float const> k
                            , float level
                           );
   float                   level(std::size_t i) const;
   std::size_t             unshifted() const;
   void                    at(
                              float ratio
                            , std::span<float> k
                            , float& level
                           ) const;
};
```


== Expressions

=== Notation

`t`               :: Object of type `formant_table`.
`n`               :: Unsigned integer value for the model's order.
`i`               :: Unsigned integer value for a row, 0 to `num_rows - 1`.
`r`               :: Floating point value for a ratio: 2 is an octave up.
`k`               :: Object of type `std::span<float>`, `t.order()` long.
`c`               :: Object of type `std::span<float const>`, `t.order()`
                     long.
`v`               :: Floating point value for a level, or an lvalue of type
                     `float` to receive one.

=== Constructors

[cols="1,1"]
|===
| Expression              | Semantics

| `formant_table()`       | Construct a `formant_table` of order 32, every row
                            flat: no correction.
| `formant_table(n)`      | Construct a `formant_table` of order `n`. It
                            allocates here, and nowhere else.
|===

=== Accessors

[cols="1,1,1"]
|===
| Expression            | Semantics                                   | Return Type

| `t.order()`           | Get the model's order.                      | `std::size_t`
| `t.row(i, k, v)`      | Get the row `i` into `k` and `v`: its
                          reflection coefficients and its level. Rows
                          run from `lo` semitones up in `1 / steps` of
                          a semitone.                                 | `void`
| `t.level(i)`          | Get the level of the row `i`.               | `float`
| `t.unshifted()`       | Get the row for a ratio of 1: the spectral
                          envelope `F` itself.                        | `std::size_t`
| `t.at(r, k, v)`       | Get the model at the ratio `r` into `k` and
                          `v`, interpolated between the two grid rows
                          around it. Ratios beyond the grid take its
                          ends.                                       | `void`
|===

=== Mutators

[cols="1,1,1"]
|===
| Expression            | Semantics                                   | Return Type

| `t.set(i, c, v)`      | Set the row `i` to the reflection
                          coefficients `c`, each rounded to 16 bits,
                          and the level `v`.                          | `void`
|===
