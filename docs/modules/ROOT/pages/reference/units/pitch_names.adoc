= Pitch Names

include::../../common.adoc[]

== Overview

`pitch_names` is a set of compile-time `{frequency}` constants for the notes of the equal-tempered chromatic scale, together with the helpers that build them. {pitch} converts between a note number and its frequency at run time. `pitch_names` holds the frequencies as named constants: `pitch_names::A[4]` is 440 Hz.

The constants follow twelve-tone equal temperament: each semitone is the twelfth root of two (about 1.059463) above the one below it, and twelve semitones double the frequency, one octave up. `next_frequency` takes one semitone step. On a log axis, the chromatic scale is a straight line, and every octave is a doubling:

image::pitch_names_ladder.svg[alt="The equal-tempered chromatic ladder", width=700px, align=center, title="Equal semitone steps become equal steps on a log axis. The A pitches (A0..A7) fall on exact octave doublings anchored at A4 = 440 Hz.", link={imagesdir}/pitch_names_ladder.svg]

The header provides three layers:

* *Named constants.* The `pitch_names` namespace holds one array per note letter, indexed by octave: `pitch_names::C`, `pitch_names::Cs` (C sharp), `pitch_names::D`, and so on, each an eight-element `frequency` array covering octaves 0 through 7. The enharmonic spellings are `pitch_names::Ab`, `Bb`, `Db` and `Gb`.
* *Per-octave builders.* `octave_pitches` takes the `A` frequency of an octave and computes all twelve notes of that octave. An octave runs from C up to B, so its C is `next_frequency(B) / 2`. The global `oct_pitch` table holds one `octave_pitches` per octave, from octave 0 to 8, with A at 27.5, 55, ... 7040 Hz.
* *Semitone builder.* `octave_frequencies` takes any base `frequency` and computes the twelve semitones from the base upward, indexed by semitone: `of[0]` is the base, `of[7]` is seven semitones up. The global `pitch_frequencies` table holds ten, with the base at the A of each octave from -1 to 8 (13.75 to 7040 Hz).

NOTE: The octave index follows scientific pitch notation: `pitch_names::A[4]` is 440 Hz, and `pitch_names::C[4]` is middle C (about 261.63 Hz), which sits below `A[4]` within octave 4.

== Include

```c++
#include <q/support/pitch_names.hpp>
```

== Declaration

```c++
constexpr frequency next_frequency(frequency f);   // one semitone up

struct octave_pitches
{
   constexpr octave_pitches(frequency base);       // base is this octave's A

   frequency A, As, B, C, Cs, D, Ds, E, F, Fs, G, Gs;
   frequency Ab, Bb, Db, eb, Gb;                    // enharmonic aliases
};

struct octave_frequencies
{
   constexpr            octave_frequencies(frequency base);
   constexpr frequency  operator[](std::size_t semitone) const;

   frequency f[12];
};

// Global tables (constexpr)
octave_pitches       oct_pitch[];          // one per octave, A = 27.5 .. 7040
octave_frequencies   pitch_frequencies[];  // A = 13.75 .. 7040

// Named constants, each frequency[8] indexed by octave 0..7
namespace pitch_names
{
   frequency Ab[], A[], As[], Bb[], B[], C[], Cs[], Db[],
             D[], Ds[], Eb[], E[], F[], Fs[], Gb[], G[], Gs[];
}
```

== Expressions

=== Notation

`f`, `base`  :: Objects of type `{frequency}`.
`op`         :: Object of type `octave_pitches`.
`of`         :: Object of type `octave_frequencies`.
`oct`        :: Octave index, a `std::size_t`: 0 to 7 for the `pitch_names` arrays, 0 to 8 for `oct_pitch`, 0 to 9 for `pitch_frequencies`.
`semitone`   :: Semitone offset, a `std::size_t` from 0 to 11.

=== Constructors

[cols="1,1"]
|===
| Expression                 | Semantics

| `octave_pitches(base)`     | Construct an `octave_pitches` with the twelve
                               notes of the octave whose A is `base`.
| `octave_frequencies(base)` | Construct an `octave_frequencies` with the
                               twelve semitones from `base` upward.
| `octave_pitches(op)`       | Copy construct from `octave_pitches op`.
| `octave_frequencies(of)`   | Copy construct from `octave_frequencies of`.
|===

NOTE: C++ brace initialization may also be used.

=== Indexing

[cols="1,1,1"]
|===
| Expression        | Semantics                                     | Return Type

| `of[semitone]`    | Get the frequency `semitone` half-steps
                      above the base.                               | `frequency`
|===

=== Access

[cols="1,1,1"]
|===
| Expression               | Semantics                              | Return Type

| `pitch_names::A[oct]`    | Get the frequency of A in octave
                             `oct`. `pitch_names::A[4]` is 440 Hz.  | `frequency`
| `pitch_names::Cs[oct]`   | Get the frequency of C sharp in
                             octave `oct`.                          | `frequency`
| `pitch_names::Ab[oct]`   | Get the frequency of A flat (G sharp)
                             in octave `oct`.                       | `frequency`
| `op.A`                   | Get the frequency of A in the octave
                             of `op`.                               | `frequency`
| `oct_pitch[oct]`         | Get the prebuilt `octave_pitches` for
                             octave `oct`.                          | `octave_pitches`
| `pitch_frequencies[oct]` | Get the prebuilt `octave_frequencies`
                             from the A of octave `oct - 1`.        | `octave_frequencies`
|===

The `pitch_names` arrays are `Ab`, `A`, `As`, `Bb`, `B`, `C`, `Cs`, `Db`, `D`, `Ds`, `Eb`, `E`, `F`, `Fs`, `Gb`, `G` and `Gs`, each indexed 0 to 7. The members of `octave_pitches` are `A`, `As`, `B`, `C`, `Cs`, `D`, `Ds`, `E`, `F`, `Fs`, `G` and `Gs`, with the aliases `Ab`, `Bb`, `Db`, `eb` and `Gb`.

=== Functions

[cols="1,1,1"]
|===
| Expression            | Semantics                             | Return Type

| `next_frequency(f)`   | Get the frequency one semitone above
                          `f` (`f` times the twelfth root of
                          two).                                 | `frequency`
|===

=== Example

Run a {phase_iterator} at A4, at `sps` samples per second, and step up one
semitone from the low E string of a guitar:

```c++
#include <q/support/phase.hpp>  // For phase_iterator

namespace q = cycfi::q;

auto a4 = q::pitch_names::A[4];           <1>
auto ph = q::phase_iterator{a4, sps};

auto f0 = q::pitch_names::E[2];           <2>
auto f1 = q::next_frequency(f0);          <3>
```

<1> Get A4, 440 Hz.
<2> Get E2, the low E string of a guitar.
<3> Get F2, one semitone (one fret) up.
