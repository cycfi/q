= Period

include::../../common.adoc[]

== Overview

Type safe representation of period: the reciprocal of frequency, or the time it takes for a periodic event to complete one full cycle or oscillation.

== Include

```c++
#include <q/support/period.hpp>
```

== Declaration

`period` is a subclass of {duration} and inherits all its public member functions, member variables, and types.

```c++
struct period : duration
{
   using duration::duration;

   constexpr explicit   period(duration d);
   constexpr explicit   period(frequency f);
};
```

== Expressions

As a subclass of `{duration}`, `period` inherits all the publicly accessible member functions, member variables, and types of its base class.

`period` is a model of `{Unit}`. In addition to valid expressions for {Unit}, `period` allows these expressions.

=== Notation

`d`   :: Object of type `duration`.
`f`   :: Object of type `frequency`.
`p`   :: Object of type `period`.

=== Constructors

[cols="1,1"]
|===
| Expression   | Semantics

| `period(d)`  | Construct a `period` given a duration, `d`.
| `period(f)`  | Construct a `period` given a frequency, `f`.
|===

NOTE: C++ brace initialization may also be used.

=== Conversions

[cols="1,1,1"]
|===
| Expression      | Semantics                                     | Return Type

| `as_float(p)`   | Convert period to a `float` in seconds.       | `float`
| `as_double(p)`  | Convert period to a `double` in seconds.      | `double`
|===

=== Example

Get the period of the frequency `f` (a `frequency`), in samples, at `sps`
samples per second:

```c++
namespace q = cycfi::q;

auto p = q::period{f};                    <1>
float samples = q::as_float(p) * sps;     <2>
```

<1> Construct a `period` from the frequency, `1 / f` seconds.
<2> Convert the period to seconds, then to samples.
